# web-rust-archive

Former Rust/axum implementation of the Marqdo web plugin (`marqdo_plugin_web`).

**Status (W-G13):** archived reference only. The official plugin is Go under
[`plugins/web/`](../web/). This crate is **not** a Cargo workspace member and is
not built by CI or `marqdo ext add web`.

Do not evolve features here — see [ext-web-go-rewrite.md](../../doc/design/ext-web-go-rewrite.md) C5 / ADR 0004.
