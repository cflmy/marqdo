## 1. 动机

无标记时，修饰语+函数名与函数名+实参都是词列，**无法消歧**。消歧标记必须来自 Marqdo 语法，**不能**依赖任一自然语言词法（「的」、形容词位置等）。

## 2. 形状

```text
修饰语… [函数名] 实参…
```

| 例子 | 含义 |
|------|------|
| `[问候] marqdo` | 调用 `问候`，位置实参 |
| `礼貌 [问候] marqdo` | 另加 `礼貌=True` |
| `正式 礼貌 [问候] marqdo` | `正式=True` `礼貌=True` |
| `[结账摘要] 品名="拿铁" 杯数=2` | 仅具名实参 |
| `[问候] ([格式化] `名字`)` | 嵌套：内层整段用 `()` |

旧形保留：`> 问候 …`、`**问候 …**`、`礼貌=True` 显式具名。

## 3. 与取元 / foreach

| 形状 | 语义 |
|------|------|
| `[X](Y)`（`]` 后**紧邻** `(`） | 取元 |
| `[X]`（`]` 后不是 `(`） | 函数名标记 |
| `- [X](Y)` | foreach |

## 4. 修饰语绑定

- `[` 前按空白切开；每段为标识（可 `` `名` ``）。
- 降为 `Named(名, Bool(true))`，再与 `]` 后实参合并。
- 与显式同名具名冲突 → 诊断。
- **核心不剥语言词缀**；形参叫 `礼貌` 则写 `礼貌 [问候]`。

## 5. AST

`CallExpr.pre_modifiers: Vec<String>`；求值/字节码在绑参前展开。
