## 三层

| 层 | 形态 | 角色 |
|----|------|------|
| **叙述面** | 无标记行 | 注释；内部标记无语义 |
| **Marqdo 可执行面** | 结构标记 + `*语句*` + `**返回**` | 本语言程序 |
| **外联面** | ` ```lang ` | 其它语言（FFI） |

输出属于可执行面里的**函数调用**（`> print …`），见 [keywords.md](keywords.md)。

---

## 语句 vs 返回 vs 输出

| 标记/形式 | 角色 | 是否架构级 |
|-----------|------|------------|
| `*…*` | 程序语句 | 是 |
| `**…**` | 返回值 | 是 |
| `> print …` | 打印副作用 | 否（内置函数） |
