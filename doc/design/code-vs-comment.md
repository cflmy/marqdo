## 三层

| 层 | 形态 | 角色 |
|----|------|------|
| **叙述面** | 成段注释（空行分段） | 注释；段内任意标记无语义 |
| **Marqdo 可执行面** | 结构标记 + `*语句*` + `**返回**` | 本语言程序 |
| **外联面** | ` ```lang ` | 其它语言（FFI） |

输出属于可执行面里的**函数调用**（`> print …`），见 [keywords.md](keywords.md)。

### 成段注释

- 以**空行**划分段落。  
- 段首行：首字符非标记 → 注释。  
- 段内续行：一律注释（即使以 `` ` `` / `-` 等开头）。  
- 叙述段与可执行代码之间**必须空一行**，否则 `> print` 等会被吞进注释段。

---

## 语句 vs 返回 vs 输出

| 标记/形式 | 角色 | 是否架构级 |
|-----------|------|------------|
| `*…*` | 程序语句 | 是 |
| `**…**` | 返回值 | 是 |
| `****` / 空粗体 | 空返回 + 结束函数体 | 是 |
| `> print …` | 打印副作用 | 否（内置函数） |
| 函数体 `---` / `***` | 结束函数体 | 是（边界） |
