---

## 三层

| 层 | 形态 | 角色 |
|----|------|------|
| **叙述面** | 普通段落 | 注释；行内 `` `名` `` 可声明/引用；装饰性 `**强调**` / `*斜体*` 不执行 |
| **Marqdo 可执行面** | 结构标记 + **`**代码**`** + **`*返回*`** | 本语言程序 |
| **外联面** | ` ```lang ` | 其它语言（FFI） |

输出属于可执行面里的**函数调用**（`> print …` / `**print …**`），见 [keywords.md](keywords.md)。

### 成段注释

- 以**空行**划分段落。  
- 段首行：首字符非标记 → 注释段；段内续行一律叙述（即使以 `` ` `` / `-` 开头）。  
- 段内仍扫描行内可执行位：`` `名` ``、代码形 `**…**`、返回形 `*…*`。  
- 叙述段与独立结构行（`>` `#`）之间**建议空一行**，否则 `> print` 可能被吞进注释段。

---

## 语句 vs 返回 vs 输出

| 标记/形式 | 角色 | 是否架构级 |
|-----------|------|------------|
| `**…**` | 代码（赋值 / 调用 / 表达式语句） | 是 |
| `*…*` | 返回值（整行、`返回*n*`、或表达式形） | 是 |
| `****` / 整行 `**` / `*None*` | 空返回 + 结束函数体 | 是 |
| `> print …` | 打印副作用 | 否（内置函数） |
| 函数体 `---` / `***` | 叙述分隔（跳过，**不**结束函数体） | 否 |
