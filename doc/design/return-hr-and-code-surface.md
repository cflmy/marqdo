## 决议

1. **`*…*` = 程序语句**。  
2. **`**…**` = 返回值**（架构级）。  
3. **输出**用内置函数 **`print`**（英文），不是粗体，不是中文名。  
4. **`---` / `***`**：可选框住分支/循环，不强制。  
5. **否决**：无标记行 = 默认代码。

详见 [keywords.md](keywords.md)、[markdown-mapping.md](markdown-mapping.md)。
