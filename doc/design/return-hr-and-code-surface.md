## 决议

1. **`*…*` = 程序语句**（与粗体不冲突）。  
2. **`**…**` = 返回值**（架构级）。  
3. **输出**不用粗体；用**关键字/函数**（如 `> 输出`）。输出不是语言架构一环，只是函数。  
4. **`---` / `***`**：建议用于**可选地框住**分支与循环，使版面清晰；**不强制**；若暂时不用，留待日后缺块级语法时再升级。  
5. **否决**：无标记行 = 默认代码（叙述会崩溃）。无标记保持注释。

曾讨论「粗体=一般程序面 / 分割线=返回」的路径，由本决议取代。权威条文见 [markdown-mapping.md](markdown-mapping.md)。
