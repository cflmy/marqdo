## 1. 块公式 `% marqdo: var=`

在 `$$…$$` 块内用 **TeX 行注释**声明绑定名（渲染通常不可见；运行时剥离后解析公式体）：

```markdown
$$
% marqdo: var=f
x^2 - 2
$$
```

- 指令：`% marqdo:` + 空白 + `var=<ident>`；未知键 → Error。  
- 可无前置 `` `f` = ``；若同时写空 RHS 与 `var=`，**同名允许、异名 Error**。  
- **保留**旧空 RHS + 后随 `$$`。  
- **不做**：行内 `$% marqdo:…$`；\`\`\` 代码围栏内语言注释 meta（本波）。  
- 行内公式继续传统绑定：`` `g` = $x+1$ ``（单 `$…$` → `formula`）或 `` `g` = $$x+1$$ ``。

无名叙述区 `$$` 仍仅展示；可执行区裸块既无空 RHS 又无 `var=` → Error。

## 2. 臂 / 循环体叙述（与函数体同权）

`parse_indented_body` 与函数体相同：消费 `` `名` `` / `**代码**` / `*返回*`；纯叙述跳过。  
斜体返回结束**当前臂或当前循环体**，不结束外层函数。

## 3. 循环头

| 面 | 写法 | 说明 |
|----|------|------|
| **推荐** | `- [项](xs)` / `- [`项`](`xs`)` | 支持嵌套 |
| 中文糖 | `- 对`xs`的每一项`项`` | 可选后缀「遍历」 |
| 英文糖 | `- for each `item` in `xs`` | 大小写不敏感 `for each` / `in` |

糖与链接头语义相同，可混用嵌套。

## 4. 分支条件行叙述

结构行仍以 `1.` / `2.` 开头。条件提取顺序：

1. 整段可解析为表达式（现状）；  
2. 行内粗体代码条件 `**`n` > 0**`；  
3. 剥离「当/若/如果/when/if」与「时/则」后，将「大于/小于/等于…」映射为运算符再解析。

else：`N. *`（可夹「否则」等叙述，条件位仍为 `*`）。  
禁止无标记自然语言整句当条件。
