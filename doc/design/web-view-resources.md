# View 中的请求资源

状态：请求资源已实现，后续旧站点迁移继续进行。遵循 ADR 0007；沿用五列 View、普通表值与 Resource，不增加 Markdown 标记或 frontmatter 方言。

view: main 仍只在启动时执行一次。它返回的结构保留为 View 节点，服务器在每次请求准备会话、路由参数和 CSRF 后渲染。普通 Markdown、控件和布局没有额外业务执行；只有 type=resource 的节点把 value 中的已声明 Resource 交给对应原生处理器。

Resource 的职责明确分开：data_query 查询当前应用数据库；form_ref 引用显式挂载的表单；view_navigation 根据当前会话筛选导航。document_head 是纯文档资源，只贡献 SEO 与原生资源链接，不需要请求上下文。它们不接受任意页面属性，不恢复 compose_*、页面变异链或 app.configure。结构和文字继续递归拆成组件及 Markdown 叶子。

启动阶段检查节点和资源契约，不查询数据库、不提交表单。请求渲染失败保留真实诊断。离线纯渲染遇到查询、表单与会话导航时明确要求上下文，不伪造空列表、登录状态或表单提交成功。纯页头资源与普通内容可以直接预览。

数据查询使用原有数据库资源与条件格式，路由参数来自实际请求。表单通过原有系统路由处理，字段、规则和提交资源保持一致，并传递真实 CSRF 与返回地址。导航的可见性不能替代服务端鉴权。资源绑定和监听仍是独立步骤。

验收覆盖启动无数据查询、请求间新增数据可见、完整正文与摘要区分、动态路由条件、登录前后导航、表单校验与提交、CSRF、未知资源失败，以及原有静态布局和浏览器用例。


已完成的实际证据：web-net-site 与 web-net-site-zh 使用这些资源完整迁移；web_handbook 在两个启动后端中验证请求期间的数据更新、表单错误重试、工具页与后台鉴权。原生 Go 测试验证结构装配不查询缺失数据库、未知资源失败、路径条件不污染保留定义、CSRF 拒绝与错误重试。browser_handbook.mjs 使用当前 WASM 验证连续回显、Enter 与空输入、实际提交与管理后台、窄屏布局。

入口与边界：component.resource（中文组件为“请求资源”，保留原“资源”作为脚本/样式引用）、data/view.query、form.reference 与 form.mount、component.navigation。表单挂载可显式保护实际系统提交路径，不能只保护展示页面。服务器回调继承授予的文件根，所选站点根只能收窄该范围；嵌套页面按统一站点根读取共享叶子，Endpoint 同样保留该上下文。


片段沿用 /_part/{slot}：递归选择唯一具名区域，在当前请求上下文中解析其资源；不会把源码当作片段返回。未声明 main 槽时保留整组节点作为 main 的兼容回退，其他未知槽返回 404，重复槽保留歧义诊断。容器遍历与完整渲染共享同一类型表，不进入资源私有数据。

检视的 registered 范围复用真实监听的注册过程，捕获处理器路径但不执行处理器；不会初始化数据库、重置会话或调用页面。metadata 范围仅扫描文件声明与运行时模板。两者明确区分，不能把目录扫描当成资源绑定已经完成的证据。监听前使用同一注册校验，冲突以诊断返回。系统和声明清单均去重并稳定排序。

页头资源保留现有五列 View：组件只安放 `_type=document_head` 的具型值，原生渲染在离线和真实页面中收集到 head，不在正文或片段中渲染占位。它只有 meta 与 links 两个领域字段，不接受任意页面属性、HTML 壳或应用配置。元数据沿用 key/value 表与原生 SEO 行为，链接复用普通 Document 的资源表及双语字段。相同链接按完整定义去重，同名元数据冲突在启动前报错。元数据按键稳定输出，保证同一结构的预览与服务一致。URL 只允许站内绝对路径与 http(s)，不读取或下载地址。charset、viewport、csrf-token 属于运行时，作者不能重声明。对应手册为 ext/web/head.mq.md 与 ext/web/页头.mq.md。
