# 内置关键字 / 函数：中英双名（草案）

| | |
|---|---|
| 状态 | **已定（已实现）** |
| 日期 | 2026-08-05 |
| 原则 | **无需导入**；中英为**同一语义的别名**，不是语言模式开关 |
| 相关 | [keywords.md](keywords.md) · [stdlib-i18n.md](stdlib-i18n.md) · [call-arguments.md](call-arguments.md) |

---

## 1. 动机

Marqdo 要中英文都能自然书写。标准库已约定「**库文件名区分语言**」（见 [stdlib-i18n.md](stdlib-i18n.md)）；对**不必导入**的一层——字面量关键字与极少内置函数——也要对等提供中文名。

正因为每增加一个内置名，就要同时维护中英（及日后更多语言）别名，所以：

> **关键字 / 内置必须少而精**——体积在「名字 × 语言」上放大，而不是在功能清单上堆满。

更多能力进可导入的 `lib/`，用中英**不同库文件、不同函数名**扩展，不膨胀解释器内核。

---

## 2. 分层（与标准库对齐）

| 层 | 是否导入 | 中英怎么区分 |
|----|----------|--------------|
| **L0 内核** | 否 | **同一文件内双名**：`print` ≡ `打印`；`True` ≡ `真` |
| **L1 标准库** | 是（`> lib/…`） | **不同文件**：`text.mq.md` vs `文本.mq.md`（见 i18n 草案） |

L0 **不做** `lang:`、不做「当前语言模式」；写英文名就用英文，写中文名就用中文，可在同一程序里混用。

---

## 3. 范围：哪些要双名

### 3.1 字面量 / 逻辑关键字（词法保留）

控制流仍靠 Markdown（`#` `1.` `-` `*` `**`），**不**为 `if`/`while`/`def` 做中英关键字。形参用 `+`。

| 英文 | 中文（提案） | 备注 |
|------|--------------|------|
| `True` | `真` | 布尔真 |
| `False` | `假` | 布尔假 |
| `None` | `空` | 空值 |
| `and` | `且` | 逻辑与 |
| `or` | `或` | 逻辑或 |
| `not` | `非` | 逻辑非 |

中英文名均**不可作变量名**（同一保留集）。

### 3.2 内置函数（可调用、无需导入）

**仅**下列核心五项做中英双名（与「少而精」一致）：

| 英文 | 中文（提案） | 作用 |
|------|--------------|------|
| `print` | `打印` | 写 stdout |
| `input` | `输入` | 读一行 |
| `len` | `长度` | 文本/表长度 |
| `str` | `文本` | 转为显示文本 |
| `int` | `整数` | 转为整数 |

形参名也提供中英别名（便于纯中文调用）：

| 英文形参 | 中文形参 | 用于 |
|----------|----------|------|
| `text` | `内容` | `print` / `打印` |
| `prompt` | `提示` | `input` / `输入` |
| `value` | `值` | `len`/`str`/`int` 及对应中文名 |

示例（等价）：

```markdown
> print text=Hello
> 打印 内容=你好

*`n` = > len `s`*
*`n` = > 长度 值=`s`*
```

### 3.3 明确不进 L0 双名表

下列若已在解释器中实现，视为**宿主原语 / 过渡 API**，**不**再批中文内核别名；应迁入或仅通过标准库暴露（中英分文件）：

| 英文名 | 去向 |
|--------|------|
| `type` | L1 或维持实现细节，不进「关键字最少集」宣传 |
| `trim` `split` `join` | L1：`lib/text.mq.md` / `lib/文本.mq.md` |
| `at` | L1：`lib/table.mq.md` / `lib/表.mq.md` |

这样 L0 公开面 ≈ **6 个关键字词 ×2 + 5 个函数 ×2**，而不是「每个工具函数都 ×2」。

## 4. 语义规则

1. **别名等价**：中英文名绑定同一实现；诊断文案可用英文稳定串（金样例已有），用户文档中英均可举例。  
2. **可混用**：同一文件可同时出现 `print` 与 `打印`、`True` 与 `真`。  
3. **遮蔽**：用户 `# 打印` 与 `# print` 均会遮蔽对应内置名（实现阶段应警告）。  
4. **大小写**：英文关键字保持 Python 风格（`True`/`False`/`None`）；中文无名感大小写问题。  
5. **扩语言**：日后日文等 → 再为 L0 增加第三个别名列；仍无「名字表」而非语言开关。标准库继续用**文件名**区分（见 i18n 草案）。

---

## 5. 与旧决议的关系

- 旧文「中文 `print` 废弃、统一为 `print`」：**废止**；改为正式双名 `print` / `打印`。  
- [keywords.md](keywords.md) 原则条「英文标识」改为「**内核双名；标准库分文件**」——实现阶段改正文。  
- 不引入中文控制流关键字（`如果`/`循环` 等）；分支用 `1.` …，循环用 `-`。

## 7. 实现备忘（暂不开发）

1. 词法 / 解析：字面量与 `and`/`or`/`not` 识别中文别名。  
2. 调用解析：内置表按别名归一到同一 `BuiltinId`。  
3. 形参绑定：`text`≡`内容`，`prompt`≡`提示`，`value`≡`值`。  
4. **不要**加 `lang:` 或全局「中文模式」。  
5. 与 [stdlib-i18n.md](stdlib-i18n.md) 一并落地时：先收束 L0 公开面，再铺 `lib/text` ↔ `lib/文本`。

---

## 8. 一句话

**内核：中英别名、无需导入、必须少；标准库：中英分文件、靠导入路径选择——这样 Marqdo 才能中英文通用而不把解释器撑爆。**
