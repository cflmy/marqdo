# Marqdo 语法映射 v0（Markup-as-Syntax）

| | |
|---|---|
| 状态 | 已定论（第一版宪法） |
| 日期 | 2026-08-04 |
| 相关 | [生成式 YAML/OKF 清单](generated-yaml-manifest.md) · [OKF 调研](../research/okf-and-marqdo.md) |

本文规定：Markdown **标记即 Marqdo 语法**。不在文中嵌入 `print` / `fn` / `import` 等外来关键字作为主路径。

---

## 1. 哲学

1. 源文件后缀 `.mq.md`：打开即渲染，运行即程序。
2. **行首符号**区分代码与注释；注释内一切标记无语义（无副作用强调写在注释行）。
3. **作用域唯一来源** = 标题 `#` 的个数；缩进不建立作用域。
4. 工程入口：`index.mq.md`（对齐 OKF 的 index 角色）。

---

## 2. 行首判别

对每一行：跳过前导空白，看第一个非空白字符。

| 情况 | 分类 |
|------|------|
| 无非空白，或首字符为普通文字（含 CJK） | **注释** — 忽略行内一切 Markdown 标记 |
| 首字符开启 Markdown/Marqdo 标记 | **代码** — 按标记解释 |

v0 标记字符至少包括：`#` `*` `>` `+` `-` `` ` `` `|`（表格）以及有序列表数字。

空行分隔结构，不执行。

---

## 3. 缩进政策

- **要识别**：CommonMark 列表嵌套缩进；行首先剥空白再认标记。
- **不要**：把缩进做成 Python 式作用域（作用域只认 `#` 层级）。
- **避免**：用 ≥4 空格缩进普通注释段（会变成 GFM 缩进代码块，破坏「打开即文档」）。v0 对此应警告或报错。

---

## 4. 映射总表

| 标记 | 语义 |
|------|------|
| `#` … `######` | 函数 / 代码块；层数 = 嵌套与作用域 |
| 函数头下 `-` 纯名 | 形参（每行一个） |
| 体内 `-` | **循环**（while / foreach） |
| 体内 `+` | **分支**（推荐） |
| 体内 `1.` `2.` … | **分支**（同样合法） |
| 分支臂整行恰为 `*` | else |
| `> 函数 形参=实参` | 调用 |
| frontmatter 中 `> path.mq.md` | **跨文件导入** |
| `**…**` | **输出**（stdout） |
| `*…*` | **返回值** |
| `` `name` `` | 变量；行首 `` `名` = … `` 为绑定 |
| `` `a` == `b` `` | 相等比较（比较不用单独 `=`） |
| GFM 表格 | 集合字面量 |
| 无标记行 | 注释 |
| ` ```lang ` 围栏 | 外联异种代码（FFI 细节后置） |

---

## 5. Frontmatter 元信息与跨文件

```markdown
---
title: 主程序
description: 示例入口
> utils.mq.md
> lib/math.mq.md
---
```

- 可含普通 YAML 键值（`title`、`description` 等）与 **`>` 导入行**（Marqdo 扩展；实现按行扫描，勿假定整块为纯 YAML）。
- `> path.mq.md`：导入目标文件顶层公有定义（顶层 `#`）；`##` 及更内层默认不导出。
- 路径相对当前文件。生成 OKF 依赖清单时可从这些行收集边。
- 正文 `> 名字 …` 为调用；frontmatter `> ….mq.md` 为文件导入（以路径/后缀区分）。

源 frontmatter = 文稿/代码元信息 + 人手声明的导入；工程级 OKF 目录仍由工具生成（见 [generated-yaml-manifest.md](generated-yaml-manifest.md)）。

---

## 6. 函数、作用域、提升

```markdown
# 输出函数
    - 输出内容

*`输出内容`*
```

- `#` 个数决定嵌套；内层可见外层；内层同名遮蔽外层。
- **定义顺序不影响可调用性**：Pass1 收集标题树，Pass2 再执行（提升）。
- **推荐**：非公有助手写成调用方下的 `##`，缩小作用域、减少泄露。
- **公有**：与入口同级的顶层 `#`，可供其它文件在导入后 `>` 调用。

推荐写法（调用可出现在内嵌定义之前，靠提升；调用写在 `# main` 下、`##` 之前，以免落入子节）：

```markdown
# main

> 输出函数 输出内容=Hello World!

## 输出函数
    - 输出内容

**`输出内容`**
```

（上例「输出函数」体用 `**…**` 做输出；若交回值则用 `*…*`。）

形参 `- 输出内容` 在体内以 `` `输出内容` `` 引用。

---

## 7. 输出与返回

| 构造 | 作用 |
|------|------|
| `**…**` | 输出到 stdout；可嵌 `` `变量` `` |
| `*…*` | 函数返回值；可嵌变量与表达式 |
| 注释行内的 `*` / `**` | 无语义 |

else 消歧：分支臂**第一行整行恰好一个** `*` → else。  
`*中间有内容*` → 返回，不是 else。

```markdown
# 加一
    - n

*`n` + 1*
```

绑定调用返回值（细写可后续收紧）：

```markdown
`y` = > 加一 n=3
```

---

## 8. 绑定与比较

| 写法 | 含义 |
|------|------|
| `` `x` = 1 `` | 绑定 |
| `` `x` == 1 `` | 相等比较 |
| `` `x` = `y` `` | 绑定（右值为引用） |

比较还支持 v0 最小集：`>` `<` `>=` `<=`（出现在臂头/while 头/表达式中时）。

---

## 9. 分支（`+` 或有序）

自上而下找第一个条件为真的臂执行；else 必须在最后。

```markdown
`x` = 0

+ `x` > 0
  **正数**
+ `x` < 0
  **负数**
+ *
  **零**
```

有序形式同等合法。v0 **不用** `*` 作为无序列表项目符（避免与 else、斜体冲突）。

---

## 10. 循环（仅 `-`）

| 项头形状 | 种类 |
|----------|------|
| `[元素](集合)` | foreach：链接文字=循环变量，目标=集合名 |
| 布尔条件 | while |
| 其它 | 编译错误 |

多项顶层 `-` = 依次执行多个循环。

```markdown
- [果](篮子)
  **今天吃`果`**

- `n` > 0
  **`n`**
  `n` = `n` - 1
```

---

## 11. 集合：GFM 表格

以 GFM 为准（纯 CommonMark 无表格）。须有表头行 + 分隔行。

```markdown
`篮子` =

| 果 |
|----|
| 苹果 |
| 梨 |
```

| 形状 | 含义 |
|------|------|
| 单列多行 | 序列 |
| 单行多列 | 元组 / 向量 |
| 多列多行 | 记录序列；表头=字段名，行进入 foreach 后字段名进作用域 |
| 仅表头无数据 | 空集合 |

`` `名` = `` 后紧跟表格块 → 表格为右值。单列/单行均合法。

---

## 12. 三种 `-` / 列表消歧

1. **形参**：紧跟函数标题，项为纯标识符名。  
2. **循环**：函数体内，项目符为 `-`，项头为链接或条件。  
3. **分支**：项目符为 `+`，或有序列表。

---

## 13. 求值入口

1. 加载 `index.mq.md` 与 frontmatter（含 `>` 导入）。  
2. Pass1：加载导入文件；收集所有函数定义树。  
3. Pass2：优先执行顶层 `# main`；若无，按文档序执行顶层可执行节点。  
4. 遇 `-` 列表 → 循环；遇 `+` / 有序 → 分支；遇 `>` / `**` / `*` / 绑定 / 表 → 相应动作。
