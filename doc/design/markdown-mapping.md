Markdown **标记即语法**。输出**不是**语言架构原语，而是普通函数（如 `> 输出`）。

---

## 1. 哲学

1. `.mq.md`：打开即文档，运行即程序。  
2. **无标记行 = 叙述注释**（内部任何标记无语义）。  
3. **可执行**靠标记：结构标记（`#` `>` `+` `-` 表…）与 **斜体语句** / **粗体返回**。  
4. 作用域 = `#` 层数；入口 = `index.mq.md`。

---

## 2. 行首判别

跳过前导空白后：

| 首字符 | 分类 |
|--------|------|
| 普通文字 / 空 | **注释** |
| 标记字符 | **代码** |

标记含：`#` `*` `>` `+` `-` `` ` `` `|`、有序数字、围栏 `` ` ``、以及函数体内的分割线 `---` / `***`（见 §11）。

---

## 3. 映射总表（v0.1）

| 标记 | 语义 |
|------|------|
| `#` … `######` | 函数；层数 = 作用域 |
| 函数头下 `-` 纯名 | 形参 |
| 体内 `-` | 循环 |
| 体内 `+` 或 `1.` | 分支 |
| 分支臂头整行恰为 `*` | else |
| `> 函数 形参=实参` | 调用（含内置 `输出`） |
| frontmatter `> path.mq.md` | 跨文件导入 |
| `*…*` | **程序语句**（绑定、表达式句、可写的调用句等） |
| `**…**` | **返回值**（架构级；函数结果） |
| 无标记行 | 注释 |
| GFM 表格 | 集合 |
| ` ```lang ` | 外联异种代码 |
| `---` / `***` | **可选**：框住分支/循环块（美化/分组；v0.1 不强制，见 §11） |

### 输出不是架构

| 错误（旧） | 正确（v0.1） |
|------------|--------------|
| `**Hello**` 表示打印 | `> 输出 内容=Hello`（或 prelude 等价名） |
| 输出与返回抢粗体 | 粗体只表示 **返回** |

`输出` 是与 `加一` 同类的函数，可内置、可用户实现。

---

## 4. 语句、返回、调用

### 程序语句（斜体）

```markdown
*`x` = 1*

*`y` = `x` + 2*
```

行首已是结构标记的构造（`#` `>` `+` `-` `|`）**不必**再包一层斜体；斜体用于「一般语句」槽位。也允许 `*> 输出 内容=hi*`，但不推荐。

### 返回值（粗体）

```markdown
# 加一
    - n

**`n` + 1**
```

### 输出（函数）

```markdown
# main

> 输出 内容=Hello World!
```

### else 与斜体消歧

- 分支臂**第一行整行只有一个** `*` → else。  
- `*中间有内容*` → 程序语句。  
- `**…**` → 返回（与 else 无关）。

---

## 5. Frontmatter 与跨文件

同 v0：文件头 `---` 对为元信息；其中 `> file.mq.md` 为导入。  
**函数体内的** `---` / `***` 不解释为 frontmatter（见 §11）。

---

## 6. 函数、作用域、提升

规则同 v0。推荐：

```markdown
# main

> 输出 内容=Hello World!

## 加问候
    - 谁

**你好，`谁`**
```

（需要打印时对返回值再 `> 输出`，或直接 `> 输出`。）

形参 `- 名` → 体内 `` `名` ``。

---

## 7. 绑定与比较

| 写法 | 含义 |
|------|------|
| `*`x` = 1*` 或行首 `` `x` = 1 `` | 绑定（两种均允许；实现应统一） |
| `` `x` == 1 `` | 相等比较 |

v0.1 **推荐**绑定写在斜体语句内，以保持「语句=斜体」一致；行首 `` ` `` 仍合法以便表格右值绑定。

---

## 8. 分支与循环

分支（`+` / 有序），循环（`-`），语义同 v0。臂体内打印改为调用 `输出`：

```markdown
*`x` = 0*

+ `x` > 0
  > 输出 内容=正数
+ `x` < 0
  > 输出 内容=负数
+ *
  > 输出 内容=零
```

```markdown
- [果](篮子)
  > 输出 内容=今天吃`果`
```

## 10. 求值入口

1. 加载 `index.mq.md` + 导入。  
2. Pass1 收集定义。  
3. Pass2 执行 `# main`。  
4. `*` 语句、`**` 返回、`>` 调用、`+`/`-` 控制流、表绑定按语义执行；`> 输出` 写 stdout。

---

## 11. 分割线框住分支/循环（可选、非强制）

允许用 `---` 或 `***` 将分支/循环块视觉框起来，便于阅读：

```markdown
---
+ `x` > 0
  > 输出 内容=正
+ *
  > 输出 内容=其它
---
```

| 约定 | 说明 |
|------|------|
| v0.1 | **不强制**；无框同样合法 |
| 语义 | 若使用，框内仍是原列表语义；分割线本身不产生控制流 |
| 保留 | 日后若缺「块」类关键语法，可升级分割线为强制块边界 |
| 消歧 | 仅文件开头的 `---` 对 = frontmatter；函数体内成对/成段的 `---`/`***` = 可选框 |

---
