# 第 6 章：函数

## 6.1 定义函数

在 Marqdo 中，函数用 `##`（及更深）标题定义：

```markdown
## 加一
    + `n`

*n + 1*
```

- `## 加一` —— 函数名
- `+ `n`` —— 参数
- `*n + 1*` —— 返回值（**斜体 = 返回**）

函数可以挂在 `# main` 之下作为嵌套函数，也可以作为顶层自由函数。

## 6.2 调用函数

使用 `>` 或粗体内调用（具名参数或位置参数）：

```markdown
# main

> greet who=World          # 具名参数
> greet World              # 位置参数

## greet
    + `who`

> print text=Hello, `who`!

*None*
```

### 具名 vs 位置

```markdown
> 问候 谁=Marqdo        # 具名：名=值
> 问候 Marqdo           # 位置：按形参顺序
```

二者可混用：位置实参按「尚未被具名绑定的形参」从左到右填充。

> 具名实参的值可以含空格，直到下一个 `名=` 边界；位置实参是单个词法单元（不含空格）。

### 方括号标记调用

可用 `[函数名]` 标出被调函数；`[` 前的裸词会变成布尔修饰（`名=True`）：

```markdown
> 问候 谁=小明 礼貌=True
礼貌 [问候] 小明
```

`]` 后**紧邻** `(` 是链接取元，不是调用（见[第 9 章](./09-集合.md)）。

## 6.3 参数与默认值

可选参数用 `=默认值`：

```markdown
## 问候
    + `谁`
    + `礼貌`=False

1. `礼貌`
  > print text=您好，`谁`！
2. *
  > print text=嗨，`谁`！
```

调用：

```markdown
> 问候 谁=小明
> 问候 谁=小明 礼貌=True
礼貌 [问候] 小明
```

## 6.4 返回值：`*…*`

用 `*…*` 返回表达式结果：

```markdown
## 加一
    + `n`

*n + 1*
```

调用并绑定结果：

```markdown
# main

**b = > 加一 n=1**
> print text=`b`        # 2
```

### 返回 None

推荐 `*None*` / `*无*`；也可整行空粗体 `**` 或 `****`：

```markdown
## 静默
    + `x`

*None*
```

### 字符串返回

```markdown
## 问候语
    + `谁`

*"你好，" + 谁 + "！"*
```

## 6.5 结束函数体

副作用函数用斜体返回收束，避免后续兄弟语句被吞进本函数：

```markdown
# main

> 问候 谁=World

## 问候
    + `谁`

> print text=Hello, `谁`!

*None*

## 下一个函数
...
```

> 单独一行的 `---` / `***` 只是 Markdown 分隔线（跳过），**不再**表示结束函数体。文件开头的成对 `---` 仍是 frontmatter。

## 6.6 完整示例

```markdown
# main

礼貌 [问候] Alice

## 问候
    + `谁`
    + `礼貌`=False

1. `礼貌`
  > print text=您好，`谁`！
2. *
  > print text=嗨，`谁`！

*None*

## 加一
    + `n`

*n + 1*
```

输出：

```text
您好，Alice！
```

## 6.7 函数嵌套（标题深度）

嵌套辅助函数用更深的标题：

```markdown
# main

> 处理 名字=小明

## 处理
    + `名字`

**上 = > 大写 文本=`名字`**
> print text=`上`

### 大写
    + `文本`

*> str `文本`*
```

> 深度约定：`##` 是 `#` 的子级，`###` 是 `##` 的子级……按标题深度嵌套。
