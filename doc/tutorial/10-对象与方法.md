# 第 10 章：对象与方法

Marqdo 用 `#` 标题定义**对象 / 类型**，用 `##` 定义其下的**方法**。这是一种轻量、可读的面向对象写法。

## 10.1 定义对象（类型）

`#`（恰好一层）定义一个对象 / 类型，其正文是**构造体**：

```markdown
# 大模型
    + `模型名`

*配置 = > json.parse text={"model":"gpt-4o-mini"}*
**配置**
```

- `# 大模型` —— 类型名
- `+ `模型名`` —— 构造参数
- 构造体执行后 `**…**` 返回一个 map，运行时写入 `_type` 字段，形成实例句柄

## 10.2 构造实例

调用类型名即可构造实例：

```markdown
# main

*模型 = > 大模型 模型名="gpt-4o-mini"*
```

## 10.3 定义方法

对象下的 `##` 标题是方法：

```markdown
# 计数器
    + `初始值`

*状态 = > json.parse text={"n":0}*
*状态 = > json.set map=`状态` key="n" value=`初始值`*
**状态**

## 加一

*n = > json.get value=`self` key="n"*
*n2 = n + 1*
*t = > json.set map=`self` key="n" value=`n2`*
**t**
```

方法体内自动绑定：

- `self`（英文）
- `自`（中文）

二者是同一个接收者，指向当前实例。

## 10.4 调用方法

### 独立 `>` 调用（接收者加反引号）

```markdown
*计数器 = > 计数器 初始值=3*
*新值 = > `计数器`.加一*
```

### `*…*` 段内调用（接收者裸名）

```markdown
*计数器 = > 计数器 初始值=3*
*新值 = > 计数器.加一*
```

> **重要**：在 `*…*` / `**…**` 段内，裸词是变量，所以**方法接收者不加反引号**：`*新值 = > 计数器.加一*`。而在独立 `>` 调用中，裸词是文本，接收者需要反引号：`> `计数器`.加一`。

## 10.5 完整对象示例

对象（`#`）定义在**顶层**，与 `# main` 平级：

```markdown
---
import json:lib/json.mq.md
---

# main

*c = > 计数器 初始值=5*
*ty = > json.get value=`c` key="_type"*
> print text=类型：`ty`

*c2 = > c.加一*
*n = > json.get value=`c2` key="n"*
> print text=加一后：`n`

# 计数器
    + `初始值`

*状态 = > json.parse text={"n":0}*
*状态 = > json.set map=`状态` key="n" value=`初始值`*
**状态**

## 加一

*n = > json.get value=`self` key="n"*
*n2 = n + 1*
*t = > json.set map=`self` key="n" value=`n2`*
**t**
```

输出：

```text
类型：计数器
加一后：6
```

## 10.6 继承：`# Child = > Parent`

```markdown
# Greeter

## hello
    + `who`

*msg = "Hello, `who`!"*
**msg**

# Loud = > Greeter

## hello
    + `who`

*msg = "HELLO, `who`!"*
**msg**
```

规则：

| 规则 | 说明 |
|------|------|
| 语法 | `# Child = > Parent` |
| `_type` | 构造后仍为**最具体子类名** |
| 方法查找 | 先子类 `##`，未命中再沿基类链；同名则子类覆盖 |
| 构造 | **不**隐式调用父构造（无 auto-super） |
| 多继承 | 不支持 |

### 显式调用父构造

子类需要父字段时，在子类正文首行显式调用父构造：

```markdown
# Child = > Parent
    + `name`

*self = > Parent name=`name`*
*self = > json.set map=`self` key="role" value="child"*
**self**
```

## 10.7 完整继承示例

```markdown
# main

*c = > Child name="Ada"*
*ty = > json.get value=`c` key="_type"*
*role = > json.get value=`c` key="role"*
> print text=`ty`
> print text=`role`

# Parent
    + `name`

*out = > json.parse text={"role":"parent"}*
*out = > json.set map=`out` key="name" value=`name`*
**out**

# Child = > Parent
    + `name`

*self = > Parent name=`name`*
*self = > json.set map=`self` key="role" value="child"*
**self**
```

输出：

```text
Child
child
```
