# 第 2 章：基本语法

## 2.1 文件结构

一个 `.mq.md` 文件由以下几部分组成：

1. **Frontmatter**（可选）：文件开头的成对 `---` 之间的元信息，如标题、导入。
2. **对象 / 函数定义**：以 `#` / `##` 开头的标题。
3. **叙述注释**：无标记的普通文字段落。
4. **可执行语句**：以标记开头的行。

```markdown
---
title: 我的程序
---

# main

这是叙述段落，整段都是注释。

> print text=Hello
```

## 2.2 代码 vs 注释：空行分段规则

Marqdo 的注释规则很特别：**无标记的叙述就是注释**，靠空行分段。

规则：

- 空行之后的第一行若**无标记**（普通文字）→ 这一段是**注释**。
- 注释段内的**每一行**（直到下一个空行）都是注释——即使它长得像代码。

```markdown
# main

这段注释里有一行看起来像代码，但它不会执行：
*not_executed = 1*
> print text=这也是注释

空行之后，代码开始运行：

> print text=这行会运行
```

> **注意**：叙述与可执行代码之间**必须空一行**。忘记空行会让本意是注释的文字被当作代码，或让代码被吞进注释段。

## 2.3 标记一览表

以下标记表示「这是代码」：

| 标记 | 含义 |
|------|------|
| `#` | 对象 / 类型（`# main` = 入口） |
| `##` … `######` | 函数 / 方法（嵌套按标题深度） |
| `` + `名` `` | 函数标题下的形参 |
| `1.` `2.` … | 条件分支 |
| `-` | 循环（遍历或 while） |
| `> 函数 参数` | 调用 |
| `*…*` | 程序语句（赋值 / 表达式） |
| `**…**` | 返回值 |
| `|` 开头的 GFM 表格 | 集合（列表 / 字典） |
| `---` / `***`（函数体内） | 结束函数体 |

## 2.4 标识符与反引号

Marqdo 中，**变量、参数名用反引号 `` ` `` 包裹**，这与 Markdown 的代码/链接语法脱钩，避免歧义。

```markdown
## 问候
    + `谁`

> print text=Hello, `谁`!
```

- `+ `谁`` —— 声明形参 `谁`
- `> print text=Hello, `谁`!` —— 在字符串中引用变量 `谁`

> **注意**：反引号规则有例外。在 `*…*`（斜体语句）和 `**…**`（粗体返回）内部，**裸标识符就是变量**，反引号可以省略（详见 [第 3 章](./03-变量与赋值.md)）。

## 2.5 字面量

Marqdo 的字面量：

| 类型 | 示例 | 说明 |
|------|------|------|
| 数字 | `1` `3.14` `-5` | 整数 / 浮点 / 负数 |
| 布尔 | `True` `False`（`真` `假`） | 布尔值 |
| 空值 | `None`（`空`） | 空值 |
| 文本 | `hello`（裸 token） | 无转义，按字面量 |
| 字符串 | `"Hello\n"` | 双引号，支持转义与变量插值 |
| 列表 | `[1, 2, 3]` | 通过表格构造 |
| 字典 | `{"a": 1}` | 通过表格构造 |

文本 vs 字符串的区别：

- **裸 token**（如 `hello`、`路径`）：按字面量，不转义，适合简短文本。
- **双引号字符串**：需要转义（`\n` 等）或嵌入变量时使用。

```markdown
> print text=Hello World!        # 裸 token，按字面量
*msg = "Hello, `name`!\n"*      # 字符串，可插值、可转义
```

## 2.6 关键字（不可作变量名）

以下单词是 Marqdo 的**保留关键字**，不能用作变量名：

| 英文 | 中文 | 含义 |
|------|------|------|
| `True` | `真` | 布尔真 |
| `False` | `假` | 布尔假 |
| `None` | `空` | 空值 |
| `and` | `且` | 逻辑与 |
| `or` | `或` | 逻辑或 |
| `not` | `非` | 逻辑非 |

**不要**尝试用 `if` / `else` / `while` / `for` / `def` / `return` ——它们不是关键字，也没有意义。

## 2.7 一个完整的例子

把学到的串起来：

```markdown
# main

这是一个完整示例：定义函数、调用、输出。

> 问候 谁=Marqdo

## 问候
    + `谁`

> print text=你好，`谁`！

---

## 加一
    + `n`

**n + 1**
```

运行输出：

```text
你好，Marqdo！
```
