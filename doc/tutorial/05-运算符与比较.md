# 第 5 章：运算符与比较

## 5.1 算术运算符

在 `*…*` 表达式内部：

```markdown
*a = 10*
*b = 3*

*sum = a + b*        # 13
*diff = a - b*       # 7
*prod = a * b*       # 30
*quo = a / b*        # 3.33…（浮点除法）
```

| 运算符 | 含义 |
|--------|------|
| `+` | 加法 / 拼接 |
| `-` | 减法 |
| `*` | 乘法 |
| `/` | 除法 |

> **注意**：在裸表达式里 `/` 是除法；但在**调用实参 / 参数默认值**中，不空格相连的 `a/b` 会被当作路径文本（详见[第 11 章](./11-模块与导入.md)）。

## 5.2 字符串拼接

`+` 也可以拼接字符串：

```markdown
*first = "Hello, "*
*second = "World!"*
*msg = first + second*
> print text=`msg`     # Hello, World!
```

> 在 `*…*` 内变量是裸名；若拼接的是字符串字面量，要加引号。

## 5.3 比较运算符

| 运算符 | 含义 |
|--------|------|
| `==` | 相等 |
| `>` | 大于 |
| `<` | 小于 |
| `>=` | 大于等于 |
| `<=` | 小于等于 |

```markdown
*n = 5*

1. `n` > 3
  > print text=大于 3
2. *
  > print text=小于等于 3
```

## 5.4 逻辑运算符

| 英文 | 中文 | 含义 |
|------|------|------|
| `and` | `且` | 逻辑与 |
| `or` | `或` | 逻辑或 |
| `not` | `非` | 逻辑非 |

```markdown
*age = 20*
*has_id = True*

1. `age` >= 18 and `has_id`
  > print text=可以进入
2. *
  > print text=不能进入
```

## 5.5 布尔值

布尔值字面量：`True` / `False`（中文 `真` / `假`）。

```markdown
*is_admin = False*

1. `is_admin` == True
  > print text=管理员
2. *
  > print text=普通用户
```

也可以直接用布尔变量作条件：

```markdown
*flag = True*

1. `flag`
  > print text=为真
2. *
  > print text=为假
```

## 5.6 完整示例

```markdown
# main

*score = 85*
*passed = score >= 60*
*bonus = passed and score >= 80*

> print text=及格：`passed`
> print text=优秀：`bonus`
```

输出：

```text
及格：True
优秀：True
```
