# Marqdo 语法教程

> **代码即文档，文档即代码。** Marqdo 把 Markdown 的标记当作编程语法：同一个 `.mq.md` 文件既是给人读的文稿，也是给机器跑的程序。

本教程面向所有读者——从没写过代码的文档作者，到熟悉 Python 的工程师。每章都配有可直接运行的完整示例。

## 快速示例

一个完整的 Marqdo 程序长这样：

```markdown
# main

> 问候 谁=World

## 问候
    + `谁`

> print text=Hello, `谁`!

---

## 加一
    + `n`

**n + 1**
```

- `# main` —— 入口
- `> 问候 谁=World` —— 调用函数（具名参数）
- `## 问候` + `+ `谁`` —— 定义函数及其参数
- `> print text=…` —— 输出（副作用，是普通函数）
- `**n + 1**` —— 返回值
- 单独一行 `---` —— 结束函数体

## 运行方式

```bash
marqdo run 文件.mq.md
```

更多运行、浏览、调试、发布方式见 [第 13 章](./13-命令行工具.md)。
