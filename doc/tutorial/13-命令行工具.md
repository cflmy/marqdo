# 第 13 章：命令行工具

Marqdo 提供一组命令行工具，覆盖运行、浏览、调试、发布全流程。

## 13.1 命令总览

```text
marqdo --version                 # 查看版本
marqdo run 文件.mq.md            # 运行程序
marqdo view 路径                 # 文档浏览器（默认端口 7429）
marqdo debug 路径                # 调试界面（默认端口 7430）
marqdo catalog 路径 -o 目录      # 生成 OKF 风格清单
marqdo sync 路径 -o 目录         # catalog 的别名
marqdo ext list                  # 列出扩展
marqdo ext add llm|agent|web|quantum
marqdo ext remove llm|agent|web|quantum
```

## 13.2 运行程序：`run`

```bash
marqdo run hello.mq.md
```

指定后端（树遍历默认 / 字节码）：

```bash
marqdo run hello.mq.md --backend bytecode
```

### 错误诊断

诊断信息格式：`path:line:col: message`（行 / 列从 1 开始）。

```text
error: hello.mq.md:5:1: undefined variable `x`
```

根据 `path:line:col` 定位并修复，再重新运行直到退出码为 0。

## 13.3 文档浏览器：`view`

`view` 启动一个本地文档浏览器，把 `.mq.md` 渲染成可浏览的文档站：

```bash
marqdo view public --no-open
```

浏览器打开后可看到：

- Structure（结构）
- 函数大纲 / 搜索
- Execution（执行）
- Variables（变量浮窗）

## 13.4 调试器：`debug`

```bash
marqdo debug public --no-open
```

提供独立调试页面，支持：

- 断点
- 单步执行
- 局部变量查看

## 13.5 生成清单：`catalog` / `sync`

从源码派生 OKF 风格的 YAML / Markdown 知识包：

```bash
marqdo catalog public -o .marqdo
# 或
marqdo sync public -o .marqdo
```

| 参数 | 默认 | 说明 |
|------|------|------|
| `PATH` | `.` | 工程根或含 `.mq.md` 的目录 |
| `-o` / `--out` | `.marqdo` | 输出目录 |

产物：`catalog.yaml`、`index.md`、`modules/*.md` 等。

## 13.6 扩展管理：`ext`

```bash
marqdo ext list
marqdo ext add llm
marqdo ext add agent
marqdo ext remove llm
```

扩展默认安装到 `~/.marqdo/ext`（或 `MARQDO_EXT`）。

## 13.7 标准库与可执行文件解析

- **标准库**：内置于二进制；磁盘 `lib/` 或 `MARQDO_LIB` 可覆盖。
- **库路径解析**：`MARQDO_LIB` → 当前目录 `lib/` → 可执行文件旁 `lib/`。
