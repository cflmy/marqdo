# 第 12 章：标准库

Marqdo 内置函数无需导入即可使用；更丰富的能力通过导入 `lib/` 模块获得。

## 12.1 内置函数（无需导入）

| 英文 | 中文 | 作用 |
|------|------|------|
| `print` | `打印` | 写标准输出（参数 `text` ≡ `内容`） |
| `input` | `输入` | 读一行（参数 `prompt` ≡ `提示`） |
| `len` | `长度` | 文本 / 集合长度（参数 `value` ≡ `值`） |
| `str` | `文本` | 转为显示文本（参数 `value` ≡ `值`） |
| `int` | `整数` | 转为整数（参数 `value` ≡ `值`） |

```markdown
# main

> print text=Hello

*s = "Marqdo"*
*n = > len value=`s`*
> print text=长度：`n`
```

## 12.2 标准库模块

导入一个 `lib/` 文件，使用**该文件**的函数名：

| 英文导入 | 中文导入 | 典型功能 |
|----------|----------|----------|
| `lib/text.mq.md` | `lib/文本.mq.md` | 文本处理（去空白、拆分、拼接） |
| `lib/table.mq.md` | `lib/表.mq.md` | 列表 / 字典元素更新 |
| `lib/fs.mq.md` | `lib/文件.mq.md` | 文件系统 |
| `lib/sys.mq.md` | `lib/系统.mq.md` | 进程 / 当前目录 / 加载环境变量 |
| `lib/plugin.mq.md` | `lib/插件.mq.md` | 加载原生 ABI 插件 |
| `lib/time.mq.md` | `lib/时间.mq.md` | 时间 / 格式化 |
| `lib/net.mq.md` | `lib/网络.mq.md` | HTTP(S) |
| `lib/json.mq.md` | — | JSON 解析 / 序列化 / 取元 |
| `lib/math.mq.md` | `lib/数学.mq.md` | 数值、三角函数、随机、公式、绘图 |
| `lib/foreign.mq.md` | `lib/外联.mq.md` | 运行异种语言代码块 |

> **语言一致性**：导入英文库文件，就用其英文 API；导入中文库文件，就用其中文 API。不要混用语言。

## 12.3 JSON 模块示例

```markdown
---
import json:lib/json.mq.md
---

# main

*obj = > json.parse text={"a":1}*
*a = > json.get value=`obj` key="a"*
> print text=`a`           # 1

*out = > json.stringify value=`obj`*
> print text=`out`         # {"a":1}
```

`json` 常用函数：

| 函数 | 作用 |
|------|------|
| `json.parse` | 解析 JSON 文本 |
| `json.stringify` | 序列化为 JSON 文本 |
| `json.get` | 取字段（键） |
| `json.keys` | 取所有键 |
| `json.set` | 设字段 |
| `json.append` | 向列表追加 |

## 12.4 文本模块示例

```markdown
---
import text:lib/text.mq.md
---

# main

*parts = > text.str_split s="a,b,c" sep=","*
> print text=`parts`

*joined = > text.str_join xs=`parts` sep="-"*
> print text=`joined`      # a-b-c
```

## 12.5 数学模块：公式与绘图

```markdown
---
import math:lib/math.mq.md
---

# main

*值 = > math.num value=3.5*
> print text=`值`
```

公式绑定：

```markdown
---
import math:lib/math.mq.md
---

# main

`f` =
$$
x^2 - 2
$$

*_svg = > math.plot formula=`f` var=x min=-3 max=3*
```

空 RHS 赋值 + 后随 `$$…$$` 绑定一个公式值。

## 12.6 官方扩展库（`ext/`）

扩展库不是 stdlib，需安装：

```bash
marqdo ext list
marqdo ext add llm
marqdo ext add agent
marqdo ext add web
marqdo ext add quantum
```

导入仍写 `import …:ext/….mq.md`：

```markdown
---
import llm:ext/llm.mq.md
---

# main

*模型 = > llm.llm model="gpt-4o-mini"*
```

| 扩展 | 功能 |
|------|------|
| `llm` | 大模型对话 |
| `agent` | 文档驱动的智能体框架 |
| `web` | Web 应用 |
| `quantum` | 量子电路模拟 |

## 12.7 查看库的精确 API

打开 `lib/` 或 `ext/` 下对应的 `.mq.md` 文件，即可看到精确的 `##` / `#` 名称和参数。例如 `lib/json.mq.md` 顶层就是 `## parse`、`## stringify` 等。
