# 第 4 章：输出与输入

## 4.1 输出：`print` / `打印`

`print`（中文 `打印`）是内置函数，用于向标准输出写一行文本。**输出不是 `**粗体**`**——粗体是返回值，不是打印。

```markdown
# main

> print text=Hello World!
```

中英等价：

```markdown
> 打印 内容=你好，世界！
```

| 英文 | 中文 | 参数 |
|------|------|------|
| `> print text=…` | `> 打印 内容=…` | `text` ≡ `内容` |

### 输出变量

独立 `>` 调用中，变量用反引号：

```markdown
*x = 42*
> print text=`x`       # 输出：42
```

### 输出拼接

```markdown
*name = "Marqdo"*
> print text=欢迎使用 `name`！
```

## 4.2 输入：`input` / `输入`

`input`（中文 `输入`）读取一行用户输入：

```markdown
# main

> input prompt=你叫什么名字？
```

| 英文 | 中文 | 参数 |
|------|------|------|
| `> input prompt=…` | `> 输入 提示=…` | `prompt` ≡ `提示` |

### 读取并保存输入

```markdown
# main

*name = > input prompt="请输入名字："*
> print text=你好，`name`！
```

> `input` 的 `prompt` 参数可省略（缺省）。

## 4.3 完整示例：一个问答程序

```markdown
# main

这是一个人机问答程序。

*name = > input prompt="你叫什么名字？\n"*
> print text=你好，`name`！

*age = > int value=`age_input`*
```

> **注意**：上面的示例为了展示 `int` 用法，`age_input` 尚未定义。实际中你需要先从 `input` 得到字符串，再用 `int` 转换。完整可运行版本：

```markdown
# main

*name = > input prompt="你叫什么名字？\n"*
> print text=你好，`name`！

*age_str = > input prompt="你几岁？\n"*
*age = > int value=`age_str`*
*next_age = age + 1*
> print text=`name`，你明年 `next_age` 岁。
```
