# 第 11 章：模块与导入

大型项目需要把代码拆成多个文件。Marqdo 用 **frontmatter 导入**和**点号寻址**组织模块。

## 11.1 Frontmatter 元信息

文件开头的成对 `---` 之间是 frontmatter，存放元信息（标题、描述、导入）：

```markdown
---
title: 我的程序
description: 描述文字
---
```

## 11.2 导入文件：`import 绑定:路径.mq.md`

```markdown
---
import text:lib/text.mq.md
import time:lib/time.mq.md
---
```

- `text` —— 绑定名（本地库名）
- `lib/text.mq.md` —— 目标文件路径

导入后得到一个**库（模块）绑定**，成员**不会**倒进全局。

中文等价：`导入 文本:lib/文本.mq.md`。

## 11.3 点号寻址调用：`库.成员`

导入后用裸点号路径调用库成员：

```markdown
---
import time:lib/time.mq.md
import json:lib/json.mq.md
---

# main

*t = > time.now_unix*
*s = > time.format unix=`t` pattern="%Y-%m-%d"*
> print text=`s`
```

- `time.now_unix` —— 调用 `time` 库的 `now_unix` 函数
- `time.format` —— 调用 `time` 库的 `format` 函数

**库名不是变量**：路径段是裸标识符，不加反引号。

## 11.4 三段路径：`库.类型.方法`

```markdown
---
import agent:ext/ai/agent.mq.md
---

# main

*助手 = > agent.agent model="gpt-4o-mini"*    # 库 → 类型：构造
```

`agent.agent` —— `agent` 库中的 `agent` 类型（构造）。

## 11.5 短名：`import 绑定:库.成员`

把库路径成员绑为本地短名：

```markdown
---
import time:lib/time.mq.md
import fmt:time.format
---

# main

*t = > time.now_unix*
*s = > fmt unix=`t` pattern="%Y-%m-%d"*
```

`fmt` 现在是 `time.format` 的短名。

## 11.6 方法调用 vs 库路径（Python 统一命名空间）

对裸点号 `a.b`，规则是：

- 若 `a` 是当前作用域的**局部变量** → **方法调用**（`a` 为接收者）
- 否则 → **库路径**

| 写法 | 含义 |
|------|------|
| `time.parse` | 库路径（裸名，第一段非变量） |
| `` > `助手`.step `` | 独立 `>` 调用：实例方法（接收者反引号） |
| `*回复 = > 助手.step …*` | `*…*` 段内：`助手` 是变量 → 实例方法；否则 → 库路径 |

```markdown
---
import agent:ext/ai/agent.mq.md
---

# main

*助手 = > agent.agent model="gpt-4o-mini"*
*out = > 助手.step task="你好"*      # 助手是变量 → 方法调用
```

## 11.7 完整示例：多模块程序

假设项目结构：

```text
project/
├── main.mq.md
├── lib/
│   ├── 数学.mq.md
│   └── 问候.mq.md
```

`lib/数学.mq.md`：

```markdown
## 加倍
    + `n`

**n * 2**
```

`lib/问候.mq.md`：

```markdown
## 你好
    + `谁`

> print text=你好，`谁`！
```

`main.mq.md`：

```markdown
---
import 数学:lib/数学.mq.md
import 问候:lib/问候.mq.md
---

# main

*结果 = > 数学.加倍 n=21*
> print text=`结果`

> 问候.你好 谁=世界
```

输出：

```text
42
你好，世界！
```

## 11.8 库路径解析

`lib/…` 按以下顺序解析：

1. 环境变量 `MARQDO_LIB`
2. 当前目录下的 `lib/`
3. `marqdo` 可执行文件旁边的 `lib/`（及几个父目录）

官方扩展（`ext/`）用 `marqdo ext add llm|agent|web|quantum` 安装，导入仍写 `import llm:ext/llm.mq.md` 等。
