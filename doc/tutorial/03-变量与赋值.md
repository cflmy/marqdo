# 第 3 章：变量与赋值

## 3.1 什么是变量

变量是给数据起的一个名字。Marqdo 中，变量在**斜体语句 `*…*`** 中通过 `=` 绑定：

```markdown
*x = 1*
*name = "Marqdo"*
*ok = True*
```

> **重要**：在 `*…*` / `**…**` 内部，**裸标识符就是变量**——不需要反引号。这是 Marqdo 的关键约定。

## 3.2 绑定的三种写法

### 写法一：斜体语句 `*…*`（推荐）

```markdown
*x = 1*
*y = x + 2*
```

这是最常用的绑定方式。裸标识符就是变量。

### 写法二：行首反引号绑定（无 `*…*`）

```markdown
`x` = 1
```

不带 `*…*` 的绑定，变量名**需要反引号**。常用于绑定集合（表格）或公式：

```markdown
`篮子` =

| 果 |
|----|
| 苹果 |
```

### 写法三：绑定调用结果

```markdown
*len_s = > len value="hello"*
```

`*…*` 内用 `= >` 表示「把调用结果赋给变量」。

## 3.3 引用变量

在 `*…*` 内部，直接写变量名即可：

```markdown
*a = 5*
*b = a * 2*
> print text=`b`     # 独立 > 调用中，变量要反引号
```

> **关键区别**：在**独立 `>` 调用**（如 `> print …`）里，裸词是**文本**，所以引用变量要加反引号：`> print text=`b``。而在 `*…*` / `**…**` 内，裸词是**变量**：`*b = a * 2*`。

## 3.4 字符串与插值

### 双引号字符串

```markdown
*msg = "Hello, World!"*
```

### 转义字符

| 转义 | 含义 |
|------|------|
| `\n` | 换行 |
| `\t` | 制表 |
| `\r` | 回车 |
| `\\` | 反斜杠 `\` |
| `\"` | 双引号 `"` |
| `\'` | 单引号 `'` |
| `\xHH` | 十六进制字符（如 `\x22` → `"`） |
| `\u{...}` | Unicode 码点（如 `\u{4e2d}` → `中`） |

未知转义（如 `\q`）**按字面保留**（`\q` → `\q`），不报错。

### 变量插值

字符串内用 `` `变量` `` 插值：

```markdown
*name = "Marqdo"*
*msg = "Hello, `name`!"*
> print text=`msg`     # 输出：Hello, Marqdo!
```

## 3.5 完整示例

```markdown
# main

*name = "Alice"*
*age = 30*
*next_age = age + 1*

> print text=名字：`name`
> print text=明年：`next_age` 岁

*msg = "你好，`name`！你明年 `next_age` 岁。"*
> print text=`msg`
```

输出：

```text
名字：Alice
明年：31 岁
你好，Alice！你明年 31 岁。
```
