# 第 7 章：条件分支

## 7.1 基本分支：`1.` `2.` …

Marqdo 用**有序列表** `1.` `2.` `3.` … 表达条件分支：

```markdown
# main

*n = 5*

1. `n` > 0
  > print text=正数
2. `n` < 0
  > print text=负数
3. *
  > print text=零
```

- `1. 条件` —— 第一个分支（条件为真时执行其下的缩进行）
- `2. 条件` —— 第二个分支
- `3. *` —— else 臂（`N. *` = 否则）

输出：

```text
正数
```

## 7.2 else 臂：`N. *`

在 `1.` 之后的任意臂上，**整行恰为 `*`** 表示 else：

```markdown
*age = 15*

1. `age` >= 18
  > print text=成年
2. *
  > print text=未成年
```

## 7.3 布尔分支

```markdown
*is_admin = False*

1. `is_admin`
  > print text=管理员
2. *
  > print text=普通用户
```

## 7.4 多条件分支

```markdown
*score = 85*

1. `score` >= 90
  > print text=优秀
2. `score` >= 80
  > print text=良好
3. `score` >= 60
  > print text=及格
4. *
  > print text=不及格
```

## 7.5 逻辑组合条件

```markdown
*age = 25*
*has_id = True*

1. `age` >= 18 and `has_id`
  > print text=可以进入
2. *
  > print text=不能进入
```

## 7.6 多个独立分支语句

**一条分支语句 = 从 `1.` 起、序号递增的一段有序列表。** 同级缩进上**再次出现 `1.`** 会开启**下一条**独立分支语句：

```markdown
# main

*a = True*
*b = False*

1. `a`
  > print text=A 为真
2. *
  > print text=A 为假

1. `b`
  > print text=B 为真
2. *
  > print text=B 为假
```

这是**两次独立判断**，不是「四个臂的一个分支」。输出：

```text
A 为真
B 为假
```

> 臂序号在同一分支内递增（`1.` → `2.` → `3.` …）；不要在同一分支中途把序号重置为 `1.`。

## 7.7 完整示例：成绩评级

```markdown
# main

*score = 72*

1. `score` >= 90
  > print text=评级：A
2. `score` >= 80
  > print text=评级：B
3. `score` >= 70
  > print text=评级：C
4. `score` >= 60
  > print text=评级：D
5. *
  > print text=评级：F
```

输出：

```text
评级：C
```
