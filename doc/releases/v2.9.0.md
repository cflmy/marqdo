# Marqdo v2.9.0 · Full Release / 正式完整版本

## 核心更新 · Highlights

Marqdo 2.9.0 将 Markdown 原生可执行知识库推进为 **可验证知识编译器（Verified Knowledge Compiler）**。这不是全语言自动证明工具：Lean 4 仅证明明确支持的逻辑模型，系统继续保存来源、信任边界与失效原因。

- **统一模块契约**：`knowledge compose` 支持静态纯函数的形参、整数表达式、连续赋值、穷尽分支、多次函数调用和多级模块调用 DAG。
- **独立 Lean 模块证明**：每个受支持函数由源码生成可检查模块；调用方导入被调方定理，而不是将定理声明自动当成公理。
- **知识锚点**：带标记步骤和定理声明具有稳定身份；`[]()` 用于可寻址引用，绝不自动赋予执行权。
- **可信证据**：`model_proved`、`proved`、`tested`、`assumed`、`unknown`、`refuted`、`stale` 严格区分；证明收据绑定源码与依赖闭包，支持失效检测和独立重放。
- **兼容性**：旧版 `marqdo prove`、`marqdo call`、知识视图和旧式简单组合证书继续兼容，Rust 与 Lean 差分测试保护语义边界。

**EN:** Marqdo 2.9.0 introduces a Verified Knowledge Compiler for native Markdown knowledge artifacts, stable anchors, source-derived bounded assume/guarantee composition, and independently replayable Lean 4 certificates. The implementation **does not** claim universal program correctness: supported Lean `Int` theorems are labeled `model_proved` until a runtime semantic correspondence is established.

## 可信边界 · Verification boundaries

Lean 自动组合仅适用于源码可精确翻译的无副作用、静态纯整数模型片段；有界整数溢出、动态 `number` / `Formula`、插件效应、未知异常、循环和递归不会自动升级为已证明。前置条件未证明、源码漂移、证书篡改、Lean 不可用或超出支持范围时，必须拒绝出证或明确返回未验证状态。

Formal logic proves **properties of the declared model**, not empirical facts or the entire runtime. External API responses, quantum hardware measurements and agent behavior require explicit experiment/test/provenance evidence. See [design decision](../design/verified-knowledge-compiler-boundaries.md).

## 使用 · Usage

```sh
marqdo knowledge .
marqdo knowledge compose --strict --json .
marqdo knowledge proof-deps --verify --json .
marqdo knowledge replay <path/to/composition-certificate.json> --json .
```

A `model_proved` certificate is **not** an unconditional authorization to call plugins or execute side effects.

## 完整发行产物 · Full distribution

The `v2.9.0` full packaging workflow produces:
- Windows x86_64 native CLI (standalone EXE and bundled ZIP);
- Linux x86_64 CLI+libraries bundle;
- standard library ZIP, source ZIP and static user-site ZIP;
- editor `marqdo-2.9.0.vsix` from the independent editor branch;
- both Windows and Linux official native plugin packs, plus the versioned extension source pack when `ext/VERSION` matches `2.9.0`.

**Release completion is determined by actual CI artifacts and publication evidence, not by this note.** In addition to GitHub assets the repository's [release handbook](../../skills/marqdo-release/index.mq.md) requires CDN/R2 byte parity and Ubuntu PPA publication/apt verification. Missing credentials, failed cross-platform builds or unverified publication channels must be reported as incomplete; never invent hashes or success.

## 质量验收 · Quality gates

- `modular-proof-smoke` — actual Lean kernel-checkable intermodule source contracts, negative/stale replay tests.
- `knowledge-proof-full-gate` — knowledge, semantic-IR, proof corpus and interpreter/Lean differential tests.
- `executable-knowledge` — backward compatibility and knowledge execution tests.
- `Release` — verify both platform assets were built from the exact immutable tag.
- `release-v2.9` gate — verify metadata, build/test on main and create the immutable tag only when checks pass.

Version 2.9.0 is a **scoped Verified Knowledge Compiler**, not a theorem that every program or scientific experiment is automatically correct.
