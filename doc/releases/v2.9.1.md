# Marqdo v2.9.1 · Library Feature-Gate Fix / 库可选特性修复

## 核心更新 · Highlights

Marqdo 2.9.1 修复 2.9.0 引入的库构建回归：`sema::ir` 在输出 `proof-index.json` 与 `proof-obligations.json` 时无条件使用 `knowledge` 模块，而该模块此前只在 `cli` 特性下编译，导致以 `default-features = false` 依赖本库的下游工程出现 `E0433: could not find knowledge in the crate root`。

**EN:** Marqdo 2.9.1 fixes a library-build regression introduced in 2.9.0. `sema::ir` unconditionally emits `proof-index.json` and `proof-obligations.json` through the `knowledge` module, but that module was gated on the `cli` feature, so downstream crates depending on the library with `default-features = false` failed with `E0433: could not find knowledge in the crate root`.

- `knowledge` 现在是核心编译器的一部分，不再由 `cli` 特性门控；CLI 二进制仍由 `required-features = ["cli"]` 约束。
- 新增 `feature-matrix` CI：分别用无默认特性、仅 `cli`、默认特性检查库构建，防止特性门控再次回归。
- 没有运行时语义、文稿格式、插件 ABI（v2）或证明证书格式的变化。

## 兼容性 · Compatibility

- 2.9.0 的 `.mq.md` 文稿、原生插件（ABI v2）和知识证明证书保持兼容，无需迁移。
- 下游库可继续使用 `default-features = false`；2.9.0 期间为绕过该回归而启用的 `cli` 特性可以撤销。
- 不可变标签 `v2.9.0` 保持不变，本次是同一主线的补丁版本。

## 验证 · Verification

- `cargo check --locked --lib --no-default-features`、`--no-default-features --features cli` 与默认特性三种配置均通过。
- `cargo test --locked` 全量通过（Linux x86_64 本地环境）。
- 下游验证：qdagent 原生插件恢复 `default-features = false` 后重新编译通过，`cargo test` 17 项通过。
- 限制：Windows 与 Linux 发布产物由标签触发的 Release 流水线构建；本地验证不代表其他平台已通过，最终以实际流水线结果和资产校验为准。

## 完整发行产物 · Full distribution

The `v2.9.1` full packaging workflow produces:
- Windows x86_64 native CLI (standalone EXE and bundled ZIP);
- Linux x86_64 CLI+libraries bundle;
- standard library ZIP, source ZIP and static user-site ZIP;
- editor `marqdo-2.9.1.vsix` from the independent editor branch;
- both Windows and Linux official native plugin packs, plus the versioned extension source pack when `ext/VERSION` matches `2.9.1`.
