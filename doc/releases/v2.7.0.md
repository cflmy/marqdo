# Marqdo 2.7.0

本次 full 发布把源码手册落到实际开发与用户站点：文件操作、开发检查、构建与发版阶段可通过 marqdo call 执行；站点以递归组件、普通 Markdown 和明确的原生资源表达页面与行为。

This full release makes executable source handbooks practical for development and user sites. Native file tools and callable development/release tasks replace generated orchestration programs. Recursive View components preserve ordinary Markdown content and explicit runtime resources.

## 亮点 / Highlights

- 开发与发版 SKILL 路由到可执行 .mq.md 手册；文件读取、审阅、摘要校验和写入使用固有标准库。工程插件承担有界进程、私密认证、压缩格式和实际编译器检查边界，流程不依赖 Python 编排。
- Literal JSON file/stdin CLI arguments preserve quotes, newlines and dollar-prefixed text. --require-ok makes a failed Result stop external automation; saved call sessions retain literal argument semantics.
- 中英文网络站点与完整用户站点改为递归 View 布局、Markdown 内容、当前数据查询、表单、真实会话导航与鉴权资源。原有配色、字体、布局、文章详情和管理功能保留。
- Pure document_head resources carry SEO and resource links into the actual head. Request-time query/form/navigation resources preserve the existing five-column View schema, source context and explicit effect boundaries. Prepared-app inspection follows the real registrar without executing handlers.
- 原生 SQLite 初始化按实际站点授权根定位，保留已有业务记录；嵌套 Document 与 Endpoint 使用一致的站点根。修复表单校验重试中的 CSRF、成功跳转以及嵌套片段选择与路由检查。
- The browser bridge supports typed nested list/control records. The maintained browser-app demonstrates duplicate-safe identities, literal text, truthful storage/network feedback, real history and local WebSocket echo with no authored business JavaScript.
- 移除与语言仓库无关的暗恋工程及过时的独立浏览器演示；底层 WASM 冒烟夹具与公共回归保留。维护入口收敛到实际可运行的工程。

## 核心表面与兼容边界 / Core surface and boundaries

核心构造仍为 19 个，没有新增 Markdown 标记。改动集中在已有标记解析、CLI 参数传送、Runtime / Document 资源及工程工具；原生插件仍具有调用用户的操作系统权限，--fs-root 不把外部进程变成沙箱。显式 raw HTML 兼容出口不等同于不可信内容清理。编译检查与叙述比例检查不能单独证明运行或视觉正确。

The core surface remains 19 constructs. Native-only filesystem, process and authenticated service capabilities do not become browser WASM capabilities. Atomic file replacement is not a multi-file transaction, and digest preflight is not a kernel compare-and-swap. Deployment credentials remain in private stores.

## 安装与使用 / Installation and use

下载对应平台的完整 ZIP，解压后使用其中的 CLI 与 lib/ext。已有 CLI 可通过 marqdo ext add 安装官方拓展；具体调用从标准库单文件或拓展库 index.mq.md 的参数与返回表开始。Linux 用户也可使用项目现有 Ubuntu noble PPA 安装路径；实际 apt 可用性以发布验证结果为准。

Download and unpack the matching platform bundle. Start from each standard-library source or extension index.mq.md. Development tools live in skills/marqdo-dev/index.mq.md; release tasks live in skills/marqdo-release/index.mq.md. A callable task preserves actual failures and grants only its declared effects. See README for the maintained install routes.

## 验证 / Validation

本地全量 Rust 验收为 1031 通过、0 失败、2 个原有模型实验忽略项；Go 网络插件完整测试通过。清理后重跑的 21 项 CLI/发版/WASM 测试以及 7 项真实浏览器用例通过，实际用户文档成功导出 102 页。源码审查单独检查标题下契约与超过一半的叙述；普通测试、人工夹具和历史兼容样例保留既有用途。

Windows and Linux release builds run in CI for this exact source tag. Final release verification separately checks those jobs, all artifact contents and hashes, GitHub/R2 byte parity and VERSION ordering, and Ubuntu source/build/apt publication. A local Linux test is not evidence of Windows execution or completed package publication. Public documentation export is packaged here; gh-pages deployment is separate.
