# Marqdo 2.7.1

本次为 CLI 修复发布，重点修复 View 中“实际逻辑”展开后立即折叠的问题，并完成描述链接的细节排版。官方拓展库继续使用 2.7.0，不发布新的独立拓展包，也不移动 CDN VERSION。

This CLI release fixes implementation disclosures that collapsed immediately after opening and improves typed details for descriptive links. Official extension packs remain at 2.7.0; no independent extension assets or CDN VERSION update are included.

## 修复与改进 / Fixes and improvements

- View 布局只记录自己的自动开合，不再覆盖用户选择；鼠标、键盘、窗口变化、嵌套原始写法及同一文档的运行结果刷新均保留手动状态。
- Disclosure choices survive layout, resize and live DOM replacement. Layout-generated toggle events do not become user intent or trigger another reset loop.
- 函数调用按函数名、命名参数和嵌套调用排版；本页函数可以定位到定义。链接在正文及侧注中保留跳转，相对 mq.md 链接适配实时和离线页面。
- Lists, records and prose have typed presentation with optional original source. Empty payloads remain explicit placeholders; reading details never runs payloads.
- 手机详情按整行排列，展开卡片不再撑高相邻卡片。新增可执行阅读示例 examples/view-details.mq.md。

## 核心表面与范围 / Core surface and scope

核心构造仍为 19 个，没有新增语法、标准库接口或插件 ABI。变更属于 CLI 内嵌 View 前端、只读渲染与发布产物选择。浏览器不会因查看详情而执行实现或自动抓取链接预览。

The core surface stays at 19 constructs. Standard-library and extension APIs are unchanged. CLI and WASM manifest versions are 2.7.1; extension source packs stay 2.7.0. The matching VS Code package is built from its separate source branch. This release does not deploy gh-pages.

## 验证范围 / Validation

本地全量 Rust 验收为 1039 通过、0 失败、2 个原有忽略项；用户文档成功导出 102 页。本地验收覆盖真实详情点击、键盘开合、原始写法、反复布局、窗口变化、实时 DOM 替换，以及静态/实时页面、桌面/手机和无脚本阅读。另验证只读导出不会触发逻辑、现有运行标注与连线、文档间跳转和示例函数调用。

Windows and Linux builds, exact-commit Release/EK jobs, archive contents and hashes, and Ubuntu source/build/apt availability are independent final release gates. Local browser tests do not establish Windows build success, and upload acceptance does not establish apt availability.
