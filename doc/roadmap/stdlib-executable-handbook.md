# 标准库：可执行手册与通用能力闭环

目标：代码即文档，文档即 SKILL，SKILL 即 tools。AI 直接阅读任务对应的 `lib/*.mq.md` 单文件，理解输入来源、输出形态、效应、失败处理和可执行示例；保持既有导入兼容。
本清单记录真实交付状态，未完成项不能因文档或接口占位而标为完成。

## 实施约束

保留工作区已有的 reader 改动。通用组合优先 `.mq.md`，OS/算法边界使用小型宿主原语；
不增加第二套 Skill 编译器、字符串 eval 或应用模板语法。递归删除保留旧入口行为，
新增清晰的窄接口；每次修改都同时写清兼容性和失败语义。
