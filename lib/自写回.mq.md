## 写回
    + `值`
    + `末尾`=False
    + `键`=None
    + `行`=None

在入口文件中写入 `<!-- marqdo-out … -->`。默认在调用行下方插入或替换；`末尾=true` 时替换无键末尾块。带 `键=`（如 `ok` / `error` / `成功` / `失败`）时只更新该命名槽，互不覆盖。可选 `行=` 锚定到指定源码行（子任务写回时需要）。

**> host_writeback_record value=`值` at_end=`末尾` key=`键` line=`行`**

## 取
    + `末尾`=False
    + `键`=None
    + `行`=None

读取当前调用处紧邻无键块、无键末尾块，或命名槽。

**> host_writeback_get at_end=`末尾` key=`键` line=`行`**

## 清除
    + `末尾`=False
    + `键`=None
    + `行`=None

删除紧邻块、末尾块或命名槽。

**> host_writeback_clear at_end=`末尾` key=`键` line=`行`**

## 确保
    + `键`
    + `占位`=pending
    + `行`=None

若命名槽不存在则创建并写入占位；已存在则不改动。

**> host_writeback_ensure key=`键` placeholder=`占位` line=`行`**

## 列出

**> host_writeback_list**

## 扫描路径
    + `路径`

扫描任意文件中的 `<!-- marqdo-out … -->` 槽（工作簿观察）。

**> host_writeback_scan_path path=`路径`**
