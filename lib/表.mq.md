列表与字典。嵌套写入优先「改」；作者程序里读元用链接取元，不要新写脚注取元。

## 改
    + `入`
    + `于`
    + `值`

把集合入在路径于上的那一元改成值。

于可以是文本键、1-based 下标，或键/下标组成的路径列表（与链接取元嵌套同构）。

调用例：[表.改] 入=None 于="Authorization" 值="Bearer-x"

*> host_collection_put in=`入` at=`于` value=`值`*

## 长度
    + `xs`

列表或字典 xs 的长度。

*> len `xs`*

## 行数
    + `xs`

列表 xs 的行数（同长度）。

*> len `xs`*

## 取
    + `xs`
    + `i`

从零起取 xs 的第 i 项（与内置 at 相同）。越界 → None。

*> at value=`xs` index=`i`*

## 取行
    + `xs`
    + `i`

从零起取 xs 的第 i 行。

*> at value=`xs` index=`i`*

## 追加
    + `list`
    + `item`

在 list 末尾追加 item。

*> host_list_append list=`list` item=`item`*

## 前插
    + `list`
    + `item`

在 list 开头插入 item。

*> host_list_prepend list=`list` item=`item`*

## 拼接
    + `a`
    + `b`

拼接列表 a 与 b。

*> host_list_concat a=`a` b=`b`*

## 插入
    + `list`
    + `index`
    + `item`

在 list 的从零起 index 处插入 item。

*> host_list_insert list=`list` index=`index` item=`item`*

## 改位
    + `list`
    + `index`
    + `item`

从零起替换 list 的 index 为 item；日常嵌套改写请用「改」。

*> host_list_set_at list=`list` index=`index` item=`item`*

## 删位
    + `list`
    + `index`

删去 list 从零起的 index。

*> host_list_remove_at list=`list` index=`index`*

## 弹出
    + `list`

去掉 list 末项（空表报错）。需要末值时先「末」。

**`n` = > len `list`**
1. `n` > 0
  *> host_list_remove_at list=`list` index=`n` - 1*
2. *
  *> host_list_remove_at list=`list` index=0*

## 首
    + `list`

list 的首项。

*> host_list_first list=`list`*

## 末
    + `list`

list 的末项。

*> host_list_last list=`list`*

## 切片
    + `list`
    + `start`
    + `end`=None

对 list 做从零起的半开切片，从 start 到 end。

*> host_list_slice list=`list` start=`start` end=`end`*

## 含有
    + `list`
    + `item`

list 是否含有 item。

*> host_list_contains list=`list` item=`item`*

## 下标
    + `list`
    + `item`

item 在 list 中从零起的下标；没有 → None。

*> host_list_index_of list=`list` item=`item`*

## 反转
    + `list`

反转 list。

*> host_list_reverse list=`list`*

## 排序
    + `list`

对 list 升序排序（优先 int/num/text）。

*> host_list_sort list=`list`*

## 按键排序
    + `list`
    + `key`

对 map 列表 list 按字段 key 排序。

*> host_list_sort_by list=`list` key=`key`*

## 去重
    + `list`

对 list 保序去重（保留首次）。

*> host_list_unique list=`list`*

## 分块
    + `list`
    + `size`

把 list 按 size 分块。

*> host_list_chunk list=`list` size=`size`*

## 拉链
    + `a`
    + `b`

将 a 与 b 配对，取较短长度。

*> host_list_zip a=`a` b=`b`*

## 展平
    + `list`

对 list 做一层展平。

*> host_list_flatten list=`list`*

## 清空
    + `value`

按类型清空 value（空列表或空字典）。

*> host_collection_clear value=`value`*

## 取键
    + `map`
    + `key`

浅取 map 的 key；缺键 → None。作者侧优先链接取元。

*> host_map_get map=`map` key=`key`*

## 设
    + `map`
    + `key`
    + `value`

浅设 map 的 key 为 value；嵌套请用「改」。

*> host_map_set map=`map` key=`key` value=`value`*

## 删键
    + `map`
    + `key`

从 map 删除 key。

*> host_map_delete map=`map` key=`key`*

## 有键
    + `map`
    + `key`

map 是否有 key。

*> host_map_has map=`map` key=`key`*

## 键表
    + `map`

map 的键表。

*> host_map_keys map=`map`*

## 值表
    + `map`

map 的值表。

*> host_map_values map=`map`*

## 项表
    + `map`

map 的键值对行表。

*> host_map_items map=`map`*

## 合并
    + `a`
    + `b`

合并 a 与 b（右侧覆盖左侧）。

*> host_map_merge a=`a` b=`b`*

## 键数
    + `map`

map 的键数。

*> host_map_size map=`map`*

## 空表

空列表。

*> host_list_concat a=None b=None*

## 空字典

空字典。

*> host_map_merge a=None b=None*
