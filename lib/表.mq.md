列表与字典。嵌套写入优先「改」；作者程序里读元用access 取元，不要新写脚注取元。

用明确的数据形态变换列表、字典和行记录。

能力与边界：access 与改的整数路径从一开始；取、切片、插入、删位等旧接口从零开始。更新返回新值，必须保存。行数只是长度别名；列转行、行转列明确转换形态。相等比较沿用运行时的类型和字典顺序规则。

本文件就是调用和开发手册：直接导入此文件，或用 marqdo call 按下面的函数标题调用。参数表说明类型和默认值；未填默认值的参数必须提供。返回表是渐进契约，后文说明失败与边界。

实现入口：[src/host/collection.rs](../src/host/collection.rs)、[src/host/collection_ops.rs](../src/host/collection_ops.rs)

开发时保持中英文语义一致，先组合公开库；仅在 OS 或算法边界添加宿主原语并声明效应。修改后运行 marqdo check --narrative-ratio 本文件，并执行 tests/stdlib_tasks.rs 的真实任务。

|---|---|---|

这里使用`入`、`于`、`值`。

调用效应：pure。

把集合入在路径于上的那一元改成值。

于可以是文本键、1-based 下标，或键/下标组成的路径列表（与access 取元嵌套同构）。

调用例：[表.改] 入=None 于="Authorization" 值="Bearer-x"

|---|---|---|---|
| 键值对 | list | 必填 | 有序行记录，每行含文本 key 与任意 value 字段；其他字段不参与构造 |

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | map | 新记录；首次出现的键决定顺序，后续同名键替换其值 |

调用效应：pure。

输入`键值对`采用普通 @ 行记录表，把过宽的横向记录改写成可逐行阅读的 key/value 数据。
适合提示章节、配置片段和具名字段较多的记录；这里复用本库既有的不可变更新，
不解析 JSON 文本，也不另造表格方言。空列表得到空记录，缺少或无效的键交给改操作报告，
不会为了制造字典而添加一个无意义的占位列。

先准备**记录 = [创建新的空记录](空字典())**，再按行读取字段，使每一项的来源都保持可见。

- [把每条具名字段写入新记录](遍历 键值对 为 键值行)
  读取**键 = [取出本行的字段名](access(键值行, "key"))**，
  以及**值 = [取出本行的字段值](access(键值行, "value"))**。
  然后保留**记录 = [设置字段而不修改输入行](改(入=`记录`, 于=`键`, 值=`值`))**。

处理完有序行后，返回*记录*。同名字段保留第一次出现的位置并更新其值；
原来的键值对仍可继续使用，本操作没有文件、网络或插件副作用。
