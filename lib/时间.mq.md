Unix 时间、格式化、解析与睡眠。

格式化时间戳并控制等待。

能力与边界：读取当前时间需要时钟效应；等待具有控制效应，在捕获模式下会被限制。日历和 IANA 时区规则由日期时间库负责。

本文件就是调用和开发手册：直接导入此文件，或用 marqdo call 按下面的函数标题调用。参数表说明类型和默认值；未填默认值的参数必须提供。返回表是渐进契约，后文说明失败与边界。

实现入口：[src/host/time.rs](../src/host/time.rs)

开发时保持中英文语义一致，先组合公开库；仅在 OS 或算法边界添加宿主原语并声明效应。修改后运行 marqdo check --narrative-ratio 本文件，并执行 tests/stdlib_tasks.rs 的真实任务。

## 格式化

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 秒 | any | 必填 | 以秒为单位的 Unix 时间戳 |
| 格式 | any | 必填 | strftime 日期时间格式文本 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 用格式把秒格式化成文本 |

这里使用`秒`、`格式`。

调用效应：pure。

直接调用此函数：

```sh
marqdo call lib/时间.mq.md 格式化 '秒=0' '格式="%Y-%m-%d"' --effects none --json
```

用格式把秒格式化成文本。

完成后返回*[用格式把秒格式化成文本](> host_format_time unix=`秒` pattern=`格式`)*。
