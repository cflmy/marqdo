只做路径代数。无 I/O；分隔符随宿主 OS。

不访问磁盘的路径运算。

能力与边界：归一化是词法运算，不代表已获得文件访问权限。真正的 IO 路径由宿主按文件根目录检查。

本文件就是调用和开发手册：直接导入此文件，或用 marqdo call 按下面的函数标题调用。参数表说明类型和默认值；未填默认值的参数必须提供。返回表是渐进契约，后文说明失败与边界。

实现入口：[src/host/path.rs](../src/host/path.rs)、[src/host/fs_ops.rs](../src/host/fs_ops.rs)

开发时保持中英文语义一致，先组合公开库；仅在 OS 或算法边界添加宿主原语并声明效应。修改后运行 marqdo check --narrative-ratio 本文件，并执行 tests/stdlib_tasks.rs 的真实任务。

## 拼接

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 甲 | any | 必填 | 基础路径 |
| 乙 | any | 必填 | 追加到基础路径的路径片段 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 拼接路径段甲与乙 |

这里使用`甲`、`乙`。

调用效应：pure。

拼接路径段甲与乙。

调用例：[路径.拼接] 甲="a" 乙="b"

完成后返回*[拼接路径段甲与乙](> host_path_join a=`甲` b=`乙`)*。

这里使用`路径`、`扩展名`。

调用效应：pure。

直接调用此函数：

```sh
marqdo call lib/路径.mq.md 换扩展名 '路径="notes/draft.txt"' '扩展名="md"' --effects none --json
```

替换最后的扩展名；空扩展名表示去除。

完成后返回*[替换最后的扩展名；空扩展名表示去除](> host_path_with_extension path=`路径` extension=`扩展名`)*。
