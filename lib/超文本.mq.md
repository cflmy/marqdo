HTML 转义助手。把不可信文本拼进标记前先转义。

转义或还原 HTML 文本。

能力与边界：文本转义不等于清洗任意 HTML 文档。站点内容优先采用 Markdown 叶子和结构化视图节点。

本文件就是调用和开发手册：直接导入此文件，或用 marqdo call 按下面的函数标题调用。参数表说明类型和默认值；未填默认值的参数必须提供。返回表是渐进契约，后文说明失败与边界。

实现入口：[src/host/html_ops.rs](../src/host/html_ops.rs)

开发时保持中英文语义一致，先组合公开库；仅在 OS 或算法边界添加宿主原语并声明效应。修改后运行 marqdo check --narrative-ratio 本文件，并执行 tests/stdlib_tasks.rs 的真实任务。

## 转义

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 内容 | any | 必填 | 本操作读取、转换或输出的文本 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 对内容做 HTML 转义 |

这里使用`内容`。

调用效应：pure。

直接调用此函数：

```sh
marqdo call lib/超文本.mq.md 转义 '内容="<strong>&"' --effects none --json
```

对内容做 HTML 转义。

调用例：[超文本.转义] 内容=`段`

完成后返回*[对内容做 HTML 转义](> host_html_escape text=`内容`)*。
