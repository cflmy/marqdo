通过渲染器共用的 Markdown 解析器读取文档结构。结构变换为纯函数，读取表值通过原生文件能力加载指定数据。

不执行内容地读取与变换 Markdown 结构。

能力与边界：复用 Markdown 解析器并识别 YAML 前置信息；区间是原始 UTF-8 字节偏移。不执行文档。重复章节名失败；替换保留周围源码，持久化使用校验后写。

本文件就是调用和开发手册：直接导入此文件，或用 marqdo call 按下面的函数标题调用。参数表说明类型和默认值；未填默认值的参数必须提供。返回表是渐进契约，后文说明失败与边界。

实现入口：[src/host/document.rs](../src/host/document.rs)

开发时保持中英文语义一致，先组合公开库；仅在 OS 或算法边界添加宿主原语并声明效应。修改后运行 marqdo check --narrative-ratio 本文件，并执行 tests/stdlib_tasks.rs 的真实任务。

## 表值

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 内容 | text | 必填 | 含字面 GFM 数据表的 Markdown |
| 标题 | any | None | 精确且唯一的章节名；None 表示整篇 |
| 索引 | number | 0 | 所选章节中从零开始的表格序号 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 与 Marqdo 字面表相同形态和类型的实际数据 |

这里使用`内容`、`标题`=None和`索引`=0。常量表中的布尔、数值、空值和引号文本保留原生类型；@、行或 row 首列产生记录列表，单列产生普通列表，其余表保留原有映射形态。定位使用渲染器共用的 Markdown 解析器，会跳过围栏内示例。重复标题、表头冲突、列数不齐和非法索引会给出诊断。变量引用、插值和可执行表达式不能作为数据读取；正文、导入和外联围栏也不会执行。这样可以把模式、种子和样式常量拆成 Markdown 数据叶子，同时让调用函数说明实际用途。

完成后返回*[按原生字面规则读取表值](document.table(text=`内容`, title=`标题`, index=`索引`))*.


## 读取表值

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 路径 | text | 必填 | 文件根内的 UTF-8 Markdown 数据文件 |
| 标题 | any | None | 精确且唯一的章节名；None 表示整篇 |
| 索引 | number | 0 | 所选章节中从零开始的表格序号 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 通过原生 fs.read 加载的字面表数据 |

这里使用`路径`、`标题`=None和`索引`=0，授权 fs.read 后读取数据叶子。文件读取检查根目录与 UTF-8，表值选择保留字面类型及实际结构。文件可以把字段说明、示例和数据写在一起，读取过程不会运行其中的语句、导入或其他语言围栏。文件缺失、标题重复、单元格动态引用和列数不齐均保留诊断。此函数只读，调用者再按数据库、样式或其他领域的真实契约使用返回值。

完成后返回*[原生读取并选择 Markdown 数据](document.read_table(path=`路径`, title=`标题`, index=`索引`))*.
