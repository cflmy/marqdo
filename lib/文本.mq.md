常用文本助手。手写拆分不如走这里；正则请用 lib/正则。

清理与组合 Unicode 文本。

能力与边界：字面替换使用本库，模式匹配使用正则库，任意二进制使用字节库。拆分和拼接使用明确分隔符，不隐式解析文档。

本文件就是调用和开发手册：直接导入此文件，或用 marqdo call 按下面的函数标题调用。参数表说明类型和默认值；未填默认值的参数必须提供。返回表是渐进契约，后文说明失败与边界。

实现入口：[src/host/text_ops.rs](../src/host/text_ops.rs)

开发时保持中英文语义一致，先组合公开库；仅在 OS 或算法边界添加宿主原语并声明效应。修改后运行 marqdo check --narrative-ratio 本文件，并执行 tests/stdlib_tasks.rs 的真实任务。

## 去空白

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| s | text | 必填 | 输入文本 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 去掉字符串 s 两端空白 |

这里使用`s`。

调用效应：pure。

直接调用此函数：

```sh
marqdo call lib/文本.mq.md 去空白 's="  readable text  "' --effects none --json
```

去掉字符串 s 两端空白。

完成后返回*[调用 trim](trim(`s`))*。
