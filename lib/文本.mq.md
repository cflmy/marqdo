常用文本助手。手写拆分不如走这里；正则请用 lib/正则。

## 去空白
    + `s`

去掉字符串 s 两端空白。

*> trim `s`*

## 拆分
    + `s`
    + `sep`

按分隔符 sep 拆分字符串 s。

*> split value=`s` sep=`sep`*

## 拼接
    + `xs`
    + `sep`

用分隔符 sep 拼接列表 xs。

*> join value=`xs` sep=`sep`*

## 包含
    + `内容`
    + `子串`

内容是否包含子串。

调用例：[文本.包含] 内容="你好" 子串="好"

*> host_text_contains text=`内容` sub=`子串`*

## 开头是
    + `内容`
    + `前缀`

内容是否以前缀开头。

*> host_text_starts_with text=`内容` prefix=`前缀`*

## 结尾是
    + `内容`
    + `后缀`

内容是否以后缀结尾。

*> host_text_ends_with text=`内容` suffix=`后缀`*

## 替换
    + `内容`
    + `旧`
    + `新`
    + `次数`=None

在内容里把字面旧换成新，可选次数。

*> host_text_replace text=`内容` old=`旧` new=`新` count=`次数`*

## 大写
    + `内容`

内容转大写。

*> host_text_to_upper text=`内容`*

## 小写
    + `内容`

内容转小写。

*> host_text_to_lower text=`内容`*

## 重复
    + `内容`
    + `次数`

把内容重复次数遍。

*> host_text_repeat text=`内容` n=`次数`*

## 填充
    + `内容`
    + `宽度`
    + `填充符`=None
    + `对齐`=None

把内容填充到宽度，可选填充符与对齐（left / right / center）。

*> host_text_pad text=`内容` width=`宽度` fill=`填充符` align=`对齐`*
