加载可选原生 ABI 插件（.dll / .so / .dylib）。

定位并加载原生能力。

能力与边界：空列表表示本进程尚未加载插件。插件发现与加载需要 plugin.call；普通使用先读对应领域扩展的入口。原生插件不支持浏览器构建。

本文件就是调用和开发手册：直接导入此文件，或用 marqdo call 按下面的函数标题调用。参数表说明类型和默认值；未填默认值的参数必须提供。返回表是渐进契约，后文说明失败与边界。

实现入口：[src/host/plugin.rs](../src/host/plugin.rs)

开发时保持中英文语义一致，先组合公开库；仅在 OS 或算法边界添加宿主原语并声明效应。修改后运行 marqdo check --narrative-ratio 本文件，并执行 tests/stdlib_tasks.rs 的真实任务。

## 加载

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 路径 | any | 必填 | 授权文件根目录内的路径 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 从路径加载原生插件 |

这里使用`路径`。

调用效应：plugin.call。

从路径加载原生插件。

调用例：[插件.加载] 路径=`so`

完成后返回*[从路径加载原生插件](> host_plugin_load path=`路径`)*。

## 卸载

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 卸载当前原生插件 |

调用效应：plugin.call。

卸载当前原生插件。

完成后返回*[卸载当前原生插件](host_plugin_unload())*。

## 列出

| 返回 | 类型 | 说明 |
|---|---|---|
| result | list | 列出已加载的原生插件 |

调用效应：pure。

直接调用此函数：

```sh
marqdo call lib/插件.mq.md 列出  --effects none --json
```

列出已加载的原生插件。

返回当前宿主进程已加载插件的名称列表；本函数不会加载插件，新进程的列表可能为空。

完成后返回*[列出已加载的原生插件](host_plugin_list())*。

## 原生路径

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 名 | any | 必填 | 已安装拓展库标识，例如 agent |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 解析已安装或本地原生插件路径（如 agent） |

这里使用`名`。

解析已安装或本地原生插件路径（如 agent）。
