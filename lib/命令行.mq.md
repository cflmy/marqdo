把进程参数解析成映射。开关与位置参（落在 _）。

把命令行词元转换为标志和位置参数。

能力与边界：参数值保持文本，裸标志变为布尔值，位置参数位于下划线键。省略输入时使用宿主参数；不提供完整的参数约束模式系统。

本文件就是调用和开发手册：直接导入此文件，或用 marqdo call 按下面的函数标题调用。参数表说明类型和默认值；未填默认值的参数必须提供。返回表是渐进契约，后文说明失败与边界。

实现入口：[src/host/cli.rs](../src/host/cli.rs)

开发时保持中英文语义一致，先组合公开库；仅在 OS 或算法边界添加宿主原语并声明效应。修改后运行 marqdo check --narrative-ratio 本文件，并执行 tests/stdlib_tasks.rs 的真实任务。

## 解析

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 参数 | any | None | 命令行 token 列表；None 读取当前宿主 argv |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | 解析 --键 值 / --键=值 / --开关 |

这里使用`参数`=None。

调用效应：pure。

直接调用此函数：

```sh
marqdo call lib/命令行.mq.md 解析 '参数=["report","--count=3","--quiet"]' --effects none --json
```

解析 --键 值 / --键=值 / --开关。裸 --开关 若当布尔，后面不要紧跟非选项词（开关放最后，或写 --开关=true）。位置参进 _。省略参数时用进程 argv（系统.参数表）。

调用例：[命令行.解析]
