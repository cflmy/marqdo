## 获取
    + `地址`
    + `headers`=None

支持 HTTPS。可选具名实参 `headers=`（映射）。

**> host_http_get url=`地址` headers=`headers`**

## 提交
    + `地址`
    + `内容`
    + `content_type`=None
    + `headers`=None

默认 Content-Type 为 JSON。可选 `content_type=` / `headers=`。

**> host_http_post url=`地址` body=`内容` content_type=`content_type` headers=`headers`**

## 提交流式
    + `地址`
    + `内容`
    + `content_type`=None
    + `headers`=None
    + `打印增量`=False

POST 并消费 OpenAI 兼容 SSE。返回 `{status, events}`（`delta` / `done` / `error`）。`打印增量=真` 时边读边打印增量文本。

**> host_http_post_sse url=`地址` body=`内容` content_type=`content_type` headers=`headers` echo=`打印增量`**

## 解析流式
    + `内容`
    + `打印增量`=False

离线解析 OpenAI 聊天 SSE 正文为事件列表（不联网）。

**> host_openai_sse_parse text=`内容` echo=`打印增量`**

## 请求
    + `方法`
    + `地址`
    + `body`=None
    + `content_type`=None
    + `headers`=None

可选 `body=` / `content_type=` / `headers=`。

**> host_http_request method=`方法` url=`地址` body=`body` content_type=`content_type` headers=`headers`**

## 编码地址
    + `内容`

**> host_url_encode text=`内容`**
