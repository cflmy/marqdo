---

## 获取
    + `地址`
    + `headers`=None

支持 HTTPS。可选具名实参 `headers=`（映射）。

**> host_http_get url=`地址` headers=`headers`**

## 提交
    + `地址`
    + `内容`
    + `content_type`=None
    + `headers`=None

默认 Content-Type 为 JSON。可选 `content_type=` / `headers=`。

**> host_http_post url=`地址` body=`内容` content_type=`content_type` headers=`headers`**

## 请求
    + `方法`
    + `地址`
    + `body`=None
    + `content_type`=None
    + `headers`=None

可选 `body=` / `content_type=` / `headers=`。

**> host_http_request method=`方法` url=`地址` body=`body` content_type=`content_type` headers=`headers`**

## 编码地址
    + `内容`

**> host_url_encode text=`内容`**
