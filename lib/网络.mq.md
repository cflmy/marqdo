中文 HTTP(S) 包装。可选 headers / content_type 经宿主别名绑定。

处理 HTTP、响应数据和有界下载。

能力与边界：读取只需 network.read；可恢复请求的方法可动态变化，因此保守要求 network.write。响应头是 name/values 行记录，可用响应头值取值。下载还需 fs.write；旧接口保留原契约。

本文件就是调用和开发手册：直接导入此文件，或用 marqdo call 按下面的函数标题调用。参数表说明类型和默认值；未填默认值的参数必须提供。返回表是渐进契约，后文说明失败与边界。

实现入口：[src/host/net.rs](../src/host/net.rs)、[src/host/net_ops.rs](../src/host/net_ops.rs)

开发时保持中英文语义一致，先组合公开库；仅在 OS 或算法边界添加宿主原语并声明效应。修改后运行 marqdo check --narrative-ratio 本文件，并执行 tests/stdlib_tasks.rs 的真实任务。

| 响应头 | list | 必填 | 响应中的 headers 行记录 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | list | 同名头部的全部值 |

这里使用`响应头`、`名称`。

调用效应：pure。

从响应头行记录中按不区分大小写的名称取全部值；不存在返回空列表。请求的 headers 参数仍使用字典，响应 headers 使用行记录以保留任意名称和重复值。

得到**`lower` = [调用 to lower](text.to_lower(text=`名称`))**。
得到**`matches` = [调用 where](table.where(list=`响应头`, key="name", value=`lower`))**。
得到**`values` = [调用 pluck](table.pluck(list=`matches`, key="values"))**。
完成后返回*[调用 flatten](table.flatten(list=`values`))*。
