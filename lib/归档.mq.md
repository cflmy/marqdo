可选 ZIP 任务；原生默认构建支持，精简与浏览器构建不支持。返回统一结果记录。

归档是可选原生能力。本文件的打包与解包就是生产接口；
两者需要 fs.write，返回统一结果记录，目标必须不存在。解包先预检路径、
重复条目、符号链接与总展开字节上限；失败只清理本次新建的目标目录。
不复制权限、符号链接和空目录；精简或浏览器构建明确返回不支持。

本文件就是调用和开发手册：直接导入此文件，或用 marqdo call 按下面的函数标题调用。参数表说明类型和默认值；未填默认值的参数必须提供。返回表是渐进契约，后文说明失败与边界。

相对文件路径以 --fs-root 为准，省略时以被调用文件所在目录为准。写入需要显式 fs.write 授权，子进程需要 process.exec；纯计算无需 IO 权限。

实现入口：[src/host/archive.rs](../src/host/archive.rs)

开发时保持中英文语义一致，先组合公开库；仅在 OS 或算法边界添加宿主原语并声明效应。修改后运行 marqdo check --narrative-ratio 本文件，并执行 tests/stdlib_tasks.rs 的真实任务。

## 打包

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 来源 | text | 必填 | 来源路径；归档打包时必须是目录 |
| 目标 | text | 必填 | 目标路径；仅在操作明确允许时才能覆盖 |
| 字节上限 | number | 1073741824 | 读取或展开的字节上限；超限则失败 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | map | 成功结果的 value 是已归档普通文件数；失败时包含结构化错误 |

这里使用`来源`、`目标`、`字节上限`=1073741824。

调用效应：fs.write。

示例先准备可丢弃的目录 MQ_WORK，其中 input 子目录放待归档普通文件；目标 bundle.zip 和 output 必须不存在。解包后自行保留产物或清理目录。

```sh
marqdo call lib/归档.mq.md 打包 '来源="input"' '目标="bundle.zip"' --fs-root "$MQ_WORK" --effects fs.write --json
marqdo call lib/归档.mq.md 解包 '来源="bundle.zip"' '目标="output"' --fs-root "$MQ_WORK" --effects fs.write --json
```

目标必须不存在；限制总展开字节数和十万条目，拒绝符号链接和越界路径。打包只收集普通文件；解包失败清理新建目标目录。

完成后返回*[把普通文件打包为 ZIP，拒绝覆盖已有目标](> host_zip_pack src=`来源` dest=`目标` max_bytes=`字节上限`)*。
