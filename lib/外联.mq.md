通过本机解释器运行绑定的代码围栏与内联源码。

## 设置命令
    + `语言`
    + `命令`
    + `参数`=None

为语言绑定解释器命令；可选附加参数。

*> host_foreign_set_cmd lang=`语言` cmd=`命令` args=`参数`*

## 运行
    + `代码`
    + `标准输入`=None
    + `环境`=None
    + `工作目录`=None
    + `超时`=None
    + `参数`=None
    + `最大输出`=None

运行已绑定的代码围栏值；可选标准输入、环境表、工作目录、超时（秒）、
附加参数与输出上限。返回 stdout 文本；非 0 退出即报错。

调用例：[外联.运行] 代码=`块`

*> host_foreign_run code=`代码` stdin=`标准输入` env=`环境` cwd=`工作目录` timeout=`超时` args=`参数` max_output=`最大输出`*

## 按语言运行
    + `语言`
    + `源码`
    + `标准输入`=None
    + `环境`=None
    + `工作目录`=None
    + `超时`=None
    + `参数`=None
    + `最大输出`=None

用语言运行源码文本；选项同“运行”。

*> host_foreign_run_lang lang=`语言` source=`源码` stdin=`标准输入` env=`环境` cwd=`工作目录` timeout=`超时` args=`参数` max_output=`最大输出`*

## 执行
    + `代码`=None
    + `语言`=None
    + `源码`=None
    + `标准输入`=None
    + `输入`=None
    + `环境`=None
    + `工作目录`=None
    + `超时`=None
    + `参数`=None
    + `输出`=auto
    + `最大输出`=None
    + `命令`=None
    + `保留`=False

运行代码或“语言+源码”，返回记录 map，而不是在进程失败时直接报错。
字段：ok、code、stdout、stderr、ms、lang、cmd、timed_out、truncated、
result、result_error、error、script、cached。

`输入` 会编码为 JSON 写入 stdin（与 `标准输入` 互斥）。`输出` 可取
auto | text | json | lines。`命令` 仅本次覆盖解释器。

*> host_foreign_invoke code=`代码` lang=`语言` source=`源码` stdin=`标准输入` input=`输入` env=`环境` cwd=`工作目录` timeout=`超时` args=`参数` output=`输出` max_output=`最大输出` cmd=`命令` keep=`保留`*

## 探测
    + `语言`=None

探测一个语言；省略语言时探测所有已知语言。返回
{lang, cmd, path, ok, version, error}（省略语言时是列表）。

*> host_foreign_probe lang=`语言`*

## 注册
    + `语言`
    + `命令`=None
    + `参数`=None
    + `模板`=None
    + `扩展名`=None
    + `环境`=None
    + `版本参数`=None

注册语言调用。提供命令（+参数）或模板（占位符
{file}、{dir}、{base}、{inline}、{lang}、{cwd}）；二者互斥。

*> host_foreign_register lang=`语言` cmd=`命令` args=`参数` template=`模板` ext=`扩展名` env=`环境` version_args=`版本参数`*

## 注销
    + `语言`

移除进程内注册；预设 / 配置 / 环境变量仍然生效。

*> host_foreign_unset lang=`语言`*

## 加载配置
    + `路径`=None

加载 .marqdo/foreign.toml（或显式路径）；返回读取到的语言表数量。

*> host_foreign_load_config path=`路径`*

## 调用
    + `代码`=None
    + `语言`=None
    + `源码`=None
    + `输入`=None
    + `标准输入`=None
    + `环境`=None
    + `工作目录`=None
    + `超时`=None
    + `参数`=None

JSON 进 / JSON 出：把 `输入` 编码到 stdin，解析 stdout JSON 返回值
（stdout 为空 → None）。进程失败或 JSON 非法时报错。

*> host_foreign_call code=`代码` lang=`语言` source=`源码` input=`输入` stdin=`标准输入` env=`环境` cwd=`工作目录` timeout=`超时` args=`参数`*

## 批量运行
    + `任务表`
    + `并发`=4

并行运行一组代码值或 invoke 选项 map；按输入顺序返回记录。单项失败不影响其它项。

*> host_foreign_run_many runs=`任务表` concurrency=`并发`*

## 批量调用
    + `输入表`
    + `代码`=None
    + `语言`=None
    + `源码`=None
    + `命令`=None
    + `环境`=None
    + `工作目录`=None
    + `超时`=None
    + `参数`=None
    + `最大输出`=None
    + `并发`=4

把同一段代码并行作用到每个输入；按输入顺序返回解析后的 JSON 结果。
全部结束后若任一项失败，报错并指出下标。

*> host_foreign_call_many inputs=`输入表` code=`代码` lang=`语言` source=`源码` cmd=`命令` env=`环境` cwd=`工作目录` timeout=`超时` args=`参数` max_output=`最大输出` concurrency=`并发`*

## 会话
    + `内核表`=None
    + `单元表`=None
    + `值表`=None
    + `输入表`=None

声明文档视图会话。内核表和单元表都是普通表格；返回一个 foreign 会话句柄，
供 view 消费。没有这个句柄时，view 的 cells 是无状态的。

**p = > table.empty_map**
**p = > table.put in=`p` at="kind" value="foreign-session"**
**p = > table.put in=`p` at="kernels" value=`内核表`**
**p = > table.put in=`p` at="cells" value=`单元表`**
**p = > table.put in=`p` at="values" value=`值表`**
**p = > table.put in=`p` at="inputs" value=`输入表`**
*p*

## 会话开启
    + `语言`
    + `命令`=None
    + `环境`=None
    + `工作目录`=None
    + `超时`=None

启动一个持久的 Python / Node 内核；返回会话 id。`超时` 是每次求值的默认超时。

*> host_foreign_session_open lang=`语言` cmd=`命令` env=`环境` cwd=`工作目录` timeout=`超时`*

## 会话求值
    + `标识`
    + `代码`=None
    + `源码`=None
    + `输入`=None
    + `标准输入`=None
    + `超时`=None

在会话中求值代码（code 值）或源码文本；返回带 id/alive 的记录。
`输入` 会编码为 JSON 交给内核。

*> host_foreign_session_eval id=`标识` code=`代码` source=`源码` input=`输入` stdin=`标准输入` timeout=`超时`*

## 会话设值
    + `标识`
    + `名称`
    + `值`

把一个 Marqdo 值写入内核变量（JSON 拷贝）。

*> host_foreign_session_set id=`标识` name=`名称` value=`值`*

## 会话取值
    + `标识`
    + `名称`

把一个内核变量读成 Marqdo 值。

*> host_foreign_session_get id=`标识` name=`名称`*

## 会话中断
    + `标识`

中断持久内核当前求值；worker 支持时，会话仍可用于下一次求值。

*> host_foreign_session_interrupt id=`标识`*

## 会话变量
    + `标识`

列出内核变量名。

*> host_foreign_session_names id=`标识`*

## 会话关闭
    + `标识`

终止并移除会话；返回是否存在。

*> host_foreign_session_close id=`标识`*

## 会话表

列出活动会话的 id/lang/cmd/evals/alive/started_ms。

*> host_foreign_session_list*

## 语言表

列出已配置的外联语言。

*> host_foreign_langs*
