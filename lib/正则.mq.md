正则表达式。Unicode；无回溯引用。字面替换请用 lib/文本。

进行 Unicode 正则匹配。

能力与边界：不支持反向引用；当前查找返回完整匹配，不承诺捕获组对象或替换回调。字面字符串替换使用文本库。

本文件就是调用和开发手册：直接导入此文件，或用 marqdo call 按下面的函数标题调用。参数表说明类型和默认值；未填默认值的参数必须提供。返回表是渐进契约，后文说明失败与边界。

实现入口：[src/host/re.rs](../src/host/re.rs)

开发时保持中英文语义一致，先组合公开库；仅在 OS 或算法边界添加宿主原语并声明效应。修改后运行 marqdo check --narrative-ratio 本文件，并执行 tests/stdlib_tasks.rs 的真实任务。

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 内容 | any | 必填 | 本操作读取、转换或输出的文本 |
| 模式 | any | 必填 | 宿主 regex 实现支持的正则表达式 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | bool | 内容是否匹配模式 |

这里使用`内容`、`模式`。

调用效应：pure。

内容是否匹配模式。

调用例：[正则.匹配] 内容=`s` 模式="a+"

完成后返回*[内容是否匹配模式](> host_re_is_match text=`内容` pattern=`模式`)*。
