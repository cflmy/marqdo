可恢复结果使用普通记录 ok/value/error；error 内含 code/message/operation。
先判断 ok 再使用 value；结果包装不会绕过宿主权限检查。

以统一数据契约组合可恢复结果。

能力与边界：先检查 ok，再使用 value；HTTP 状态和子进程退出码仍需按领域规则判断；错误含 code/message/operation。尝试接口处理已定义的可恢复失败，不是捕获任意运行时错误的异常系统，也不会授予权限。

本文件就是调用和开发手册：直接导入此文件，或用 marqdo call 按下面的函数标题调用。参数表说明类型和默认值；未填默认值的参数必须提供。返回表是渐进契约，后文说明失败与边界。

实现入口：[src/host/result.rs](../src/host/result.rs)

开发时保持中英文语义一致，先组合公开库；仅在 OS 或算法边界添加宿主原语并声明效应。修改后运行 marqdo check --narrative-ratio 本文件，并执行 tests/stdlib_tasks.rs 的真实任务。

## 成功

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 值 | any | 必填 | 成功操作的值，包括 None |

| 返回 | 类型 | 说明 |
|------|------|------|
| 结果 | map | Successful Result |

这里使用`值`。

将当前输入交给 成功，保留同源能力的返回值和失败语义。

调用效应：pure。

`out` =

| ok | value | error |
|----|-------|-------|
| True | `值` | None |

完成后返回*out*。

## 失败

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 错误码 | text | 必填 | 供程序判断的稳定错误类别 |
| 消息 | text | 必填 | 供人阅读的错误解释 |
| 操作 | text | "application" | 发生失败的操作名 |

| 返回 | 类型 | 说明 |
|------|------|------|
| 结果 | map | Failed Result |

这里使用`错误码`、`消息`、`操作`="application"。

将当前输入交给 失败，保留同源能力的返回值和失败语义。

调用效应：pure。

`failure` =

| code | message | operation |
|------|---------|-----------|
| `错误码` | `消息` | `操作` |

`out` =

| ok | value | error |
|----|-------|-------|
| False | None | `failure` |

完成后返回*out*。

## 值或默认

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 结果 | map | 必填 | 可恢复操作返回的结果记录 |
| 默认值 | any | None | 操作失败时明确采用的替代值 |

| 返回 | 类型 | 说明 |
|------|------|------|
| 结果 | any | Successful value or fallback |

这里使用`结果`、`默认值`=None。

调用效应：pure。

直接调用此函数：

```sh
marqdo call lib/结果.mq.md 值或默认 '结果={"ok":false,"value":null,"error":{"code":"missing","message":"absent","operation":"example"}}' '默认值="fallback"' --effects none --json
```

只在 ok 为真时读取 value；成功且值为 None 时仍保留 None。仅在操作失败时使用默认值，不按真假性吞掉零或空文本。
