安全随机令牌。勿用 math.random 生成令牌。

生成密码学随机令牌。

能力与边界：字节数是输入字节长度，不是输出文本长度。不能用数学伪随机数生成凭证；浏览器熵源依赖运行时桥接，不可悄悄替换为伪随机。

本文件就是调用和开发手册：直接导入此文件，或用 marqdo call 按下面的函数标题调用。参数表说明类型和默认值；未填默认值的参数必须提供。返回表是渐进契约，后文说明失败与边界。

实现入口：[src/host/secrets.rs](../src/host/secrets.rs)

开发时保持中英文语义一致，先组合公开库；仅在 OS 或算法边界添加宿主原语并声明效应。修改后运行 marqdo check --narrative-ratio 本文件，并执行 tests/stdlib_tasks.rs 的真实任务。

## 十六进制令牌

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 字节数 | any | None | 请求的字节数；None 使用接口默认值 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 字节长度（默认 16），返回长度为 2*字节数 的小写 hex |

这里使用`字节数`=None。

调用效应：random.read。

直接调用此函数：

```sh
marqdo call lib/机密.mq.md 十六进制令牌 '字节数=16' --effects random.read --json
```

字节长度（默认 16），返回长度为 2*字节数 的小写 hex。

调用例：[机密.十六进制令牌] 字节数=16

完成后返回*[字节长度（默认 16），返回长度为 2*字节数 的小写 hex](> host_secrets_token_hex n=`字节数`)*。

## 网址安全令牌

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 字节数 | any | None | 请求的字节数；None 使用接口默认值 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | text | 字节长度（默认 16），URL-safe Base64（无填充） |

这里使用`字节数`=None。

调用效应：random.read。

字节长度（默认 16），URL-safe Base64（无填充）。

完成后返回*[字节长度（默认 16），URL-safe Base64（无填充）](> host_secrets_token_urlsafe n=`字节数`)*。
