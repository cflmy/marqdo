## 音频
    + `操作`="play"
    + `id`="default"
    + `源`=""
    + `频率`=None
    + `毫秒`=None
    + `选择器`=""

构造 audio 效应。

**`spec` = > table.put in=None at="op" value=操作**
**`spec` = > table.put in=`spec` at="id" value=id**
1. `源` != ""
    **`spec` = > table.put in=`spec` at="src" value=源**
1. `频率` != None
    **`spec` = > table.put in=`spec` at="freq" value=频率**
1. `毫秒` != None
    **`spec` = > table.put in=`spec` at="ms" value=毫秒**
1. `选择器` != ""
    **`spec` = > table.put in=`spec` at="sel" value=选择器**
*> table.put in=None at="audio" value=spec*

## 存设
    + `键`
    + `值`
    + `作用域`="memory"
    + `然后`=""

SPA 客户端状态写入。优先 `作用域=memory`（页内内存）。
可选 `然后`：写入后回调，参数含 `{ok, op, key, scope}`。

`spec` =

| op | key | value | scope |
|----|-----|-------|-------|
| set | `键` | `值` | `作用域` |

1. `然后` != ""
    **`spec` = > table.put in=spec at="then" value=然后**
*> table.put in=None at="storage" value=spec*
