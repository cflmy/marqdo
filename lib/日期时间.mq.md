日历时刻 map `{unix, zone, iso}`（中层 Mid2 M7）。固定偏移和内嵌 IANA 时区与夏令时规则。

处理时间戳、IANA 时区和当地日历。

能力与边界：zone 保留数值偏移，timezone 保留 IANA 身份。加按经过的秒数计算；加日历日保持当地钟点。夏令时缺口失败，重叠时间须明确选择策略。

本文件就是调用和开发手册：直接导入此文件，或用 marqdo call 按下面的函数标题调用。参数表说明类型和默认值；未填默认值的参数必须提供。返回表是渐进契约，后文说明失败与边界。

实现入口：[src/host/datetime.rs](../src/host/datetime.rs)、[src/host/data_ops.rs](../src/host/data_ops.rs)

开发时保持中英文语义一致，先组合公开库；仅在 OS 或算法边界添加宿主原语并声明效应。修改后运行 marqdo check --narrative-ratio 本文件，并执行 tests/stdlib_tasks.rs 的真实任务。

## 解析当地时间

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 内容 | text | 必填 | 本操作读取、转换或输出的文本 |
| 时区 | text | 必填 | 本操作接受的固定偏移或命名时区 |
| 歧义处理 | text | "reject" | 夏令时重叠处理：reject、earliest 或 latest |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | map | 解析 IANA 时区的当地时间并返回结果记录；夏令时缺口失败，重叠须选择 reject/earliest/latest。格式为年-月-日 时:分:秒。 |

这里使用`内容`、`时区`、`歧义处理`="reject"。

调用效应：pure。

直接调用此函数：

```sh
marqdo call lib/日期时间.mq.md 解析当地时间 '内容="2024-11-03 01:30:00"' '时区="America/New_York"' '歧义处理="earliest"' --effects none --json
```

解析 IANA 时区的当地时间并返回结果记录；夏令时缺口失败，重叠须选择 reject/earliest/latest。格式为年-月-日 时:分:秒。

完成后返回*[解析 IANA 时区的当地时间并返回结果记录；夏令时缺口失败，重叠须选择 reject/earliest/latest](> host_datetime_local text=`内容` zone=`时区` ambiguity=`歧义处理`)*。
