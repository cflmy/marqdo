解析 URL 与查询串。单段编码仍用网络.网址编码。

    + `内容`

把 URL 解析成 scheme / userinfo / host / port / path / query / fragment。

调用例：[地址.解析] 内容=`u`

*> host_url_parse text=`内容`*

## 查询解析
    + `内容`

把 a=1&b=2 解析成映射；重复键变成列表。

*> host_url_query_parse text=`内容`*

## 查询串化
    + `表`

*> host_url_query_stringify map=`表`*
