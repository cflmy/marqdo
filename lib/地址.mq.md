解析 URL 与查询串。单段编码仍用网络.网址编码。

解析地址与重复查询参数。

能力与边界：重复查询键返回列表，不应假设所有值都是标量。地址编码和 HTML 转义是不同操作。

本文件就是调用和开发手册：直接导入此文件，或用 marqdo call 按下面的函数标题调用。参数表说明类型和默认值；未填默认值的参数必须提供。返回表是渐进契约，后文说明失败与边界。

实现入口：[src/host/url_ops.rs](../src/host/url_ops.rs)

开发时保持中英文语义一致，先组合公开库；仅在 OS 或算法边界添加宿主原语并声明效应。修改后运行 marqdo check --narrative-ratio 本文件，并执行 tests/stdlib_tasks.rs 的真实任务。

## 解析

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 内容 | any | 必填 | 本操作读取、转换或输出的文本 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | 把 URL 解析成 scheme / userinfo / host / port / path / query / fragment |

这里使用`内容`。

调用效应：pure。

把 URL 解析成 scheme / userinfo / host / port / path / query / fragment。

调用例：[地址.解析] 内容=`u`

完成后返回*[把 URL 解析成 scheme / userinfo / host / port / path / query / fragment](> host_url_parse text=`内容`)*。

## 查询解析

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 内容 | any | 必填 | 本操作读取、转换或输出的文本 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | 把 a=1&b=2 解析成映射；重复键变成列表 |

这里使用`内容`。

调用效应：pure。

直接调用此函数：

```sh
marqdo call lib/地址.mq.md 查询解析 '内容="tag=a&tag=b&name=Marqdo"' --effects none --json
```

把 a=1&b=2 解析成映射；重复键变成列表。

完成后返回*[把 a=1&b=2 解析成映射；重复键变成列表](> host_url_query_parse text=`内容`)*。
