## 加载原生

加载 `plugins/agent` 共享库。顺序：环境变量 `MARQDO_AGENT_PLUGIN`，否则 `marqdo ext add agent` 安装路径（`host_ext_native_path`）。

*`环境路径` = > 取环境 名=MARQDO_AGENT_PLUGIN *
+ `环境路径`
  **> 加载 路径=`环境路径`**
+ *
  *`原生` = > host_ext_native_path name=agent *
  + `原生`
    **> 加载 路径=`原生`**
  + *
    > 打印 内容=ext/智能体: 请设置 MARQDO_AGENT_PLUGIN 或执行 marqdo ext add agent
    > 退出 码=1

# 智能体
    - 根

构造工作区句柄。可选 `根=`；否则从工作目录向上 `agent_find_root`。

+ `根`
  *`r` = `根`*
+ *
  *`起点` = > 工作目录 *
  *`r` = > agent_find_root start=`起点` markers=agents,runbooks,marqdo.agent.json *

*`t` = > parse text={"p":"{\"_type\":\"智能体\",\"root\":","s":"}"} *
*`qr` = > quote text=`r` *
*`p` = > get value=`t` key=p *
*`s` = > get value=`t` key=s *
*`raw` = `p` + `qr` + `s` *
**> parse text=`raw`**
