电路构造：需要保留并继续操作一个量子程序时，从这里开始。

初态为全零态，每次施加都返回新电路，必须接住返回值才能继续。比特 0 对应基矢标签
最右位，角度单位为弧度。默认支持 1–12 比特；MARQDO_QUANTUM_MAX_QUBITS 可调整
限制，硬上限 16。态矢量内存按 2^n 增长，密度和施密特另有限制。

读懂 → 执行 → 观察

下面的完整 shell 实验造出贝尔态，再交给[模拟模块](../模拟/索引.mq.md)观察。
00 和 11 的概率应各约 0.5。单引号保护会话引用，避免 shell 提前展开变量。
所有命令使用同一会话 handbook，每一步覆盖 qc 绑定，不改动旧电路值。

```sh
marqdo call ext/quantum/量子/电路/索引.mq.md 新建 比特数=2 --effects plugin --session handbook --toget qc --json
marqdo call ext/quantum/量子/电路/索引.mq.md 哈达玛 '电路=$qc' 比特=0 --effects plugin --session handbook --toget qc --json
marqdo call ext/quantum/量子/电路/索引.mq.md 控非 '电路=$qc' 控制=0 目标=1 --effects plugin --session handbook --toget qc --json
marqdo call ext/quantum/量子/模拟/索引.mq.md 概率 '电路=$qc' --effects plugin --session handbook --json
```

创建线路或预载步骤表：使用 新建，下一步为 模拟模块取结果。

叠加、基态与相位操作：使用 哈达玛、泡利X、泡利Y、泡利Z、相位S、相位T、单位，下一步为 概率。

连续控制：使用 绕X、绕Y、绕Z，下一步为 参数单位为弧度。

纠缠与路由：使用 控非、控相、交换，下一步为 态模块施密特分解。

组合片段、自定义门：使用 追加、施加，下一步为 门模块提供门。

教学分层或读出：使用 屏障、测量标记，下一步为 可视化或运行采样。

下方电路对象保留作者方法链；其模拟、密度和绘图方法是便利入口，完整工具契约在
对应模块。不要尝试无接收者调用实例方法，直接调用对象之前的自由工具即可。

开发路线

新电路配方优先在[根索引](../索引.mq.md)组合已有工具。只有组合与自定义门都无法
表达时才扩原生能力：修改 plugins/quantum/src/sim.rs 和同目录 src/lib.rs，随后
同步本页自由工具、作者方法及英文镜像。验证两个后端，并保留
 tests/ext/quantum-steps-smoke.mq.md 的作者步骤表行为。

## 新建

| 参数 | 类型 | 说明 |
|------|------|------|
| 比特数 | number | 线宽 |
| 步骤 | any | 可选门表或 None |

创建宽度为 `比特数`=1 的态矢量电路。可选 `步骤`=None 表示不预载门表。

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 新电路句柄 |

> 能力.加载
*> quantum_circuit_new qubits=`比特数` steps=`步骤`*

# 电路

| 参数 | 类型 | 说明 |
|------|------|------|
| 比特数 | number | 默认 1 |
| 步骤 | any | 默认 None |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 新的电路值，接住返回值以继续 |

输入：`比特数`=1, `步骤`=None。

状态向量电路，初态为全零。可选步骤表预载门列。方法追加门并返回新句柄，供作者链式写法；智能体更宜用上方 ## 工具配合 marqdo call。测量标记只影响采样，不坍缩概率所用的理想态。

> 能力.加载
*> quantum_circuit_new qubits=`比特数` steps=`步骤`*
