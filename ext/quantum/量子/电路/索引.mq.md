电路是 n 条线上的有序门列，初态为全零。可用本页 ## 工具逐步构造，或用对象
「电路」的方法链。测量标记只影响采样，不坍缩理想概率所用的态矢量。

## 给智能体
若你只拿到本文件，每个 ## 都是工具。一律加 --effects plugin。

创建两比特电路并保存为 qc：

调用示例（纯文本）：
  marqdo call ext/quantum/量子/电路/索引.mq.md 新建 比特数=2 --effects plugin --session s --toget qc --json

在比特 0 上施加哈达玛：

调用示例（纯文本）：
  marqdo call ext/quantum/量子/电路/索引.mq.md 哈达玛 电路=$qc 比特=0 --effects plugin --session s --toget qc --json

控非 0→1：

调用示例（纯文本）：
  marqdo call ext/quantum/量子/电路/索引.mq.md 控非 电路=$qc 控制=0 目标=1 --effects plugin --session s --toget qc --json

若你只拿到本文件，这里没有「概率」这个 ## 工具。控非之后请在同一会话调用模拟模块
（不要在本文件上发明概率工具）：

调用示例（纯文本）：
  marqdo call ext/quantum/量子/模拟/索引.mq.md 概率 电路=$qc --effects plugin --session s --json

作者程序可导入本文件并使用对象电路（方法如哈达玛、控非）。智能体优先用上面的
marqdo call，再调模拟取振幅或概率。

## 新建
创建宽度为 `比特数`=1 的态矢量电路。可选 `步骤`=None 表示不预载门表。

| 参数 | 类型 | 说明 |
|------|------|------|
| 比特数 | number | 线宽 |
| 步骤 | any | 可选门表或 None |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 新电路句柄 |

> 能力.加载
*> quantum_circuit_new qubits=`比特数` steps=`步骤`*

## 哈达玛
对已有 `电路` 的 `比特`=0 施加哈达玛。

| 参数 | 类型 | 说明 |
|------|------|------|

| 比特 | number | 目标线 |
