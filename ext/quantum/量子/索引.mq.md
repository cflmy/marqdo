## 如何执行任意工具

Marqdo 用下面的 shell 命令形状，从 Markdown 文件里运行一个函数。请原样复制，
再替换 FILE、FUNCTION 与参数。

调用示例（纯文本）：
  marqdo call FILE FUNCTION 名=值 名=值 --effects plugin --json

FILE 总是 ext/quantum/量子/ 下的路径，通常以 索引.mq.md 结尾。FUNCTION 是该文件中 ##
标题的精确名字（例如 新建、哈达玛、概率）。嵌套的 ### 用 parent.child 路径。
本包必须加 --effects plugin，因为模拟器是原生插件；不加会被拒绝。需要机器可读
结果时加 --json。若要在下一步复用返回值，加 --session 某id 与 --toget 名字
（或在命令末尾写 toget 名字）。之后参数可用 电路=$名字。插件句柄靠会话日志
跨进程重建。参数值可以是数字、引号文本、True/False/None、以 [ 或 { 开头的 JSON、
或 $名字。不要调用 确保插件 或任何 host 星号 API；领域文件会自行加载插件。

验证本包可用的最小命令（无工具参数）：

调用示例（纯文本）：
  marqdo call ext/quantum/量子/索引.mq.md 贝尔态 --effects plugin --json

## 贝尔态

本索引上的一键编排工具，无参数。在比特 0 上哈达玛再控非 0→1，返回理想基矢概率。
只要演示结果时用本工具；需要中间句柄时用上面的分步 call。

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 基矢标签到概率的映射 |

精确命令：

调用示例（纯文本）：
  marqdo call ext/quantum/量子/索引.mq.md 贝尔态 --effects plugin --json

**qc = > 电路.新建 比特数=2 步骤=None**
**qc = > 电路.哈达玛 电路=`qc` 比特=0**
**qc = > 电路.控非 电路=`qc` 控制=0 目标=1**
*> 模拟.概率 电路=`qc`*
