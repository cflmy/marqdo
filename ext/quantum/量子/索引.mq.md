量子库开发手册：先读本索引，运行一个可核对的实验，再打开负责下一问题的模块。
本文件既是包的真实程序，也是使用与开发指引。下方可调用标题就是工具，周围叙述解释
何时、为何使用它们，不需要另一份 skill manifest。

从可核对的结果开始

以下命令互相独立，不需要会话。贝尔态 00、11 概率应各约 0.5；纠缠分析还返回
ZZ 关联约 1、约化纯度约 0.5、施密特熵约 ln(2)。以 1e-9 容差比较数值，
不要把浮点 JSON 字符串与字面量 0.5 作精确文本比较。

```sh
marqdo call ext/quantum/量子/索引.mq.md 贝尔态 --effects plugin --json
marqdo call ext/quantum/量子/索引.mq.md 纠缠分析 --effects plugin --json
```

根据下一问题导航

需要继续编辑电路，调用本页贝尔电路并通过会话保存返回值。需要其他初始程序，打开
[电路](电路/索引.mq.md)：新建、哈达玛、泡利X/Y/Z、相位S/T、单位、绕X/Y/Z、
控非、控相、交换、施加、追加、屏障、测量标记覆盖构造和组合。

定义具名或公式算符，打开[门](门/索引.mq.md)，那里还有矩阵导出与比较。
观察精确振幅、纯态、概率或含噪采样，打开[模拟](模拟/索引.mq.md)。
计算张量积、保真度、施密特分割，打开[态](态/索引.mq.md)。混合态、部分迹、
期望与本征谱在[密度](密度/索引.mq.md)，SVG 轨线、概率、布洛赫、qsphere、multibloch 和矩阵图在
[可视化](可视化/索引.mq.md)。每个子入口都给出完整实验、输入输出约定和开发路线。

英文工具见[英文根索引](../index.mq.md)。双语目录共用一个插件并用相同科学期望验证，
选好一棵树后按对应参数名调用。[能力](能力/索引.mq.md)用于诊断插件，不是实验的
前置手动步骤；日常工具会自行加载。

安装与定位源码

下面示例以当前目录能看见包源码为前提。安装用户把命令第一个文件参数换为实际
安装路径，默认 ~/.marqdo/ext/quantum/量子/索引.mq.md。包内导入通过扩展搜索根解析。

```text
marqdo ext add quantum
marqdo ext list
```

在本仓库开发时先构建本地插件。安装过多版本时，将 MARQDO_QUANTUM_PLUGIN 指向
 target/debug/libquantum.so 的绝对路径，其他平台使用对应动态库名。不要把
MARQDO_EXT 指向仓库 ext 后执行 ext add；安装产物与编辑源码各有自己的位置。

```text
source scripts/dev-env.sh
cargo build --locked -p marqdo_plugin_quantum
```

理解一次调用

基本形式为 marqdo call 文件 函数 名=值 --effects plugin --json。函数名取真实可调用
标题；嵌套工具使用 parent.child。作者对象内读取 self 的标题是实例方法，需要接收者，
命令行直接使用本包自由工具；写作者程序时导入同一模块即可。

参数支持数字、文本、True/False/None、JSON 列表或映射、会话引用。给文本字面量、JSON 和美元引用
加 shell 单引号：'名="H"' 保留 CLI 所需的文本引号；'电路=$qc' 才是发送给 Marqdo 的引用；裸写 电路=$qc 会先被 shell
展开。带 --json 时，同时检查退出码与 ok，再读取 result；失败说明不是有效句柄。

完整的持久实验

以下命令可按顺序执行，都使用 handbook 会话。--toget 只保存当前调用返回值。
施门保留旧值，所以每步必须接住新电路；不带 --toget 的观察不会覆盖已有绑定。
最后结果应约 0.5：贝尔整体是纯态，任一单比特子系统却是最大混合态。

```sh
marqdo call ext/quantum/量子/索引.mq.md 贝尔电路 --effects plugin --session handbook --toget qc --json
marqdo call ext/quantum/量子/模拟/索引.mq.md 概率 '电路=$qc' --effects plugin --session handbook --json
marqdo call ext/quantum/量子/密度/索引.mq.md 从态 '态=$qc' --effects plugin --session handbook --toget rho --json
marqdo call ext/quantum/量子/密度/索引.mq.md 部分迹 '密度=$rho' '保留=[0]' --effects plugin --session handbook --toget reduced --json
marqdo call ext/quantum/量子/密度/索引.mq.md 纯度 '密度=$reduced' --effects plugin --session handbook --json
```

会话默认保存在 .marqdo/call-sessions，MARQDO_CALL_SESSION_DIR 可改变目录。
跨进程插件调用通过 journal 重放。保持会话短小，修改源码或插件版本后换新会话，
重放可能重复绘图输出等插件效果。不要复制某个实现版本的 JSON 来手工伪造句柄。

科学约定与边界

比特 0 在基矢最右位，泡利串最高位在左；角度用弧度。态矢量默认上限 12，比特
限制可由环境调整但硬上限为 16；密度与施密特上限六比特。施密特 A 占低位分割数，
熵单位为自然对数 nats。

精确模拟、概率、保真度、从电路构造密度都忽略教学噪声。只有运行采样使用已附加的
bitflip、depolarizing、amplitude_damping 通道。测量标记选择采样线，不坍缩理想态。
混合矩阵构造只核对厄米性与形状，不保证半正定或迹为 1。实验的科学解释必须遵循
这些边界，各模块入口提供独立反向校验。

用同一份知识写作者程序

把以下内容存为 bell.mq.md，执行 marqdo run bell.mq.md。步骤表就是线路规格，
程序打印的两个权重应各约 0.5。frontmatter 导入已有模块；GFM 记录表首列为 @，逗号分隔的线号依次表示控制与目标。
公式也可以绑定后交给门的自定义工具或作者构造器，不必再翻译为另一套结构。

开发时复用现有能力

新增实验通常只需在本索引组合模块，并把问题、输入、期望和局限写在步骤旁。
下方纠缠分析展示这种编排。新增酉算符通常使用门的自定义工具，无需新增 ABI。

确实需要新原语时，先读归属模块的开发路线，再增加自由工具、保留作者方法，并同步
英文镜像。数值演化位于 plugins/quantum/src/sim.rs，代数在 linalg.rs，SVG 在 draw.rs，
ABI 注册在同目录 src/lib.rs。插件加载只经过能力边界。新增文件还需更新
src/ext_cli.rs 的包文件列表，让安装用户能得到它。

参数默认值写进叙述，参数契约紧跟标题，返回契约也必须放在首条执行语句之前。
当前 extract_function_contract 只读取该区域，cap.load 或能力.加载 之后的返回表只是
说明而非生效契约。类型使用现有 number/text/bool/any；句柄的来源与形状用叙述交代，
不要声称新增了领域类型检查器。把具体意图与操作交错书写，不能靠重复套话凑叙述比例。

普通说明节名保持纯叙述：## 会生成真实可调用符号。工具树中只出现可执行工具和
对象方法。导航使用源码链接与已有 knowledge inspect/resolve，稳定符号由编译器
产生，不手工维护第二份工具目录。

```text
marqdo knowledge ext/quantum --json inspect 纠缠分析
marqdo check --narrative-ratio ext/quantum/量子/索引.mq.md
cargo test --locked --test quantum_handbook
cargo test --locked --test call_cli quantum_
cargo test --locked --test gold ext_quantum -- --test-threads=1
```

手册测试直接执行双语文档的 sh 围栏与作者程序，对照独立科学期望，并验证 Tree 与
Bytecode。例子不能照抄运行就是公共接口缺陷，叙述比例再高也不能替代。既有量子
金样继续约束噪声、公式、SVG 与对象方法，验证不需要网络或 LLM。
本轮采用 next/010–012 中由 call 自然派生的简洁能力；更复杂的自我改进智能体和
持久交互分支仍是未来规划，不作为当前量子库已经具备的承诺。

失败后如何恢复

插件缺失：检查能力入口，构建或安装 quantum，再重试最小贝尔命令。会话绑定不存在：
使用同一个会话名，先重跑生产者，再运行消费者。设置噪声后理想概率未变：用运行
观察含噪采样。维数或形状失败：按上面的边界修正输入，不要静默缩小科学问题。
错误信封不能当作空的成功结果继续传递。

## 贝尔电路

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 两比特电路，可交给模拟、密度或绘图 |

无参数制备贝尔 Φ+ 线路，初态为 00。先在最低位制造等权叠加，
再由该位控制另一位翻转，把振幅关联到 00 和 11。
工具返回线路而非概率，便于继续施门、设置噪声或独立验证纠缠。
每一步接住新电路值，原值不被隐式修改。

**qc = 电路.新建 比特数=2 步骤=None**

先让最低位具有两条等权路径，再把路径信息传播给第二条线。

**qc = 电路.哈达玛 电路=`qc` 比特=0**
*> 电路.控非 电路=`qc` 控制=0 目标=1*

## 贝尔态

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 基矢概率映射；00、11 各约 0.5 |

无参数演示工具，复用本页贝尔电路的真实制备步骤，只返回理想概率。
00 和 11 各约一半，其余基矢为零；这是计算基关联，单靠概率还不能证明纠缠，
因此需要纠缠证据时继续调用本页纠缠分析，对照约化纯度与 ZZ 期望。

**qc = > 贝尔电路**
*> 模拟.概率 电路=`qc`*

## 纠缠分析

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | probabilities、purity、reduced_purity、zz、schmidt；不写文件 |

无参数实验，从同一条贝尔线路交叉观察整体、子系统与关联。
字段保留插件的科学命名，双语入口具有相同结果形状，便于机器比较。
这是一份可复用实验配方，调用者无需了解原生导出名，也不需要保存中间会话。
整体纯度应为 1，约化纯度应为 0.5，ZZ 应为 1，施密特熵为 ln(2)。
所有数值按 1e-9 容差核对；纯态概率与密度构造均使用理想演化。

**qc = > 贝尔电路**
**probs = 模拟.概率 电路=`qc`**

先构造整体密度并计算纯度。整体纯不意味着每个局部也纯，
接着只保留最低位，检查丢弃另一个比特后出现的混合性。

**rho = 密度.从态 态=`qc`**
**whole = 密度.纯度 密度=`rho`**
`kept` =

| 比特 |
|------|
| 0 |

**reduced = 密度.部分迹 密度=`rho` 保留=`kept`**
**local = 密度.纯度 密度=`reduced`**

ZZ 测量关联，不是单独的纠缠判据。施密特分解独立给出纯态两侧的
系数与熵；联合这些观察才能解释为何这是贝尔纯态而非经典概率混合。
返回表将各观察保留原值，便于调用者自行检查，而不是输出一个隐藏阈值的通过标签。

**correlation = 密度.期望 密度=`rho` 可观测量="ZZ"**
**split = 态.施密特分解 态=`qc` 分割=1**

`report` =

| probabilities | purity | reduced_purity | zz | schmidt |
|---------------|--------|----------------|----|---------|
| `probs` | `whole` | `local` | `correlation` | `split` |
