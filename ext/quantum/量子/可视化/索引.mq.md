可视化：把科学结果变成可检查的 SVG。

输入为电路时，用画电路绘制门轨线。

输入为电路时，用画概率绘制理想概率条。

输入为电路时，用画布洛赫绘制单线约化布洛赫矢量。

输入为密度时，用画密度绘制hinton、city、density、paulivec。

输入为门时，用画门绘制 gate 门符号或 matrix 热图。

输入为电路时，用画态绘制 qsphere 或 multibloch。

电路图支持 dark、light、bw；当前门和密度绘图没有主题参数。
结果为含 svg、kind 的 quantum_svg 映射。命令行 call 使用 路径=None，只返回并记录
SVG；--effects plugin 允许加载与绘图，但当前 call 宿主禁止文件写入。
需要落盘时，在作者程序中使用绘图方法，并通过 marqdo run 执行。

完整的绘图实验

先创建电路，不假设已经存在句柄。画概率的 svg 必须包含 SVG 文档，kind 为 probs；
后两步分别得到 qsphere、multibloch。省略路径等同于 None。
要保存图片，在根索引的作者程序中追加以下行，再运行该程序：

```text
**img = > `qc`.绘图 路径="bell.svg"**
```

相对路径按源文档目录解析，不一定是 shell 工作目录。

```sh
marqdo call ext/quantum/量子/电路/索引.mq.md 新建 比特数=1 --effects plugin --session handbook --toget qc --json
marqdo call ext/quantum/量子/电路/索引.mq.md 哈达玛 '电路=$qc' --effects plugin --session handbook --toget qc --json
marqdo call ext/quantum/量子/可视化/索引.mq.md 画概率 '电路=$qc' '主题="light"' --effects plugin --session handbook --json
marqdo call ext/quantum/量子/可视化/索引.mq.md 画态 '电路=$qc' 路径=None --effects plugin --session handbook --json
marqdo call ext/quantum/量子/可视化/索引.mq.md 画态 '电路=$qc' '种类="multibloch"' 路径=None --effects plugin --session handbook --json
```

开发路线

渲染实现位于 plugins/quantum/src/draw.rs 和 src/lib.rs 中的
record_plot 桥接。新增图类时同步本页和英文入口，别把文件系统操作混入电路代数。
核对 SVG 结构及数值标签，截图不能代替数值校验。保留
 tests/ext/quantum-draw-smoke.mq.md 与 quantum-viz-advanced-smoke.mq.md。
输入准备见[电路](../电路/索引.mq.md)、[门](../门/索引.mq.md)、[密度](../密度/索引.mq.md)。

## 画电路

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 电路 | any | 必填 | 调用方提供的电路 |
| 主题 | text | "dark" | dark light 或 bw |
| 路径 | any | None | 可选输出路径或 None |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 绘图结果 |

这里使用`电路`、`主题`="dark"、`路径`=None。

把 `电路` 的门和屏障画成轨线。默认 `主题`="dark"，也可选择 light 或 bw。
可选 `路径`=None 只返回 SVG，不写文件；非空路径供 run 下的作者程序使用。
主题选择只改变配色，不改变线路几何与计算含义。

这里**[调用 加载](能力.加载())**。
完成后返回*[把 电路 的门和屏障画成轨线。默认 主题="dark"，也可选择 light 或 bw。 可选 路径=None 只返回 SVG，不写文件；非空路径供 run 下的作者程序使用。 主题选择只改变配色，不改变线路几何与计算含义。](quantum_draw_circuit(circuit=`电路`, path=`路径`, kind="circuit", qubit=0, theme=`主题`))*。

## 画态

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 电路 | any | 必填 | 源电路，作理想演化 |
| 种类 | text | "qsphere" | qsphere 或 multibloch |
| 路径 | any | None | SVG 输出路径或 None |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | quantum_svg，含 kind 和 svg |

这里使用`电路`、`种类`="qsphere"、`路径`=None。

从 `电路` 观察整体纯态的振幅/相位球，或每条线的约化布洛赫球。
默认 `种类`="qsphere"，可改为 multibloch；默认 `路径`=None，不显式落盘。
qsphere 展示基矢振幅与相位，multibloch 展示各线约化态，不能由单线球图独自证明纠缠。
这两类高级态图当前使用固定配色，主题换肤仍属 Q8c 规划，不暴露无效主题参数。

这里**[调用 加载](能力.加载())**。
完成后返回*[从 电路 观察整体纯态的振幅/相位球，或每条线的约化布洛赫球。 默认 种类="qsphere"，可改为 multibloch；默认 路径=None，不显式落盘。 qsphere 展示基矢振幅与相位，multibloch 展示各线约化态，不能由单线球图独自证明纠缠。 这两类高级态图当前使用固定配色，主题换肤仍属 Q8c 规划，不暴露无效主题参数。](quantum_draw_circuit(circuit=`电路`, path=`路径`, kind=`种类`, qubit=0, theme="dark"))*。
