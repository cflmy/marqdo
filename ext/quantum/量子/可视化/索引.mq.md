把电路或密度画成 SVG。选择 kind 与主题。主题 dark（默认）、light、bw 几何一致。

## 给智能体

若你只拿到本文件，需要其它模块给出的电路或密度句柄（toget）。

调用示例（纯文本）：
  marqdo call ext/quantum/量子/可视化/索引.mq.md 画概率 电路=$qc 路径="out.svg" --effects plugin --session s --json

*None*

## 画电路

`电路` 的轨线图。默认 `主题`="dark"。可选 `路径` 落盘。

| 参数 | 类型 | 说明 |
|------|------|------|
| 电路 | any | 电路 |
| 路径 | any | 可选输出路径或 None |
| 主题 | text | dark light 或 bw |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 绘图结果 |

> 能力.加载
*> quantum_draw_circuit circuit=`电路` path=`路径` kind="circuit" qubit=0 theme=`主题`*

## 画概率

`电路` 理想态概率条。默认 `主题`="dark"。可选 `路径` 落盘。

| 参数 | 类型 | 说明 |
|------|------|------|
| 电路 | any | 电路 |
| 路径 | any | 可选路径或 None |
| 主题 | text | dark light 或 bw |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 绘图结果 |

> 能力.加载
*> quantum_draw_circuit circuit=`电路` path=`路径` kind="probs" qubit=0 theme=`主题`*

## 画布洛赫

`电路` 上单线布洛赫球。默认 `比特`=0、`主题`="dark"。可选 `路径` 落盘。

| 参数 | 类型 | 说明 |
|------|------|------|
| 电路 | any | 电路 |
| 路径 | any | 可选路径或 None |
| 比特 | number | 哪一根线 |
| 主题 | text | dark light 或 bw |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 绘图结果 |

> 能力.加载
*> quantum_draw_circuit circuit=`电路` path=`路径` kind="bloch" qubit=`比特` theme=`主题`*

## 画密度

绘制密度算符 `密度`。默认 `种类`="hinton"。可选 `路径` 落盘。

| 参数 | 类型 | 说明 |
|------|------|------|
| 密度 | any | 密度算符 |
| 路径 | any | 可选路径或 None |
| 种类 | text | hinton city density 或 paulivec |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 绘图结果 |

> 能力.加载
*> quantum_density_draw density=`密度` path=`路径` kind=`种类`*

## 画门

绘制单个 `门`。默认 `种类`="gate"。可选 `路径` 落盘。

| 参数 | 类型 | 说明 |
|------|------|------|
| 门 | any | 门句柄 |
| 路径 | any | 可选路径或 None |
| 种类 | text | gate 或 matrix |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 绘图结果 |

> 能力.加载
*> quantum_gate_draw gate=`门` path=`路径` kind=`种类`*
