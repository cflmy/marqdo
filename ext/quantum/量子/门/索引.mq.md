门是作用在一个或多个比特上的酉变换。本 skill 先写矩阵含义，再构造门句柄。
电路施加门；本页定义门是什么。

## 给智能体
若你只拿到本文件，用 marqdo call 调用 ## 工具，必须加 --effects plugin。

调用示例（纯文本）：
  marqdo call ext/quantum/量子/门/索引.mq.md 哈达玛 --effects plugin --json

作者程序也可使用本文件中的对象「门」。

*None*

## 哈达玛
哈达玛门把计算基变成等权叠加。本工具返回名为 H 的门句柄。

本工具无参数。

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 哈达玛门句柄 |

> 能力.加载
*> quantum_gate_new name="H" theta=None matrix=None*

## 泡利X
泡利 X 是比特翻转门。

本工具无参数。

| result | any | 泡利 X 句柄 |

> 能力.加载
*> quantum_gate_new name="X" theta=None matrix=None*

## 控非门
两比特受控非门句柄。施到线路上时请用电路模块并写明控制位与目标位。

本工具无参数。

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | CNOT 门句柄 |

> 能力.加载
*> quantum_gate_new name="CX" theta=None matrix=None*

## 自定义
用显式酉矩阵 `矩阵` 构造门。可选标签 `名`="U"。

| 参数 | 类型 | 说明 |
|------|------|------|
| 矩阵 | any | 酉矩阵公式或列表 |
| 名 | text | 可选标签，默认 U |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 自定义门句柄 |

> 能力.加载
*> quantum_gate_new name=`名` theta=None matrix=`矩阵`*

## 匹配
检查 `门` 是否在容差 `容差`=0.000000001 内匹配 `矩阵`。

| 参数 | 类型 | 说明 |
|------|------|------|
| 门 | any | 门句柄 |
| 矩阵 | any | 期望酉矩阵 |
| 容差 | number | 绝对容差 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | bool | 匹配则为 True |

> 能力.加载
*> quantum_gate_matches_matrix gate=`门` matrix=`矩阵` tol=`容差`*


# 门
    + `名`=None
    + `参数`=None
    + `矩阵`=None

具名内置门（名=H）或由矩阵=（嵌套 list 或公式矩阵围栏）定义的自定义酉门。自定义门可选名=（默认 U）。作者链式与智能体 ## 工具共用本对象面。

本构造返回可供链式调用的句柄，与同文件 ## 工具共用能力.加载 路径。作者程序写对象方法链；智能体优先 marqdo call 上方工具。

> 能力.加载
*> quantum_gate_new name=`名` theta=`参数` matrix=`矩阵`*

## 矩阵

返回本门句柄的显式酉矩阵，便于检查元素，或在公式构造自定义门后交给匹配矩阵验收。

本方法把领域意图写进句柄并返回结果，便于作者程序继续组合；智能体若只需单步操作也可改调同文件上方对应的 ## 工具与 marqdo call。参数默认值写在 + 形参行；调用时只覆盖需要改的项即可。

*> quantum_gate_matrix gate=`self`*

## 匹配矩阵
    + `矩阵`
    + `容差`=0.000000001

检查本门是否在绝对容差内容差内匹配给定矩阵。讲义里用公式围栏造门后，常用本方法做数值验收。

本方法把领域意图写进句柄并返回结果，便于作者程序继续组合；智能体若只需单步操作也可改调同文件上方对应的 ## 工具与 marqdo call。参数默认值写在 + 形参行；调用时只覆盖需要改的项即可。

*> quantum_gate_matches_matrix gate=`self` matrix=`矩阵` tol=`容差`*

## 绘图
    + `路径`=None
    + `种类`=gate

绘制门符号或复矩阵热力图（种类=gate 或 matrix）。可选路径落盘；亦经 record_plot 进入本会话的 view/CLI 图面。

本方法把领域意图写进句柄并返回结果，便于作者程序继续组合；智能体若只需单步操作也可改调同文件上方对应的 ## 工具与 marqdo call。参数默认值写在 + 形参行；调用时只覆盖需要改的项即可。

*> quantum_gate_draw gate=`self` path=`路径` kind=`种类`*
