量子门：先定义算符，再选择它作用的线路。

具名工具支持 I、X、Y、Z、H、S、T、Rx、Ry、Rz、CX、CZ、SWAP。旋转参数为弧度。
自定义门必须是 2^k 阶方阵，并满足 U†U = I，构造容差为 1e-6。元素可为实数或
含 re、im 的复数映射。JSON 与 Markdown 公式绑定使用同一个构造器。

完整的自定义门实验

下面矩阵交换零与一，匹配工具应返回 true，最终基矢 1 的概率应为 1。
仅构造门不会改变电路；必须调用[电路模块](../电路/索引.mq.md)的施加工具。
所有引用保存在同一会话，不需要手写或解析插件句柄。

```sh
marqdo call ext/quantum/量子/门/索引.mq.md 自定义 '矩阵=[[0,1],[1,0]]' '名="X-demo"' --effects plugin --session handbook --toget u --json
marqdo call ext/quantum/量子/门/索引.mq.md 匹配 '门=$u' '矩阵=[[0,1],[1,0]]' --effects plugin --session handbook --json
marqdo call ext/quantum/量子/电路/索引.mq.md 新建 比特数=1 --effects plugin --session handbook --toget qc --json
marqdo call ext/quantum/量子/电路/索引.mq.md 施加 '电路=$qc' '门=$u' 比特=0 --effects plugin --session handbook --toget qc --json
marqdo call ext/quantum/量子/模拟/索引.mq.md 概率 '电路=$qc' --effects plugin --session handbook --json
```

哈达玛、泡利X、泡利Z、控非门提供常用常量，其余内置门使用具名；矩阵工具导出
条目，匹配用于核对讲义公式与实现。[可视化](../可视化/索引.mq.md)的画门支持
门符号与矩阵热图。需要纠缠操作时，优先使用控制、目标明确的电路控非工具。

开发路线

新增用户酉矩阵只需自定义与独立期望矩阵，不必修改 Rust 或 ABI。新增内置门时，
先更新 plugins/quantum/src/sim.rs::named_gate_matrix 及数值测试，再同步中英入口。
保留 tests/ext/quantum-custom-gate-smoke.mq.md 中公式直接构造哈达玛门的例子。

## 哈达玛

哈达玛门把计算基变成等权叠加。本工具返回名为 H 的门句柄。

本工具无参数。

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 哈达玛门句柄 |

> 能力.加载
*> quantum_gate_new name="H" theta=None matrix=None*

## 自定义

| 参数 | 类型 | 说明 |
|------|------|------|
| 矩阵 | any | 酉矩阵公式或列表 |
| 名 | text | 可选标签，默认 U |

| 返回 | 类型 | 说明 |

| result | any | 自定义门句柄 |

## 匹配

| 参数 | 类型 | 说明 |
|------|------|------|
| 门 | any | 门句柄 |
| 矩阵 | any | 期望酉矩阵 |
| 容差 | number | 绝对容差 |

检查 `门` 是否在容差 `容差`=0.000000001 内匹配 `矩阵`。

|------|------|------|
| result | bool | 匹配则为 True |

> 能力.加载
*> quantum_gate_matches_matrix gate=`门` matrix=`矩阵` tol=`容差`*

## 具名

| 参数 | 类型 | 说明 |
|------|------|------|
| 名 | text | 内置门名 |
| 参数 | any | 旋转角或 None |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 可交给施加工具的门句柄 |

构造内置门 `名`="H"；可选 `参数`=None，Rx、Ry、Rz 必须给出弧度角。
返回可交给电路施加的门句柄，创建过程不改变任何线路。支持名称见本页开篇表述。

> 能力.加载
*> quantum_gate_new name=`名` theta=`参数` matrix=None*

## 矩阵

| 参数 | 类型 | 说明 |
|------|------|------|
| 门 | any | 门句柄 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 复数矩阵条目，每项含 re 与 im |

导出 `门` 的显式酉矩阵。每个元素含 re、im，可用于公式复核或独立矩阵比较；
本工具仅观察算符，不改变句柄，也不把门应用到任何电路。

> 能力.加载
*> quantum_gate_matrix gate=`门`*

# 门

| 参数 | 类型 | 说明 |
|------|------|------|
| 名 | any | 默认 None |
| 参数 | number | 默认 None |
| 矩阵 | any | 默认 None |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 可交给施加工具的门句柄 |

输入：`名`=None, `参数`=None, `矩阵`=None。

具名内置门（名=H）或由矩阵=（嵌套 list 或公式矩阵围栏）定义的自定义酉门。自定义门可选名=（默认 U）。作者链式与智能体 ## 工具共用本对象面。

> 能力.加载
*> quantum_gate_new name=`名` theta=`参数` matrix=`矩阵`*

## 矩阵

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 复数矩阵条目，每项含 re 与 im |

返回本门句柄的显式酉矩阵，便于检查元素，或在公式构造自定义门后交给匹配矩阵验收。

*> quantum_gate_matrix gate=`self`*

## 匹配矩阵

| 参数 | 类型 | 说明 |
|------|------|------|
| 矩阵 | any | 必填 |
| 容差 | any | 默认 0.000000001 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | bool | 容差内匹配 |

输入：`矩阵`, `容差`=0.000000001。

检查本门是否在绝对容差内容差内匹配给定矩阵。讲义里用公式围栏造门后，常用本方法做数值验收。

*> quantum_gate_matches_matrix gate=`self` matrix=`矩阵` tol=`容差`*

## 绘图

| 参数 | 类型 | 说明 |
|------|------|------|
| 路径 | any | 默认 None |
| 种类 | any | 默认 gate |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | quantum_svg，含 kind 与 svg |

输入：`路径`=None, `种类`="gate"。

绘制门符号或复矩阵热力图（种类=gate 或 matrix）。可选路径落盘；亦经 record_plot 进入本会话的 view/CLI 图面。

*> quantum_gate_draw gate=`self` path=`路径` kind=`种类`*
