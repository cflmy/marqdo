密度算符：观察子系统或显式混合态矩阵。

从态工具将理想电路或纯态转成密度；从矩阵接受 2^n 阶厄米方阵。密度操作与施密特
最多支持六比特。矩阵构造器只检查形状和厄米性，不保证半正定或迹为 1。
解释物理纯度前，应核对迹并用本征工具检查本征值。

独立的混合态校验

以下最大混合单比特矩阵迹为 1、纯度为 0.5、Z 期望为 0，无需已有电路或会话。
研究纠缠时，从贝尔电路经过从态，再以 保留=[0] 求部分迹，约化纯度也应为 0.5。

```sh
marqdo call ext/quantum/量子/密度/索引.mq.md 从矩阵 '矩阵=[[0.5,0],[0,0.5]]' --effects plugin --session handbook --toget rho --json
marqdo call ext/quantum/量子/密度/索引.mq.md 纯度 '密度=$rho' --effects plugin --session handbook --json
marqdo call ext/quantum/量子/密度/索引.mq.md 期望 '密度=$rho' '可观测量="Z"' --effects plugin --session handbook --json
marqdo call ext/quantum/量子/密度/索引.mq.md 本征 '密度=$rho' --effects plugin --session handbook --json
```

部分迹保留列表指定的零起始比特并消去其余。泡利串左端表示高位，ZZ 表示两线关联。
矩阵工具导出复数嵌套条目，本征返回 eigenvalues 与 eigenvectors。
[可视化](../可视化/索引.mq.md)画密度支持 hinton、city、density、paulivec。
从态与理想模拟一样忽略已附加教学噪声，不应当作含噪密度演化。

开发路线

新增混合态数学放入 plugins/quantum/src/linalg.rs，通过同目录 src/lib.rs 导出，
同步本页与英文镜像。构造器描述必须与真实校验能力相符。用纯态纯度 1、贝尔约化
纯度 0.5、独立矩阵的期望检验 tests/ext/quantum-linalg-smoke.mq.md。
