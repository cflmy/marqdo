纯态：比较、组合或划分一个量子态。

用模拟模块的态工具取得含 qubits、dim、amplitudes 的句柄。每个振幅是 re、im 映射；
模拟工具返回的裸振幅列表不是态句柄。保真度与施密特分解也接受电路并作理想演化。
张量积的态分支要求两个态句柄，必须先把电路转换为态。

完整的张量积实验

两个零态得到两比特零态，自身保真度为 1。张量积第一个因子占高位，第二个占低位。
施密特分割相反地按低位数定义 A，不要把这两个约定混淆。

```sh
marqdo call ext/quantum/量子/电路/索引.mq.md 新建 比特数=1 --effects plugin --session handbook --toget qc --json
marqdo call ext/quantum/量子/模拟/索引.mq.md 态 '电路=$qc' --effects plugin --session handbook --toget psi --json
marqdo call ext/quantum/量子/态/索引.mq.md 张量积 'a=$psi' 'b=$psi' --effects plugin --session handbook --toget product --json
marqdo call ext/quantum/量子/态/索引.mq.md 保真度 'a=$product' 'b=$product' --effects plugin --session handbook --json
marqdo call ext/quantum/量子/态/索引.mq.md 施密特分解 '态=$product' 分割=1 --effects plugin --session handbook --json
```

保真度是等维纯态重叠绝对值的平方。施密特返回 coeffs、ua、ub、entropy、cut、qubits；
entropy 单位为自然对数 nats，贝尔态为 ln(2)，两个系数各约 1/√2。
施密特沿用密度求解器的六比特上限，要求 0 < 分割 < 比特数。
张量积也支持矩阵因子并返回含矩阵的句柄，此时表示算符积，不自动保证归一化纯态。

开发路线

纯态代数放在本页，混合态操作放在[密度](../密度/索引.mq.md)。数学实现和独立数值
测试位于 plugins/quantum/src/linalg.rs，导出位于同目录 src/lib.rs。同步双语契约，
保留 tests/ext/quantum-linalg-smoke.mq.md。用已知正交态、积态、纠缠态作独立期望，
不要仅与实现自身比较。单线布洛赫图通过[可视化](../可视化/索引.mq.md)画布洛赫
并传入源电路。

| 参数 | 类型 | 默认 | 说明 |

| b | any | 必填 | 右因子 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 张量积结果 |

## 保真度

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| a | any | 必填 | 第一态或电路 |
| b | any | 必填 | 第二态或电路 |

| 返回 | 类型 | 说明 |
