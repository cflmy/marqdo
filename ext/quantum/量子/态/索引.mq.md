纯态是复空间中的单位向量。本包振幅用含 re、im 的映射表示。基矢标签里比特 0 在
最右侧。理想模拟忽略教学噪声；采样轨迹见模拟模块。

## 给智能体

若你只拿到本文件，用 marqdo call 调用下面的 ## 工具，并务必加 --effects plugin。

调用示例（纯文本）：
  marqdo call ext/quantum/量子/态/索引.mq.md 保真度 a=$psi b=$phi --effects plugin --json

工具名：张量积、保真度、施密特分解。

*None*

## 张量积

将 `a` 与 `b` 做张量积，得到更大空间上的态或算符。

| 参数 | 类型 | 说明 |
|------|------|------|
| a | any | 左因子 |
| b | any | 右因子 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 张量积结果 |

> 能力.加载
*> quantum_kron a=`a` b=`b`*

## 保真度

纯态 `a` 与 `b` 的保真度为重叠绝对值的平方。可传入电路句柄（取理想模拟态）。
教学噪声忽略。

| 参数 | 类型 | 说明 |
|------|------|------|
| a | any | 第一态或电路 |
| b | any | 第二态或电路 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | number | 保真度 |

> 能力.加载
*> quantum_fidelity a=`a` b=`b`*

## 施密特分解

对纯态或电路 `态` 做施密特分解。`分割`=1 表示子系统 A 的比特数（低位）。

| 参数 | 类型 | 说明 |
|------|------|------|
| 态 | any | 纯态或电路 |
| 分割 | number | 子系统 A 比特数 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 施密特数据 |

> 能力.加载
*> quantum_schmidt state=`态` cut=`分割`*
