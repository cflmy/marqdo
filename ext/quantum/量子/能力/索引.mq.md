原生能力边界：诊断插件发现后，回到领域模块继续工作。

本页定位并加载 ABI v2 量子动态库。领域工具自行调用加载，不需要每次先手动初始化。
英文 _capability 是此边界的等价语言入口，领域代码不应再实现第二套加载过程。

```sh
marqdo call ext/quantum/量子/能力/索引.mq.md 加载 --effects plugin --json
```

成功返回 null。缺失动态库会提示安装并以非零状态退出；本工具使用 sys.exit，所以
要同时检查进程状态，不能假定所有失败都有 JSON 信封。安装用 marqdo ext add quantum，
源码开发用 cargo build -p marqdo_plugin_quantum。MARQDO_QUANTUM_PLUGIN 可指定
开发动态库的绝对路径。

仅能力边界导入 lib/plugin，不向领域代码新增加载器或 host_*。修改发现流程时，
同时验证双语根工具与 tests/call_cli.rs，再回到[电路](../电路/索引.mq.md)。

## 加载

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 加载成功后为空 |

通过 plugin.native_path 找到 ABI v2 quantum 共享库，再 plugin.load。若缺失则打印
安装提示并以非零退出。成功后本进程内可用 quantum_* 符号。本包中只有这里应直接
接触 lib/plugin。领域模块在需要模拟器的工具开头调用加载。

本工具无参数。

得到**`p` = [定位已安装的原生插件](plugin.native_path(name="quantum"))**。
1. `p`
  这里**[加载本操作依赖的原生插件](plugin.load(path=`p`))**。
2. *
  这里**[输出本步已准备的消息](print(text="ext/quantum/量子: 未找到原生 quantum 插件（请 build marqdo_plugin_quantum 或 marqdo ext add quantum）"))**。
  这里**[按指定退出码结束本次运行](sys.exit(code=1))**。
完成后返回*None*。
