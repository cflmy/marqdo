模拟回答「这条电路会怎样」。理想路径（模拟、态、概率）忽略教学噪声。运行工具
做计算基采样，并在已附着噪声时应用噪声。超宽电路会被插件拒绝，不会静默截断。

## 给智能体

若你只拿到本文件，需要先有电路句柄（通常来自电路模块的 toget）。然后：

调用示例（纯文本）：
  marqdo call ext/quantum/量子/模拟/索引.mq.md 概率 电路=$qc --effects plugin --session s --json

其它工具：模拟、态、运行、噪声。一律 --effects plugin。

*None*

## 模拟

返回 `电路` 的理想态矢量振幅。

| 参数 | 类型 | 说明 |
|------|------|------|
| 电路 | any | 待演化电路 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 振幅列表 |

> 能力.加载
*> quantum_simulate circuit=`电路`*

## 态

与模拟相同：取 `电路` 的理想振幅，打包为态对象，便于后续保真度或密度构造。

| 参数 | 类型 | 说明 |
|------|------|------|
| 电路 | any | 待演化电路 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 理想态 |

> 能力.加载
*> quantum_state circuit=`电路`*

## 概率

`电路` 理想态的基矢标签到概率映射。比特 0 为最右侧。忽略噪声。

| 参数 | 类型 | 说明 |
|------|------|------|
| 电路 | any | 待读取电路 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 概率映射 |

> 能力.加载
*> quantum_probabilities circuit=`电路`*

## 运行

对 `电路` 采样。默认 `次数`=1024、`种子`=1。若有教学噪声则轨迹含噪声。

| 参数 | 类型 | 说明 |
|------|------|------|
| 电路 | any | 待采样电路 |
| 次数 | number | 采样次数 |
| 种子 | number | 随机种子 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 计数或采样结果 |

> 能力.加载
*> quantum_run circuit=`电路` shots=`次数` seed=`种子`*

## 噪声

在 `电路` 上附着种类 `种类`、强度 `强度` 的教学噪声。理想概率工具忽略它。

| 参数 | 类型 | 说明 |
|------|------|------|
| 电路 | any | 电路 |
| 种类 | text | 噪声族名 |
| 强度 | number | 单位区间强度 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 带噪声元数据的电路 |

> 能力.加载
*> quantum_noise circuit=`电路` kind=`种类` p=`强度`*
