# 电路
    + `比特数`=1
    + `步骤`=None

状态向量电路（默认 |0…0⟩）。可选 `步骤=` 门序列表。方法追加门并返回更新后的句柄。

> 确保插件
**> quantum_circuit_new qubits=`比特数` steps=`步骤`**

## 屏障

仅可视化分隔（不改态）。

**> quantum_barrier circuit=`self`**

## 测量
    + `比特`=None

标记计算基读出（空 = 全部比特）。影响 `运行` 报告哪些位。

**> quantum_measure circuit=`self` qubits=`比特`**

## 追加
    + `操作`

追加另一电路的 ops，或 `{gate,qubits}` 操作表。

**> quantum_append circuit=`self` op=`操作`**

## 施加
    + `门`
    + `比特`=0

将门句柄（具名或 `矩阵=` 自定义）施加到 `比特`（整数或列表）。

**> quantum_apply circuit=`self` gate=`门` qubits=`比特`**

## 噪声
    + `种类`
    + `概率`

教学噪声，供 `运行` 轨迹使用（`bitflip` / `depolarizing` / `amplitude_damping`，或中文：比特翻转 / 退极化 / 振幅阻尼）。`模拟` / `概率` 忽略。

**> quantum_noise circuit=`self` kind=`种类` p=`概率`**

## 模拟

返回态矢量振幅 `{re,im}`（理想；无噪声）。

**> quantum_simulate circuit=`self`**

## 态

理想态矢量（与 `模拟` 相同振幅）。

**> quantum_state circuit=`self`**

## 概率

基矢标签 → 概率（qubit 0 为最右侧比特）。理想；忽略噪声。

**> quantum_probabilities circuit=`self`**

## 运行
    + `次数`=1024
    + `种子`=1

计算基采样（`种子=` 可复现）。若设置了电路噪声则启用。

**> quantum_run circuit=`self` shots=`次数` seed=`种子`**

## 绘图
    + `路径`=None
    + `种类`=circuit
    + `比特`=0

电路轨线 / 概率条 / 布洛赫球（种类 circuit、probs 或 bloch）。经 record_plot 进入 view/CLI plots。

**> quantum_draw_circuit circuit=`self` path=`路径` kind=`种类` qubit=`比特`**

# 门
    + `名`=None
    + `参数`=None
    + `矩阵`=None

具名内置门（`名=H`）或由 `矩阵=`（嵌套 list 或公式矩阵围栏）定义的自定义酉门。自定义门可选 `名=`（默认 `U`）。

> 确保插件
**> quantum_gate_new name=`名` theta=`参数` matrix=`矩阵`**

## 矩阵

**> quantum_gate_matrix gate=`self`**

## 匹配矩阵
    + `矩阵`
    + `容差`=0.000000001

**> quantum_gate_matches_matrix gate=`self` matrix=`矩阵` tol=`容差`**

## 绘图
    + `路径`=None
    + `种类`=gate

门符号或复矩阵热力图（`种类=gate|matrix`）。经 `record_plot` 记录。

**> quantum_gate_draw gate=`self` path=`路径` kind=`种类`**
