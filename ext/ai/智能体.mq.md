## 构建单步上下文
    + `智能体`
    + `任务`
    + `源码深度`=default
    + `技能深度`=default

组装可读提示：站立提示、任务、**调用位置**、工具、**预算**源码 + Skill，以及人可见的行动约定。
编排 `.mq.md` 即真相源（代码即文档）。默认预算防爆窗；可先 `读取：source|skill` 加深再答或 `调用：`。
实现委托 `agent.build_step_context`（与英文版同源）。

**> agent.build_step_context agent=`智能体` task=`任务` source_depth=`源码深度` skill_depth=`技能深度`**

解析人可读调用行：`CALL:<名>` 或 `调用：<名>` / `调用:<名>`。

*esc = > json.parse text={"nl":"\n"}*
*nl = > json.get value=`esc` key="nl"*
*text = > trim value=`回复`*
*lines = > split value=`text` sep=`nl`*
*found = 空*

- [`line`](`lines`)
  *t = > trim value=`line`*
  *parts = > split value=`t` sep=:*
  *n = > len value=`parts`*
  1. `n` > 1
    *head = > at value=`parts` index=0*
    *head = > trim value=`head`*
    *rest = > at value=`parts` index=1*
    *rest = > trim value=`rest`*
    1. `head` == CALL
      *found = rest*
    2. `head` == 调用
      *found = rest*
    3. *
      *_ = 1*
  2. *
    *_ = 1*

**found**

## 单步
    + `任务`
    + `写回`=真
    + `流式`=假
    + `打印增量`=假

原子一轮：上下文 → 大模型 → 可选子任务调工具。返回 **map**（`status`、`task`、`decision`；成功含 `result`，可选 `tool` / `tool_result`；失败含 `error`）。默认（`写回=真`）将结果写入调用行下的命名槽 `ok` / `error`；传 `写回=假` 可关闭。

流式=真 时走 SSE；打印增量=真 边读边打印。返回 map 仍是最终 result 文本。

*ctx = > 构建单步上下文 智能体=`自` 任务=`任务`*
*id = > json.get value=`自` key="id"*
*model = > json.get value=`自` key="model"*
*tools = > json.get value=`自` key="tools"*

*user_turn = > json.parse text={"role":"user"}*
*user_turn = > json.set map=`user_turn` key="content" value=`任务`*
> agent_history_append id=`id` item=`user_turn`

1. `流式`
  *evs = > model.运行 提示=`ctx` 流式=真 打印增量=`打印增量`*
  *reply = > 大模型.流式结果 事件=`evs`*
2. *
  *reply = > model.运行 提示=`ctx`*

*reply = > trim value=`reply`*
*decision = reply*
*tool_name = > 提取工具名 回复=`reply`*
*out = > json.parse text={"status":"ok"}*
*out = > json.set map=`out` key="task" value=`任务`*
*out = > json.set map=`out` key="decision" value=`decision`*

1. `tool_name`
  *tool_out = > 运行工具 工具=`tools` 名=`tool_name`*
  *tool_s = > json.stringify value=`tool_out`*
  *deny = > split value=`tool_s` sep="Tool not allowed"*
  *deny_n = > len value=`deny`*
  1. `deny_n` > 1
    *out = > json.set map=`out` key="status" value="error"*
    *out = > json.set map=`out` key="error" value=`tool_s`*
    *reply = tool_s*
  2. *
    *task_s = > json.stringify value=`任务`*
    *fp = "The user asked:"*
    *fp = fp + task_s*
    *fp = fp + ". Tool"*
    *fp = fp + tool_name*
    *fp = fp + "ran via subtask and returned:"*
    *fp = fp + tool_s*
    *fp = fp + ". Reply to the user briefly."*
    1. `流式`
      *evs2 = > model.运行 提示=`fp` 流式=真 打印增量=`打印增量`*
      *reply = > 大模型.流式结果 事件=`evs2`*
    2. *
      *reply = > model.运行 提示=`fp`*
    *out = > json.set map=`out` key="tool" value=`tool_name`*
    *out = > json.set map=`out` key="tool_result" value=`tool_s`*
    *out = > json.set map=`out` key="result" value=`reply`*
2. *
  *out = > json.set map=`out` key="result" value=`reply`*

*as_turn = > json.parse text={"role":"assistant"}*
*as_turn = > json.set map=`as_turn` key="content" value=`reply`*
> agent_history_append id=`id` item=`as_turn`

1. `写回`
  *body = > json.stringify value=`out`*
  *st = > json.get value=`out` key="status"*
  1. `st` == "ok"
    > host_writeback_record value=`body` key="ok"
  2. *
    > host_writeback_record value=`body` key="error"
2. *
  *_ = 1*

**out**
