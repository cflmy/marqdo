本文件提供中文试跑门面，对应[试跑实现](sandbox.mq.md)。先读[中文入口](索引.mq.md)了解模型调用与 CoW 试跑的区别。试跑产生的文件变更和诊断供调用者检查，提升变更必须走已有显式流程；试跑返回不等于宿主工作区已经更新。保持失败、取消和提升的结果可区分，避免复制一份隔离实现。

## 打开

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 根 | any | None | 当前会话或工程明确授权的根目录 |

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | any | 按根目录与能力配置打开同源 CoW 试运行会话，不立即修改真实文件树。 |

这里使用`根`=None。

按根目录与能力配置打开同源 CoW 试运行会话，不立即修改真实文件树。

完成后返回*[调用 open](sandbox.open(root=`根`))*。

## 写入

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| id | any | 必填 | Identifier produced or selected by the corresponding resource operation |
| 路径 | any | 必填 | 授权根目录内的文件路径 |
| 文本 | any | 必填 | 本操作接收的文本 |

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | any | 把文本写入试运行会话的覆盖层，提交前不改真实文件。 |

这里使用`id`、`路径`、`文本`。

把文本写入试运行会话的覆盖层，提交前不改真实文件。

完成后返回*[调用 write](sandbox.write(id=`id`, path=`路径`, text=`文本`))*。
