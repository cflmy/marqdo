## 运行
    + `提示`
    + `流式`=False
    + `打印增量`=False

使用 `自` / `self` 句柄字段做聊天补全。

`流式=真` 时返回事件列表（`delta` / `done` / `error`），默认同今日返回整段文本。`打印增量=真` 边读边打印。

*`api_key` = > json.get value=`自` key=api_key *
*`base_url` = > json.get value=`自` key=base_url *
*`model` = > json.get value=`自` key=model *
*`suffix` = > json.get value=`自` key=suffix *
*`bearer` = > json.get value=`自` key=bearer *
*`p1` = > json.get value=`自` key=p1 *
*`p2` = > json.get value=`自` key=p2 *
*`p3` = > json.get value=`自` key=p3 *
*`h1` = > json.get value=`自` key=h1 *
*`h2` = > json.get value=`自` key=h2 *
*`url` = `base_url` + `suffix` *
*`auth` = `bearer` + `api_key` *
*`q_auth` = > json.quote text=`auth` *
*`hdr_raw` = `h1` + `q_auth` + `h2` *
*`headers` = > json.parse text=`hdr_raw` *
*`q_model` = > json.quote text=`model` *
*`q_prompt` = > json.quote text=`提示` *

1. `流式`
  *`p3s` = "}],\"stream\":true}" *
  *`body` = `p1` + `q_model` + `p2` + `q_prompt` + `p3s` *
  *`resp` = > 网络.提交流式 地址=`url` 内容=`body` headers=`headers` 打印增量=`打印增量` *
  *`status` = > json.get value=`resp` key=status *
  *`events` = > json.get value=`resp` key=events *
  1. `status` == 200
    **`events`**
  2. *
    > 打印 内容=ext/ai/大模型: HTTP 错误（流式）
    > 打印 内容=`status`
    > 系统.退出 码=1
2. *
  *`body` = `p1` + `q_model` + `p2` + `q_prompt` + `p3` *
  *`resp` = > 网络.提交 地址=`url` 内容=`body` headers=`headers` *
  *`status` = > json.get value=`resp` key=status *
  *`raw` = > json.get value=`resp` key=body *
  1. `status` == 200
    *`data` = > json.parse text=`raw` *
    *`choices` = > json.get value=`data` key=choices *
    *`first` = > at value=`choices` index=0 *
    *`message` = > json.get value=`first` key=message *
    *`content` = > json.get value=`message` key=content *
    **`content`**
  2. *
    > 打印 内容=ext/ai/大模型: HTTP 错误
    > 打印 内容=`status`
    > 打印 内容=`raw`
    > 系统.退出 码=1
