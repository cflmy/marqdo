从本入口选择任务：[大模型](大模型.mq.md)负责提示、配置、请求和流收集；
[智能体](智能体.mq.md)提供中文使用面，[同源编排实现](agent.mq.md)负责上下文、
白名单工具、路由、工作簿和继续执行；[沙盒](沙盒.mq.md)管理试运行覆盖层及晋升。
[提供方适配入口](llm/index.mq.md)解释 HTTP 适配，[路由策略](policies/step-route.mq.md)
保留可读表数据。[英文入口](index.mq.md)给出相同职责划分。

可以先运行完全离线的流收集，不需要凭据、模型服务或原生插件：

```sh
marqdo call ext/ai/索引.mq.md 离线示例 --json
```

真实请求前明确模型基址和可信凭据，智能体还需要已构建的 agent 插件与工具白名单。
生成的调用文本不是执行授权，文件写入、网络和进程仍受宿主限制。工具失败、取消、
超预算或恢复时应保留观察与效果状态，不因继续工作簿而重复不可逆操作。

新增提供方去适配目录，公共模型行为去大模型模块，规划和上下文去智能体模块，
隔离修改去沙盒模块；保持中英文默认值与行为一致。先用本地可控替身验证成功与失败，
再在明确运行配置下测试真实服务。不能用固定完成标记冒充已经调用模型或验证了工具。

## 收集事件

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 事件 | list | 必填 | 按顺序排列的语义流或公开收集器支持的提供方事件 |

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | text | 由公共收集器组装的最终回答文本 |

输入`事件`是已经观测的数据，不会触发新请求或执行其中的工具文本。
本工具复用公开大模型库的 delta/text 与 done.result 收集约定，
直接返回*[把已有事件组装成最终文本](大模型.收集(事件=`事件`))*，
使离线处理与真实传输复用同一份组装规则。

## 离线示例

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | text | Hello world，由下面的实际事件组装得到 |

下面是一条确定的增量事件和一条完成事件。表格把输入内容完整列出，
读者可以比较局部文本与完成结果，不需要相信一个自报通过的标志。
此流程只验证流收集，不暗示模型服务或网络已经可用。

`事件` =

| @ | type | text | result |
|---|---|---|---|
| 1 | delta | "Hello " | None |
| 2 | done | None | "Hello world" |

最后返回*[根据列出的事件得到最终文本](收集事件(事件=`事件`))*，供下一步展示或保存。
