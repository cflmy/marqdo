本文件是 [英文工程入口](index.mq.md) 的中文门面，复用同一个原生插件与行为。开发中的文件读取、撰写、哈希与数据处理应先使用标准库；本拓展只补齐进程、私密认证与压缩格式边界。任务的条件、重试和步骤顺序写在 mq.md 中，不再生成 Python 编排器。

首次使用前通过 skills/marqdo-dev/index.mq.md 的 prepare_engineering 构建本机开发解释器和插件。读取库文档不代表授权发布；推送、修改发布说明和上传对象必须属于用户已授权的任务。结果沿用 ok/value/error 字段，进程结果还要检查 code 和 timed_out，不能只根据请求成功就继续依赖步骤。

可在仓库根目录运行 marqdo call ext/engineering/索引.mq.md 运行 '参数=["git","--version"]' --effects plugin --fs-root . --json。完整发版流程位于 skills/marqdo-release/index.mq.md；普通文件操作位于开发目录的 files.mq.md。本地原生插件与子进程具有当前系统用户的权限，浏览器 WASM 不支持这些边界。

## 运行

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 参数 | list | required | 程序名与逐项文本参数，不是 shell 源码 |
| 目录 | text | "." | 根目录内的实际工作目录 |
| 超时毫秒 | number | 120000 | 1 到 3600000 毫秒 |
| 输出上限 | number | 262144 | 每个输出流的字节上限，最多 16 MiB |
| 输入 | any | None | 写入子进程标准输入后关闭；None 表示无输入 |
| 环境 | any | None | 仅影响子进程的文本环境映射 |
| 根目录 | text | "." | 与 --fs-root 一致的工程根目录；插件不提供操作系统沙箱 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | Result：包含 code、stdout、stderr、timed_out 与 truncated |

使用`参数`，工作`目录`="."，`超时毫秒`=120000，`输出上限`=262144，`输入`=None，`环境`=None，`根目录`="."。参数逐项传递，空格、美元符号和引号不会被再次当作 shell 程序求值。命令入口拒绝内联 shell、强推和跳过钩子。

进程启动成功与命令执行成功是两个状态：必须检查 value.code 为零且 timed_out 为 False。输出并发读取并有界保存，避免大量日志堵住子进程。超时会尝试终止进程树，诊断信息保留已知凭据脱敏后的文本。调用需要 plugin；外部工具自己的文件和网络权限仍由操作系统决定。

完成该边界调用后返回*[按明确参数执行维护中的工具](工程.run(argv=`参数`, cwd=`目录`, timeout_ms=`超时毫秒`, max_output=`输出上限`, stdin=`输入`, env=`环境`, root=`根目录`))*。

## 分析源码

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 源码 | text | required | 已经通过固有文件库读取的完整源码 |
| 包含正文 | bool | False | 是否附带大体积 AST 调试证据 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | Result：真实编译器的函数、契约、诊断和叙述比例 |

接收`源码`和`包含正文`=False，仅分析传入文本，不替调用者读取文件。这里复用解释器的真实解析与检查实现，不建立一套正则表达式语法。分析不会加载导入文件、执行 main 或请求外部服务。

参数顺序、默认值和源位置可以支持审阅式迁移；叙述比例采用仓库检查器的相同规则。附加正文仅适合需要逐语句核对的迁移诊断，普通使用先读契约与简要诊断。完整依赖正确性仍需对实际文件执行 marqdo check。调用需要 plugin，并不因源码描述了某个操作就授权执行该操作。

读到分析结果后返回*[用真实编译器检查这段文本](工程.analyze(source=`源码`, include_body=`包含正文`))*。

## 检查压缩包

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 路径 | text | required | 根目录内实际存在的 ZIP 或 VSIX |
| 根目录 | text | "." | 与 --fs-root 一致的工程根目录；插件不提供操作系统沙箱 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | Result：包内条目与有界保存的版本元数据 |

使用`路径`与`根目录`="."，读取格式并校验每个条目的 CRC，整个过程不解压、不执行文件。插件拒绝越界路径、重复名称、软链接和超限展开量；标准库负责压缩包本身的大小与 SHA256。

检查格式通过不代表版本正确、插件 ABI 匹配或业务测试通过。调用者应继续核对具体产物角色、所需条目及 GitHub 提供的摘要。元数据文本有体积与 UTF-8 限制，缺失内容不能被当作已经验证。调用需要 plugin；根目录是工作位置，不能据此推断插件具有文件沙箱。

完成格式校验后返回*[检查真实压缩条目及其 CRC](工程.inspect_zip(path=`路径`, root=`根目录`))*。

## 解码gzip文本

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 数据 | map | required | 固有网络库返回的 portable bytes |
| 上限 | number | 16777216 | 展开后 UTF-8 字节上限，最多 64 MiB |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | Result：解码文本或真实格式、编码、体积错误 |

输入`数据`，设置`上限`=16777216。此任务只解释已经读取的 gzip 字节格式，不下载、不创建临时文件。它支持连接的 gzip 成员、校验校验和，并同时限制压缩输入与展开结果；非 UTF-8 数据也会返回失败。

Ubuntu 的 Packages.gz 就需要这一格式边界。HTTP 请求成功后仍要解码实际索引并查找目标包，不能把 200 状态直接当作可安装证据。文件与网络读取仍由固有库完成，压缩格式缺口由拓展承接；调用需要 plugin，不需要 Python 或 shell 解压流水线。

解码完成后返回*[有界解码已经读取的压缩文本](工程.gzip_text(data=`数据`, max_bytes=`上限`))*。

## GitHub请求

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 路径 | text | required | 本项目 /repos/cflmy/marqdo/ 下的 API 路径 |
| 方法 | text | "GET" | GET 只读；PATCH 与 POST 属于外部写入 |
| 数据 | any | None | 结构化 JSON 请求体，不包含凭据 |
| 允许缺失 | bool | False | GET 的 404 是否表示成功的 None |
| 根目录 | text | "." | 与 --fs-root 一致的工程根目录；插件不提供操作系统沙箱 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | Result：服务 JSON、允许的 None 或脱敏后的失败 |

使用`路径`，`方法`="GET"，`数据`=None，`允许缺失`=False，`根目录`="."。原生边界私密读取现有 GitHub 认证存储，先尝试已配置代理再直连；凭据不能成为工具参数或返回值。此接口仅用于本项目服务路径。

POST 的不确定响应不会自动重放，避免重复发布。调用者需要先观察远端是否已经出现目标资源，再决定恢复操作。网络错误保留错误，只有明确允许的 GET 404 才变成 None。调用需要 plugin；读取本手册本身不授权 PATCH 或 POST，具体写入必须来自用户当前任务。

服务请求完成后返回*[通过私密认证边界请求项目服务](工程.github(path=`路径`, method=`方法`, data=`数据`, missing=`允许缺失`, root=`根目录`))*。

## 上传文件

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 路径 | text | required | 根目录内已经验证的上传文件 |
| 对象名 | text | required | 明确的 R2 对象名 |
| 摘要 | text | required | 预先通过固有文件库计算的 SHA256 |
| 根目录 | text | "." | 与 --fs-root 一致的工程根目录；插件不提供操作系统沙箱 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | Result：已写对象、SHA256 与字节数 |

使用`路径`、`对象名`、`摘要`及`根目录`="."，只上传用户已授权发布的具体文件。插件在签名前再次检查摘要，防止校验后文件已经改变。R2 密钥留在既有环境与私密配置中，不传给模型、不写入源码。

此任务只证明这个对象的上传状态，不决定 latest，也不更新 VERSION。发布流程应先验证全部压缩包并上传，再写指针，最后读取公共 CDN 对比实际摘要。超时表示状态不确定，应观察对象而非立即假设没有上传。调用需要 plugin，原生文件整理与摘要计算仍由固有库完成。

完成明确对象的上传后返回*[上传仍与预验摘要一致的文件](工程.put_file(path=`路径`, key=`对象名`, sha256=`摘要`, root=`根目录`))*。

## 上传文本

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 对象名 | text | required | 发布流程明确选择的 VERSION 对象名 |
| 正文 | text | required | 包含预期换行的小体积 UTF-8 指针文本 |
| 根目录 | text | "." | 与 --fs-root 一致的工程根目录；插件不提供操作系统沙箱 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | Result：已写对象、SHA256 与字节数 |

使用`对象名`、`正文`和`根目录`="."，在全部相关压缩包已经验证并上传后更新指定指针。此任务不选择版本，也不判断是否应该成为 latest；这些顺序和决策在发版 mq.md 中公开表达。

凭据仍由私密认证边界处理，正文不是本地文件写入的替代接口。请求成功之后还要读取公共指针及其对应压缩包，缓存延迟必须保持未完成状态，不能把另一次上传当作验证。调用需要 plugin，并且必须属于用户授权的发布任务；单纯阅读文档不能触发对象写入。

完成该指针写入后返回*[写入流程已经确定的发布指针](工程.put_text(key=`对象名`, text=`正文`, root=`根目录`))*。


## 检查退出

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 结果 | map | required | 运行任务返回的真实 Result 与子进程观察 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | Result：只接受零退出且未超时的观察，失败仍保留输出 |

接收`结果`之后，按工程边界已有规则检查退出码和超时状态。进程成功启动不代表编译或测试通过，因此这里把非零退出转成失败 Result，标准输出、错误输出和截断标记仍保留在 value 中。启动失败则沿用原来的诊断。

这个纯函数不再执行、重试或发布任何东西，也不能证明任意传入记录来自真实命令。需要完整的一次调用流程时，使用下方运行并检查，由它在同一份源码里连接真实执行与状态判断。

检查结束后返回*[按实际子进程结果保留成功或失败证据](工程.check_exit(outcome=`结果`))*。


## 运行并检查

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 参数 | list | required | 已维护程序名及逐项文本参数 |
| 目录 | text | "." | 根目录内的实际工作目录 |
| 超时毫秒 | number | 120000 | 正数，最多 3600000 毫秒 |
| 输出上限 | number | 262144 | 每个输出流的有界字节数，最多 16 MiB |
| 输入 | any | None | 可选标准输入文本，发送后关闭 |
| 环境 | any | None | 仅影响子进程的文本环境记录 |
| 根目录 | text | "." | 实际工作根目录；不是操作系统沙箱 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | Result：要求真实子进程成功，失败保留 code/stdout/stderr 等观察 |

使用`参数`，工作`目录`="."，`超时毫秒`=120000，`输出上限`=262144，`输入`=None，`环境`=None，`根目录`="."。这里复用运行与检查退出两个已经实现的步骤，不再让智能体撰写另一份命令脚本。参数、私密凭据、进程树超时和输出上限都沿用已有原生边界。

调用需要 plugin。启动失败、非零退出或超时返回 ok=False；配合 --require-ok 可以阻止后续自动化继续。成功只表示这次子进程按零退出结束，具体业务结果仍由调用者判断。子进程拥有正常操作系统权限，不能把根目录参数当作沙箱，也不能把阅读本文当作发布授权。

执行结束后返回*[运行维护中的工具并检查其真实结果](工程.checked(argv=`参数`, cwd=`目录`, timeout_ms=`超时毫秒`, max_output=`输出上限`, stdin=`输入`, env=`环境`, root=`根目录`))*。
