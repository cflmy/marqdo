本文件提供 auth.mq.md 的服务端绑定中文入口。凭据验证、会话和路径门禁是不同责任：本入口配置登录会话，业务端点与表单仍需显式访问策略。它不会把隐藏链接当作授权。账户表中的明文密码只适合本地夹具；真实用户应使用英文资源的 hash_password 生成受支持的口令散列，避免记录秘密。

## 绑定

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 应用 | any | 必填 | 已准备并按需启用原生后台的应用 |
| 用户 | any | 必填 | username、password、role 凭据表，或原生用户库配置 |
| 会话时长 | number | 3600 | 会话寿命，单位为秒 |
| 后台前缀 | text | "/admin" | 启用原生后台时安装默认门禁的路径前缀 |
| 登录路径 | text | "/login" | 实际 GET 与 POST 登录地址 |
| 登录返回 | text | "" | 成功登录后的可选目标 |
| 退出返回 | text | "" | 退出后的可选目标 |
| 注册 | bool | False | 明确启用用户注册；默认关闭 |
| 注册路径 | text | "/register" | 启用注册后的系统地址 |
| 默认角色 | text | "user" | 新注册用户的角色 |
| 会话地址 | text | "" | 可选外部会话存储 URI |

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | map | 保留原有资源、附加登录和会话策略的新应用 |

使用`应用`、`用户`、`会话时长`=3600、`后台前缀`="/admin"、`登录路径`="/login"、`登录返回`=""、`退出返回`=""、`注册`=False、`注册路径`="/register"、`默认角色`="user"及`会话地址`=""。在监听前授权 plugin 并保留新应用。这里不认证某一次请求，也不启动监听。

原生后台应先启用再绑定鉴权，业务接口的 Endpoint 元数据或显式门禁继续决定所需的身份和角色。注册必须明确启用，外部会话后端另需可用连接。配置成功不能替代拒绝与接受凭据的真实验收；用户数据与口令不要写入检视结果或日志。

绑定完成后返回 *[配置原生登录与会话策略](auth.attach(app=`应用`, users=`用户`, session_ttl=`会话时长`, admin_prefix=`后台前缀`, login_path=`登录路径`, login_redirect=`登录返回`, logout_redirect=`退出返回`, register=`注册`, register_path=`注册路径`, default_role=`默认角色`, session_url=`会话地址`))*。


## 门禁

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 应用 | any | 必填 | 已准备且保留实际资源的应用 |
| 路径 | text | 必填 | 需实际保护的服务器路径 |
| 角色 | any | "admin" | 允许的角色逗号文本或列表 |
| 权限 | text | "" | 可选权限逗号文本，沿用原生任一匹配 |
| 匹配 | text | "prefix" | prefix 前缀或 exact 精确匹配 |
| 拒绝 | text | "forbid" | forbid 禁止或 redirect 让匿名访问转登录 |
| 排除 | any | None | 可选路径排除；原生登录和退出仍保持可用 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | 附加实际服务器访问策略的新应用，尚未监听 |

使用`应用`、`路径`、`角色`="admin"、`权限`=""、`匹配`="prefix"、`拒绝`="forbid"及`排除`=None，在监听前授权 plugin 并保留返回值。本安全资源保护实际请求，不因导航隐藏链接就认定地址安全。前缀覆盖本路径及其斜杠子路径，登录和退出按原生规则排除，避免鉴权循环。

给出权限时采用原生权限匹配，而不是角色清单；任一所需权限命中即可。redirect 只让匿名拒绝转向登录，已登录但不足权限仍收到禁止。表单与 API 还应按实际数据策略保护自己的提交路径；不能只给展示页面加门禁就宣称所有写入已私有化。

绑定完成后返回 *[将明确的访问规则交给安全资源](auth.gate(app=`应用`, path=`路径`, roles=`角色`, permissions=`权限`, match=`匹配`, on_deny=`拒绝`, exclude=`排除`))*。
