## 装配
    + `跨域`=None
    + `安全`=None
    + `压缩`=None
    + `请求体上限`=None
    + `接口`=None

每项能力用数据表声明，`监听` 时统一装配。`跨域` 参数接受 `|允许来源|方法|头|暴露头|凭证|` 表（每来源一行；`允许来源` 留空表示允许任意来源）。`安全` 参数接受 `|头|值|` 响应头表（如 `X-Frame-Options`、`Content-Security-Policy`、`X-Content-Type-Options`、`Referrer-Policy`、`Strict-Transport-Security`）。`压缩` 为 `真` 时对响应体做 gzip 压缩。`请求体上限` 是请求体最大字节数（如 `1048576`）。`接口` 参数接受 `|路径|方法|表|条件|排序|上限|` JSON API 端点表（每个返回 `application/json`）。

表仍是数据，`装配` 把它们变成能力。配置即数据、装配即函数。

**> web_app_middleware app=`self` cors=`跨域` security=`安全` compress=`压缩` body_limit=`请求体上限` json_routes=`接口`**
