门面模块：从[中文根手册](网页/索引.mq.md)选择业务路径。
布局先拆成父组件与 Markdown 叶子，默认不写整页 HTML。构造值与启动进程是两件事；
下面示例从生产者开始，所有句柄沿同一会话传递，渲染时才需要原生插件。

```sh
marqdo call ext/web/网页.mq.md 渲染 '正文="# 文档"' '标题="预览"' --effects plugin --json
marqdo call ext/web/网页.mq.md 检视 '根="examples/web-layout-handbook"' --effects plugin --json
```

页面结构用五列 View 记录，父值保留子表。纯布局、DOM 构造和客户端描述无需插件。
整站服务通过 launcher 的 marqdo run 启动；检视磁盘站点请给出根目录，不能从新进程
读取另一个进程的私有应用。结构化 Document 使用 视图: main，在启动时执行布局装配。

开发时先复用组件和布局模块，再改对应领域实现；保持中英入口与真实契约一致。
验证 web_handbook 与既有 Web Artifact 金样，资源、鉴权和网络能力不要塞回门面。

## 页面

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 标题 | text | "" | 文档标题 |
| 路由 | text | "/" | 路径 |
| 方法 | text | "GET" | HTTP 方法 |
| 正文 | text | "" | Markdown 正文 |
| 节点 | any | None | View 表或 None |
| 数据源 | text | "" | 表名 |
| 排序 | text | "" | 如 -created_at |
| 条件 | text | "" | col=val 列表 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 页面句柄 |

这里使用`标题`=""、`路由`="/"、`方法`="GET"、`正文`=""、`节点`=None、`数据源`=""、`排序`=""、`条件`=""。

构造 Document 句柄，默认 `标题`=""、`路由`="/"、`方法`="GET"、`正文`=""、

`节点`=None、`数据源`=""、`排序`=""、`条件`=""。站点页面优先用 `类型: 网页`
Artifact，由 `服务` 发现；本工具供预览或程序化构造。节点必须是统一 View 表，
不是 HTML。

完成后返回*[调用 page](web.page(title=`标题`, route=`路由`, method=`方法`, body=`正文`, nodes=`节点`, data_source=`数据源`, data_order=`排序`, data_where=`条件`))*。

| 参数 | 类型 | 默认 | 说明 |

| 应用 | any | 必填 | 应用句柄 |
| 路径 | text | 必填 | URL 路径 |
| 方法 | text | "GET" | HTTP 方法 |
| 页面 | any | None | Document 或 None |
| 函数 | text | "" | Endpoint lib.member |
| 请求 | text | "json" | 请求体类型 |
| 响应 | text | "json" | 响应类型 |
| 鉴权 | text | "" | 鉴权标签 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 路由结果 |

这里使用`应用`、`路径`、`方法`="GET"、`页面`=None、`函数`=""、`请求`="json"、`响应`="json"、`鉴权`=""。

在 `应用` 上注册已声明 Document 或 Endpoint：`路径`、`方法`="GET"、`页面`=None、

`函数`=""、`请求`="json"、`响应`="json"、`鉴权`=""。不要隐式注册用户路由。

完成后返回*[调用 route](web.route(app=`应用`, path=`路径`, method=`方法`, page=`页面`, fn=`函数`, request=`请求`, response=`响应`, auth=`鉴权`))*。

## 渲染

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 文档 | any | None | Document 或 None |
| 节点 | any | None | View 表或 None |
| 正文 | text | "" | Markdown |
| 标题 | text | "" | 调用方提供的标题 |
| 数据库 | any | None | 可选 db |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | HTML 或渲染结果 |

这里使用`文档`=None、`节点`=None、`正文`=""、`标题`=""、`数据库`=None。

把 Document 或 View 节点渲染为 HTML（预览）。可选 `文档`=None、`节点`=None、

`正文`=""、`标题`=""、`数据库`=None。输入应来自 Markdown/View，而不是手写 HTML
大字符串。

完成后返回*[调用 render](web.render(doc=`文档`, nodes=`节点`, body=`正文`, title=`标题`, db=`数据库`))*。

## 检视

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 应用 | any | None | 应用或 None |
| 根 | text | "" | 离线扫描的站点目录 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 路由检视 |

这里使用`应用`=None、`根`=""。

## 服务

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 根 | text | "." | 站点根目录 |
| 主机 | text | "127.0.0.1" | 绑定主机 |
| 端口 | number | 18081 | 调用方提供的端口 |
| 数据库 | any | None | 可选 db |
| 静态目录 | text | "" | 静态资源 |
| 中间件 | any | None | 可选中间件 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 服务结果 |

这里使用`根`="."、`主机`="127.0.0.1"、`端口`=18081、`数据库`=None、`静态目录`=""、`中间件`=None。

扫描 `根`="." 下 `类型: 网页|端点` Artifact，注册声明路由并在 `主机`="127.0.0.1"
与 `端口`=18081 监听。可选 `数据库`=None、`静态目录`=""、`中间件`=None。站点
目录应已按布局铁律拆好组件文件。

完成后返回*[调用 serve](web.serve(root=`根`, host=`主机`, port=`端口`, db=`数据库`, static_dir=`静态目录`, middleware=`中间件`))*。
