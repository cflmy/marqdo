本文件是 Marqdo 网络（web）扩展的中文根 skill。若你是没有其它上下文的智能体，
请先读「选哪条路」与「布局铁律」，再按 call 形状执行。不要发明 MCP、整页 HTML
或第二套 API。`##` 标题就是工具。

## 选哪条路

只选一行。不要混用中英工具名。

| 若你需要 | 这样做 |
|----------|--------|
| 写站前的布局规则 | 调用本包 `布局.规则`（或 `ext/web/布局/索引.mq.md` 的 `规则`） |
| 预览 Document / View | `渲染`，加 `--effects plugin` |
| 启动站点 | 作者程序 `服务`，或 call `服务` 并传 `根=` · `端口=` |
| 英文工具名 | 改开 `ext/web/index.mq.md`，留在英文树 |

智能体默认 `##` + `marqdo call`。`# page` 等对象给作者程序。`dom.raw` /
`page.css` 不是首页默认做法。

*None*

## 布局铁律

网页靠文件划分建造，不靠注入 HTML。首页拆成导航、侧栏、主区、底栏等文件。某一
区仍复杂（双栏底栏、密样式）时再拆，直到每文件单一职责、一张 View 或短
Markdown。值、库与具名样式只走统一 View 列（类型、槽、值、属性、样式，或英列
名）。默认禁止整页 HTML 字符串、CSS 注入袋、compose 碎片与 json.set 拼 DOM。
逃逸舱仅限 dom.raw / page.css，且必须写明为何不能表驱动。

详见 doc/design/ext-web-layout-paradigm.md。包内工具：ext/web/布局/索引.mq.md。

调用示例（纯文本）：
  marqdo call ext/web/布局/索引.mq.md 规则 --json
  marqdo call ext/web/网页.mq.md 布局规则 --json

*None*

## 如何执行任意工具

调用示例（纯文本）：
  marqdo call FILE FUNCTION 名=值 --effects plugin --json

FILE 在 `ext/web/` 下。涉及原生插件的工具必须 `--effects plugin`。布局规则类
工具可纯 call。不要调用 `确保插件` 或 `host_*`。

*None*

与 `布局.规则` 相同，便于只打开本文件的智能体。

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 布局规则映射 |

*> 布局.规则*

## 页面
    + `标题`=""
    + `路由`="/"
    + `方法`="GET"
    + `正文`=""
    + `节点`=None
    + `数据源`=""
    + `排序`=""
    + `条件`=""

构造 Document 句柄。站点页面优先用 `类型: 网页` Artifact，由 `服务` 发现；本工具
供预览或程序化构造。节点必须是统一 View 表，不是 HTML。

| 参数 | 类型 | 说明 |
|------|------|------|
| 标题 | text | 文档标题 |
| 路由 | text | 路径 |
| 方法 | text | HTTP 方法 |
| 正文 | text | Markdown 正文 |
| 节点 | any | View 表或 None |
| 数据源 | text | 表名 |
| 排序 | text | 如 -created_at |
| 条件 | text | col=val 列表 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 页面句柄 |

*> web.page title=`标题` route=`路由` method=`方法` body=`正文` nodes=`节点` data_source=`数据源` data_order=`排序` data_where=`条件`*

## 路由
    + `应用`
    + `路径`
    + `方法`="GET"
    + `页面`=None
    + `函数`=""
    + `请求`="json"
    + `响应`="json"
    + `鉴权`=""

注册已声明的 Document 或 Endpoint。不要隐式注册用户路由。

| 参数 | 类型 | 说明 |
|------|------|------|
| 应用 | any | 应用句柄 |
| 路径 | text | URL 路径 |
| 方法 | text | HTTP 方法 |
| 页面 | any | Document 或 None |
| 函数 | text | Endpoint lib.member |
| 请求 | text | 请求体类型 |
| 响应 | text | 响应类型 |
| 鉴权 | text | 鉴权标签 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 路由结果 |

*> web.route app=`应用` path=`路径` method=`方法` page=`页面` fn=`函数` request=`请求` response=`响应` auth=`鉴权`*

## 渲染
    + `文档`=None
    + `节点`=None
    + `正文`=""
    + `标题`=""
    + `数据库`=None

把 Document 或 View 节点渲染为 HTML（预览）。输入应来自 Markdown/View，而不是
手写 HTML 大字符串。

| 参数 | 类型 | 说明 |
|------|------|------|
| 文档 | any | Document 或 None |
| 节点 | any | View 表或 None |
| 正文 | text | Markdown |
| 标题 | text | 标题 |
| 数据库 | any | 可选 db |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | HTML 或渲染结果 |

*> web.render doc=`文档` nodes=`节点` body=`正文` title=`标题` db=`数据库`*

## 使用
    + `应用`
    + `中间件`

一等中间件（表驱动）。禁止 `configure(...)` 垃圾抽屉。

| 参数 | 类型 | 说明 |
|------|------|------|
| 应用 | any | 应用句柄 |
| 中间件 | any | 中间件表 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 应用句柄 |

*> web.use app=`应用` middleware=`中间件`*

## 服务
    + `根`="."
    + `主机`="127.0.0.1"
    + `端口`=18081
    + `数据库`=None
    + `静态目录`=""
    + `中间件`=None

扫描 `根/**/*.mq.md` 中 `类型: 网页|端点`，注册声明路由并监听。站点目录应已按
布局铁律拆好组件文件。

| 参数 | 类型 | 说明 |
|------|------|------|
| 根 | text | 站点根目录 |
| 主机 | text | 绑定主机 |
| 端口 | number | 端口 |
| 数据库 | any | 可选 db |
| 静态目录 | text | 静态资源 |
| 中间件 | any | 可选中间件 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 服务结果 |

*> web.serve root=`根` host=`主机` port=`端口` db=`数据库` static_dir=`静态目录` middleware=`中间件`*

## 客户端挂载
    + `桥`="/static/marqdo-bridge.js"
    + `wasm`="/static/marqdo_wasm.wasm"
    + `源`=""
    + `启动`=True

嵌入 WASM 桥。不是用 HTML 字符串拼整页的借口。

| 参数 | 类型 | 说明 |
|------|------|------|
| 桥 | text | bridge 脚本路径 |
| wasm | text | wasm 路径 |
| 源 | text | 可选源 |
| 启动 | bool | 是否自动 boot |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 挂载描述 |

*> web.client_embed bridge=`桥` wasm=`wasm` source=`源` boot=`启动`*
