门面模块：从[中文根手册](网页/索引.mq.md)选择业务路径。
布局先拆成父组件与 Markdown 叶子，默认不写整页 HTML。构造值与启动进程是两件事；
下面示例从生产者开始，所有句柄沿同一会话传递，渲染时才需要原生插件。

```sh
marqdo call ext/web/网页.mq.md 渲染 '正文="# 文档"' '标题="预览"' --effects plugin --json
marqdo call ext/web/网页.mq.md 检视 '根="examples/web-layout-handbook"' --effects plugin --json
```

页面结构用五列 View 记录，父值保留子表。纯布局、DOM 构造和客户端描述无需插件。
整站服务通过 launcher 的 marqdo run 启动；检视磁盘站点请给出根目录，不能从新进程
读取另一个进程的私有应用。结构化 Document 使用 视图: main，在启动时执行布局装配。

开发时先复用组件和布局模块，再改对应领域实现；保持中英入口与真实契约一致。
验证 web_handbook 与既有 Web Artifact 金样，资源、鉴权和网络能力不要塞回门面。

## 布局规则

与 `布局.规则` 相同，便于只打开本文件的智能体。

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 布局规则映射 |

*> 布局.规则*

## 页面

| 参数 | 类型 | 说明 |
|------|------|------|
| 标题 | text | 文档标题 |
| 路由 | text | 路径 |
| 方法 | text | HTTP 方法 |
| 正文 | text | Markdown 正文 |
| 节点 | any | View 表或 None |
| 数据源 | text | 表名 |
| 排序 | text | 如 -created_at |
| 条件 | text | col=val 列表 |

构造 Document 句柄，默认 `标题`=""、`路由`="/"、`方法`="GET"、`正文`=""、
`节点`=None、`数据源`=""、`排序`=""、`条件`=""。站点页面优先用 `类型: 网页`
Artifact，由 `服务` 发现；本工具供预览或程序化构造。节点必须是统一 View 表，
不是 HTML。

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 页面句柄 |

*> web.page title=`标题` route=`路由` method=`方法` body=`正文` nodes=`节点` data_source=`数据源` data_order=`排序` data_where=`条件`*

## 路由

| 参数 | 类型 | 说明 |
|------|------|------|
| 应用 | any | 应用句柄 |
| 路径 | text | URL 路径 |
| 方法 | text | HTTP 方法 |
| 页面 | any | Document 或 None |
| 函数 | text | Endpoint lib.member |
| 请求 | text | 请求体类型 |
| 响应 | text | 响应类型 |
| 鉴权 | text | 鉴权标签 |

在 `应用` 上注册已声明 Document 或 Endpoint：`路径`、`方法`="GET"、`页面`=None、
`函数`=""、`请求`="json"、`响应`="json"、`鉴权`=""。不要隐式注册用户路由。

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 路由结果 |

*> web.route app=`应用` path=`路径` method=`方法` page=`页面` fn=`函数` request=`请求` response=`响应` auth=`鉴权`*

## 渲染

| 参数 | 类型 | 说明 |
|------|------|------|
| 文档 | any | Document 或 None |
| 节点 | any | View 表或 None |
| 正文 | text | Markdown |
| 标题 | text | 标题 |
| 数据库 | any | 可选 db |

把 Document 或 View 节点渲染为 HTML（预览）。可选 `文档`=None、`节点`=None、
`正文`=""、`标题`=""、`数据库`=None。输入应来自 Markdown/View，而不是手写 HTML
大字符串。

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | HTML 或渲染结果 |

*> web.render doc=`文档` nodes=`节点` body=`正文` title=`标题` db=`数据库`*

## 使用

| 参数 | 类型 | 说明 |
|------|------|------|
| 应用 | any | 应用句柄 |
| 中间件 | any | 中间件表 |

把 `中间件` 挂到 `应用`（表驱动）。禁止 `configure(...)` 垃圾抽屉。

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 应用句柄 |

*> web.use app=`应用` middleware=`中间件`*

## 检视

| 参数 | 类型 | 说明 |
|------|------|------|
| 应用 | any | 应用或 None |
| 根 | text | 离线扫描的站点目录 |

返回 `{declared, system}` 路由表；可选 `应用`=None。

可选 `根`=""，给出时扫描站点目录，不启动服务器。

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 路由检视 |

*> web.inspect app=`应用` root=`根`*

## 服务

| 参数 | 类型 | 说明 |
|------|------|------|
| 根 | text | 站点根目录 |
| 主机 | text | 绑定主机 |
| 端口 | number | 端口 |
| 数据库 | any | 可选 db |
| 静态目录 | text | 静态资源 |
| 中间件 | any | 可选中间件 |

扫描 `根`="." 下 `类型: 网页|端点` Artifact，注册声明路由并在 `主机`="127.0.0.1"
与 `端口`=18081 监听。可选 `数据库`=None、`静态目录`=""、`中间件`=None。站点
目录应已按布局铁律拆好组件文件。

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 服务结果 |

*> web.serve root=`根` host=`主机` port=`端口` db=`数据库` static_dir=`静态目录` middleware=`中间件`*

## 客户端挂载

| 参数 | 类型 | 说明 |
|------|------|------|
| 桥 | text | bridge 脚本路径 |
| wasm | text | wasm 路径 |
| 源 | text | 可选源 |
| 启动 | bool | 是否自动 boot |

嵌入 WASM 桥，默认 `桥`="/static/marqdo-bridge.js"、`wasm`="/static/marqdo_wasm.wasm"、
`源`=""、`启动`=True。不是用 HTML 字符串拼整页的借口。

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 挂载描述 |

*> web.client_embed bridge=`桥` wasm=`wasm` source=`源` boot=`启动`*
