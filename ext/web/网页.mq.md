## 样式装配
    + `名`=""
    + `表`

把 GFM 样式表装配成一段 CSS 文本。支持两种表形：
`|选择器|属性|值|` 规则行（选择器任意，同一选择器多行合并成一条规则；
加 `|媒体|` 列即可分组进 `@media` 块），或 `|属性|值|` 属性行（按 `.名 { … }` 包裹）。
样式即数据、装配即函数 —— 主题模块据此把样式表拼成完整样式表。

> 确保插件
**> web_style name=`名` table=`表`**

## 查询条件
    + `条件`

为主主体绑定附加 DB 条件映射。值可含 `{参数}` 占位符，由动态路由参数替换（如 `/post/{slug}`）。

**> web_page_query page=`self` query=`条件`**

## 排序
    + `排序`

设置主主体绑定的默认 `ORDER BY`（如 `-created_at` 表示最新在前）。

**> web_page_order page=`self` order=`排序`**

## 链接前缀
    + `前缀`

卡片链接前缀（默认 `/post/`）。主体绑定中含 `链接`/`href` 字段时，卡片标题会包成 `<a href="{前缀}{值}">`。

**> web_page_link_prefix page=`self` prefix=`前缀`**

## 样式
    + `样式`

把一段手写 CSS 字符串追加到页面样式表（`styles_css`），用于在装配好的外壳上叠加自定义主题。

**> web_page_css page=`self` css=`样式`**

## 详情
    + `详情`=True

把主体绑定的首行渲染成完整文章（标题/日期/标签/正文）而非卡片列表。用于动态文章页 `/post/{slug}`。

**> web_page_detail page=`self` detail=`详情`**

**> web_compose_form page=`self` form=`表单` id=`id`**

## 静态
    + `目录`
    + `挂载`=/static

将 `目录` 下的文件挂到 `挂载`（默认 `/static`）。路径在 `监听` 时相对进程工作目录解析。

**> web_app_static app=`self` dir=`目录` mount=`挂载`**

## 监听

提供 `/`、路由页、首页 `/_part/{id}`、路由 `{路径}/_part/{id}`、`/_form/{id}`、可选静态目录，以及可选 `/admin`。

**> web_listen app=`self`**

## 路由实时
    + `路径`
    + `回显`=真

在 `路径`（如 `/live`）注册 WebSocket 端点。`回显=真`（默认）时服务器对每条收到的文本帧原样回复；否则仅读取丢弃。客户端用 `网页.实时` 的 `连接` 接入。

**> web_app_route_ws app=`self` path=`路径` echo=`回显`**

## 鉴权
    + `用户表`
    + `会话时长`=3600

在保持 `后台=真` 的同时，为 `/admin*` 加登录门禁。`用户表` 是管理员表（`|用户名|密码|`）；未登录请求重定向到 `/admin/login`。

**> web_app_auth app=`self` users=`用户表` session_ttl=`会话时长`**
