本文件对应 head.mq.md。结构化页面将本资源交给组件的请求资源节点，服务器与离线预览都把它收集到真正的 head，不在正文或片段中留下占位。沿用现有五列 View，不增加新标记、嵌套元数据或页面变异链。

```sh
marqdo call ext/web/页头.mq.md 声明 '元数据=[{"key":"description","value":"可读的站点"}]' --json
```

## 声明

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 元数据 | any | None | key/value 行记录或 GFM 列式表，值为原生标量 |
| 链接 | any | None | rel/href 原生资源记录，支持媒体、跨域及脚本标志 |

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | map | 供组件安放的纯 document_head 描述 |

使用`元数据`=None、`链接`=None，构造不需要任何副作用。元数据保留 description、og: 等 SEO 名称，title、canonical、icon 等沿用普通文档约定；charset、viewport 和 csrf-token 归运行时所有，不在这里重声明。

链接复用原生 rel/href 表与中文字段别名，可声明字体预连接、样式、图标或显式脚本资源。地址只允许 / 开头的站内路径与 http(s)，不接受活动数据方案或协议相对地址。这里不下载字体、不执行脚本、不挂载静态文件；浏览器打开实际页面后才请求地址。官方桥仍用客户端挂载节点，不在资源里写业务 JavaScript。

多个子组件可以贡献资源，相同链接去重，同名元数据有不同值时保留诊断，不静默覆盖。片段不会重复输出页头；离线预览能处理本纯资源，但查询、表单与会话导航仍需真实请求上下文。缺失文件、网络可用性和页面视觉效果须另做实际验证，构造描述不能证明这些条件。

声明完成后返回 *[复用同一个文档页头契约](head.resource(meta=`元数据`, links=`链接`))*。
