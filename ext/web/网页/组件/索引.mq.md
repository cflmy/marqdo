组件是返回 View 记录列表的普通函数。父文件只表达子块关系，叶子只负责一段 Markdown。
页脚拆成品牌与链接，链接若仍是双栏就继续拆，直到每个文件只有一个可解释的内容职责。
完整参考见[拆分站点](../../../../examples/web-layout-handbook/index.mq.md)。

以下构造均为纯函数，无需插件或已有句柄：

```sh
marqdo call ext/web/网页/组件/索引.mq.md 正文 '文本="## 可读的叶子"' '槽="介绍"' --json
marqdo call ext/web/网页/组件/索引.mq.md 包裹 '子节点=[{"type":"markdown","value":"左"},{"type":"markdown","value":"右"}]' '种类="row"' --json
marqdo call ext/web/网页/组件/索引.mq.md 合并 '甲=[{"type":"text","value":"前"}]' '乙=[{"type":"text","value":"后"}]' --json
marqdo call ext/web/网页/组件/索引.mq.md 资源 '地址="/static/generated/theme.css"' '种类="stylesheet"' --json
```

复用组件使用 @ 记录表，合并只确定兄弟顺序，不会自动产生双栏。布局请转到
[布局入口](../../布局/索引.mq.md)，渲染交给[页面](../页面/索引.mq.md)。
新增内容先在站点组件目录实现；新结构类型需同步 Go 渲染器、双语入口与实际页面测试。
不要先渲染子块再拼 HTML 字符串，值单元格应保留子节点列表本身。

## 节点

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 表 | any | 必填 | View 表 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 原样返回输入 View 表，保留记录列表或列式表的实际形态 |

这里使用`表`。

原样返回 `表`，保留已有恒等入口。可接受列式表或记录列表；
需要组合和嵌套时统一选择 @ 记录列表，让子表保持结构值而不是字符串。

完成后返回*[调用 nodes](component.nodes(table=`表`))*。

## 合并

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 甲 | list | 必填 | 第一组节点记录 |
| 乙 | list | 必填 | 第二组节点记录 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | list | 有序兄弟节点 |

这里使用`甲`、`乙`。

拼接 `甲` 与 `乙`，保留顺序和内部父子关系。输入均为 @ 记录列表；
本工具不把平面节点变成两栏，需要双栏时再交给布局的分栏工具。

完成后返回*[调用 merge](component.merge(a=`甲`, b=`乙`))*。

## 正文

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 文本 | text | 必填 | 普通 Markdown |
| 槽 | text | "" | 区域名 |
| 样式 | text | "" | 可选类名 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | list | 单个 Markdown 叶子 |

这里使用`文本`、`槽`=""、`样式`=""。

将 Markdown `文本` 包成叶子，默认 `槽`=""、`样式`=""。
不加载原生插件，输出仍为结构数据；标题、链接、列表与表格在渲染时处理。
叶子不关心自己位于页脚左栏还是其他位置，父组件负责几何关系。

完成后返回*[调用 markdown](component.markdown(text=`文本`, slot=`槽`, style=`样式`))*。

## 包裹

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 子节点 | list | 必填 | 子块记录列表 |
| 种类 | text | "column" | 容器类型 |
| 槽 | text | "" | 区域名 |
| 样式 | text | "" | 可选类名 |
| 属性 | any | None | 容器属性记录，例如 id 与 hidden |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | list | 包含子节点的父块 |

这里使用`子节点`、`种类`="column"、`槽`=""、`样式`=""、`属性`=None。

将 `子节点` 放进一层父容器，默认 `种类`="column"、`槽`=""、`样式`=""。
几何类型为 row、column；语义类型包括 nav、header、footer、section、aside。
值单元格保留子表，不承载拼好的 HTML；构造器只生成结构，实际形状由渲染器检查。

完成后返回*[调用 wrap](component.wrap(children=`子节点`, kind=`种类`, slot=`槽`, style=`样式`, attrs=`属性`))*。

## 控件

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 种类 | text | 必填 | input、button、textarea、label、pre、option、text 或 link |
| 值 | text | "" | 控件文字或输入框初值 |
| 属性 | any | None | id、name、布尔标志等属性记录 |
| 槽 | text | "" | 布局区域名 |
| 样式 | text | "" | 可选样式类名 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | list | 现有五列 View 结构中的单个控件叶子 |

这里使用`种类`、`值`=""、`属性`=None、`槽`=""和`样式`=""。当普通 Markdown 无法表示编辑框或客户端事件目标时，才使用原生控件。属性记录中的 required、hidden 等必须是布尔值；控件文字按文本转义，不解释为 HTML。表单、列表和语义区域仍用包裹函数保存子节点关系。构造器本身是纯函数，实际渲染阶段检查类型与属性；事件处理器和内联样式不能混入属性表。客户端状态可用 data 与 aria 属性，外观通过类名引用站点样式表。

完成描述后返回*[构造可检查的原生控件](component.element(kind=`种类`, value=`值`, attrs=`属性`, slot=`槽`, style=`样式`))*.



## 资源

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 地址 | text | 必填 | 应用提供的脚本或样式表 URL |
| 种类 | text | "script" | script 或 stylesheet |
| 属性 | any | None | 模块类型、完整性或 data-mq 等属性记录 |
| 槽 | text | "" | 可选资源区域名 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | list | 现有五列 View 结构中的单个资源叶子 |

这里使用`地址`、`种类`="script"、`属性`=None、`槽`=""。脚本节点只引用资源地址，不承载内联业务 JavaScript；样式节点引用独立 CSS 文件。地址保留在值列，其余信息保留在属性记录。构造本身不访问网络，也不验证文件存在；原生渲染器负责转义和属性检查，浏览器打开页面后才加载资源。这样运行时桥和主题可以独立组织，不需要把整个页面写成 HTML 字符串。

完成后返回*[声明浏览器需要的独立资源](component.asset(url=`地址`, kind=`种类`, attrs=`属性`, slot=`槽`))*.



## 请求资源

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 值 | map | 必填 | 数据查询、表单引用、导航或纯页头声明的具型资源 |
| 槽 | text | "" | 动态内容区域的稳定名称 |
| 样式 | text | "" | 资源外层的可选类名 |

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | list | 五列 View 中的一个资源节点 |

使用`值`、`槽`=""与`样式`=""，把职责模块提供的资源放进布局。查询来自数据视图模块，表单由表单模块显式挂载，导航由下方工具构造，纯页头来自 ext/web/页头.mq.md。值单元格保留资源本身，父组件不先把子内容渲染成 HTML。

构造是纯计算，不查询数据库、不提交表单，也不加载插件。服务器准备请求参数、会话与 CSRF 后才解析资源。未知种类在监听前失败，缺失运行资源保留实际请求诊断。离线渲染不能伪造请求上下文或返回固定成功；纯页头声明可以离线预览，并收集进真正的 head，不作为正文占位。

`节点` =

| @ | 类型 | 槽 | 值 | 属性 | 样式 |
|---|---|---|---|---|---|
| 1 | resource | `槽` | `值` | None | `样式` |

父布局确定位置后，返回 *节点*，与静态 Markdown 和控件继续组合。

## 导航资源

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 项 | any | 必填 | 含 label、href 及可选 when、class、media 的链接记录 |
| 区域 | text | "nav" | nav、sidebar 或 footer |

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | map | 由实际会话决定链接可见性的纯导航资源 |

使用`项`与`区域`="nav"声明链接目的地。when 为 guest 或 auth 时根据当前请求会话筛选；空条件始终显示。父组件仍决定布局，原生导航渲染器保留已有类名和条件显示能力，不在作者源码中拼写整段 HTML。

隐藏链接不能保护目标地址。鉴权与角色门禁仍须由服务端资源显式绑定，构造导航不注册隐式路由，也不执行登录或退出。把返回值放入资源节点后，监听期间才读取真实会话；离线读取不会伪造某个用户的登录状态。

`资源` =

| _type | items | region |
|---|---|---|
| view_navigation | `项` | `区域` |

声明完可见性与目的地后，返回 *资源*，交给相同的五列 View 组合。
