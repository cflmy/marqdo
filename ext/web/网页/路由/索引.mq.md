路由模块：从[中文根手册](../索引.mq.md)选择业务路径。
布局先拆成父组件与 Markdown 叶子，默认不写整页 HTML。构造值与启动进程是两件事；
下面示例从生产者开始，所有句柄沿同一会话传递，渲染时才需要原生插件。

```sh
marqdo call ext/web/网页/路由/索引.mq.md 新建 '应用={}' '路径="/hello"' '页面={"title":"Hello","body":"Hi"}' --effects plugin --session handbook --toget route --json
marqdo call ext/web/网页/路由/索引.mq.md 注册 '路由=$route' --effects plugin --session handbook --json
```

页面结构用五列 View 记录，父值保留子表。纯布局、DOM 构造和客户端描述无需插件。
整站服务通过网页.服务或工程入口的 serve 函数用 marqdo call 启动；检视磁盘站点请给出根目录，不能从新进程
读取另一个进程的私有应用。结构化 Document 使用 视图: main，在启动时执行布局装配。

开发时先复用组件和布局模块，再改对应领域实现；保持中英入口与真实契约一致。
验证 web_handbook 与既有 Web Artifact 金样，资源、鉴权和网络能力不要塞回门面。

## 新建

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 应用 | any | 必填 | 应用句柄 |
| 路径 | text | 必填 | URL 路径 |
| 方法 | text | "GET" | HTTP 方法 |
| 页面 | any | None | Document 或 None |
| 函数 | text | "" | Endpoint 成员 |
| 请求 | text | "json" | 请求体类型 |
| 响应 | text | "json" | 响应类型 |
| 鉴权 | text | "" | 鉴权标签 |
| 类别 | text | "" | 路由类别 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 路由句柄 |

这里使用`应用`、`路径`、`方法`="GET"、`页面`=None、`函数`=""、`请求`="json"、`响应`="json"、`鉴权`=""、`类别`=""。

为 `应用` 在 `路径` 上构造路由句柄，`方法`="GET"。`页面`=None 或 `函数`="" 二
选一。`请求`="json"、`响应`="json"、`鉴权`=""、`类别`=""。本工具尚未注册——再
调 `注册`，或用门面 `路由` 一步完成。

完成后返回*[调用 new](route.new(app=`应用`, path=`路径`, method=`方法`, page=`页面`, fn=`函数`, request=`请求`, response=`响应`, auth=`鉴权`, class=`类别`))*。

## 注册

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 路由 | any | 必填 | 路由句柄 |
| 应用 | any | None | 应用或 None |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 注册结果 |

这里使用`路由`、`应用`=None。

把路由句柄 `路由` 注册到应用；可选 `应用`=None 时用句柄内保存的应用。

完成后返回*[调用 register](route.register(route=`路由`, app=`应用`))*。

## 使用

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 路由 | any | 必填 | 路由句柄 |
| 中间件 | any | 必填 | 中间件表 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 带 middleware 字段的路由记录；此步骤不注册或启动路由 |

这里使用`路由`、`中间件`。

给路由句柄 `路由` 挂上中间件表 `中间件`。

完成后返回*[调用 use](route.use(route=`路由`, middleware=`中间件`))*。
