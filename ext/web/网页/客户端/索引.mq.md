客户端模块：从[中文根手册](../索引.mq.md)选择业务路径。
布局先拆成父组件与 Markdown 叶子，默认不写整页 HTML。构造值与启动进程是两件事；
下面示例从生产者开始，所有句柄沿同一会话传递，渲染时才需要原生插件。

```sh
marqdo call ext/web/网页/客户端/索引.mq.md 挂载 --json
marqdo call ext/web/网页/客户端/索引.mq.md 文本补丁 '选择器="#status"' '文本="就绪"' --json
```

页面结构用五列 View 记录，父值保留子表。纯布局、DOM 构造和客户端描述无需插件。
整站服务通过网页.服务或工程入口的 serve 函数用 marqdo call 启动；检视磁盘站点请给出根目录，不能从新进程
读取另一个进程的私有应用。结构化 Document 使用 视图: main，在启动时执行布局装配。

开发时先复用组件和布局模块，再改对应领域实现；保持中英入口与真实契约一致。
验证 web_handbook 与既有 Web Artifact 金样，资源、鉴权和网络能力不要塞回门面。

## 挂载

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 桥 | text | "/static/marqdo-bridge.js" | bridge 脚本 URL |
| wasm | text | "/static/marqdo_wasm.wasm" | wasm URL |
| 源 | text | "" | 可选源 |
| 启动 | bool | True | 自动启动 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | text | script 标签 HTML |

这里使用`桥`="/static/marqdo-bridge.js"、`wasm`="/static/marqdo_wasm.wasm"、`源`=""、`启动`=True。

返回加载官方浏览器桥的 HTML 片段。默认 `桥`="/static/marqdo-bridge.js"、

`wasm`="/static/marqdo_wasm.wasm"、`源`=""、`启动`=True。不是用 HTML 拼整页的
借口。

完成后返回*[调用 embed](client.embed(bridge=`桥`, wasm=`wasm`, source=`源`, boot=`启动`))*。

## 文本补丁

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 选择器 | text | 必填 | CSS 选择器 |
| 文本 | text | 必填 | 文本内容 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 效果表 |

这里使用`选择器`、`文本`。

为选择器 `选择器` 构造 `set_text` 效果表，文本为 `文本`。

完成后返回*[调用 text patch](client.text_patch(sel=`选择器`, text=`文本`))*。

| 参数 | 类型 | 默认 | 说明 |

| html | text | "" | 可选 HTML |
| 属性 | any | None | 可选属性表 |
| 移除 | bool | False | 是否移除 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 效果表 |

这里使用`选择器`、`html`=""、`属性`=None、`移除`=False。

## 挂载节点

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 桥 | text | "/static/marqdo-bridge.js" | 官方浏览器桥地址 |
| wasm | text | "/static/marqdo_wasm.wasm" | 当前构建的 WASM 产物地址 |
| 源 | text | "" | 可选客户端 Marqdo 程序地址 |
| 启动 | bool | True | 是否自动挂载客户端程序 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | list | 组件 Document 可直接组合的脚本资源节点 |

这里使用`桥`="/static/marqdo-bridge.js"、`wasm`="/static/marqdo_wasm.wasm"、`源`=""和`启动`=True。节点引用官方模块资源，把 WASM 和程序地址保留为属性数据。启动关闭时只声明桥，不自动执行客户端。构造无需插件，不访问网络，也不生成业务 HTML；浏览器打开页面后才加载实际文件。应先构建当前 WASM 并挂载静态目录，再把这些节点与内容组件组合。旧的字符串挂载工具保留兼容用途。

完成后返回*[将官方运行时作为结构资源声明](client.nodes(bridge=`桥`, wasm=`wasm`, source=`源`, boot=`启动`))*.
