文档对象模型模块：从[中文根手册](../索引.mq.md)选择业务路径。
布局先拆成父组件与 Markdown 叶子，默认不写整页 HTML。构造值与启动进程是两件事；
下面示例从生产者开始，所有句柄沿同一会话传递，渲染时才需要原生插件。

```sh
marqdo call ext/web/网页/文档对象模型/索引.mq.md 自Markdown '文本="# 可读"' --session handbook --toget body --json
marqdo call ext/web/网页/文档对象模型/索引.mq.md 渲染 'dom=$body' --effects plugin --session handbook --json
```

页面结构用五列 View 记录，父值保留子表。纯布局、DOM 构造和客户端描述无需插件。
整站服务通过网页.服务或工程入口的 serve 函数用 marqdo call 启动；检视磁盘站点请给出根目录，不能从新进程
读取另一个进程的私有应用。结构化 Document 使用 视图: main，在启动时执行布局装配。

开发时先复用组件和布局模块，再改对应领域实现；保持中英入口与真实契约一致。
验证 web_handbook 与既有 Web Artifact 金样，资源、鉴权和网络能力不要塞回门面。

## 自Markdown

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 文本 | text | 必填 | Markdown 源 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | DOM 映射 |

这里使用`文本`。

把 Markdown `文本` 变成 `{kind:"markdown", text}`，供页面渲染。

完成后返回*[调用 from markdown](dom.from_markdown(text=`文本`))*。

## 原始

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| html | text | 必填 | 原始 HTML |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | DOM 映射 kind=raw |

这里使用`html`。

逃逸舱 — 包装原始 `html`。仅当表驱动无法表达宿主约束时使用，并写明原因。

完成后返回*[调用 raw](dom.raw(html=`html`))*。

## 渲染

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| dom | any | 必填 | 自Markdown 或 原始 的结果 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | HTML 文本 |

这里使用`dom`。

把 DOM 映射 `dom` 渲染为 HTML（须插件）。

完成后返回*[调用 render](dom.render(dom=`dom`))*。
