页面模块：从[中文根手册](../索引.mq.md)选择业务路径。
布局先拆成父组件与 Markdown 叶子，默认不写整页 HTML。构造值与启动进程是两件事；
下面示例从生产者开始，所有句柄沿同一会话传递，渲染时才需要原生插件。

```sh
marqdo call ext/web/网页/页面/索引.mq.md 新建 '标题="预览"' '正文="# 你好"' --effects plugin --session handbook --toget pg --json
marqdo call ext/web/网页/页面/索引.mq.md 渲染 '页面=$pg' --effects plugin --session handbook --json
```

页面结构用五列 View 记录，父值保留子表。纯布局、DOM 构造和客户端描述无需插件。
整站服务通过 launcher 的 marqdo run 启动；检视磁盘站点请给出根目录，不能从新进程
读取另一个进程的私有应用。结构化 Document 使用 视图: main，在启动时执行布局装配。

开发时先复用组件和布局模块，再改对应领域实现；保持中英入口与真实契约一致。
验证 web_handbook 与既有 Web Artifact 金样，资源、鉴权和网络能力不要塞回门面。

## 新建

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 标题 | text | "" | 文档标题 |
| 路由 | text | "/" | 路径 |
| 方法 | text | "GET" | HTTP 方法 |
| 正文 | text | "" | Markdown 正文 |
| 节点 | any | None | View 表或 None |
| 数据源 | text | "" | 表名 |
| 排序 | text | "" | 排序键 |
| 条件 | text | "" | 过滤 |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | 页面句柄 |

这里使用`标题`=""、`路由`="/"、`方法`="GET"、`正文`=""、`节点`=None、`数据源`=""、`排序`=""、`条件`=""。

构造 Document 句柄，默认 `标题`=""、`路由`="/"、`方法`="GET"、`正文`=""、

`节点`=None、`数据源`=""、`排序`=""、`条件`=""。节点必须是统一 View 表。

完成后返回*[调用 new](page.new(title=`标题`, route=`路由`, method=`方法`, body=`正文`, nodes=`节点`, data_source=`数据源`, data_order=`排序`, data_where=`条件`))*。

## 渲染

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 页面 | any | 必填 | Document 句柄 |
| 节点 | any | None | View 表或 None |
| 数据库 | any | None | 可选 db |

| 返回 | 类型 | 说明 |
|------|------|------|
| result | any | HTML 或渲染结果 |

这里使用`页面`、`节点`=None、`数据库`=None。

渲染 Document 句柄 `页面`。可选 `节点`=None、`数据库`=None。不要把手写 HTML 当
作页面壳。

完成后返回*[调用 render](page.render(page=`页面`, nodes=`节点`, db=`数据库`))*。
