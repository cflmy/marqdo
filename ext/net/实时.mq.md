本文件提供 websocket.mq.md 的路由绑定中文入口。客户端持续连接由浏览器标准库负责，服务器只在准备好的应用上声明运输资源。独立的一次连接/响应测试仍使用英文文件的 ws 与 connect，不把两种生命周期混为一谈。

## 绑定

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 应用 | any | 必填 | 准备站点返回并保留其他资源的应用 |
| 路径 | text | 必填 | 明确声明的套接字路径，可含路径捕获 |
| 模式 | text | "echo" | echo、drain、broadcast 或 room |
| 房间键 | text | "" | room 模式的房间模板，例如文档路径捕获 |
| 在线通知 | bool | False | 是否发布原生在线人数消息 |
| 需要登录 | any | None | None 保留广播/房间私有默认；False 明确公开 |
| 消息回调 | text | "" | 可选已声明 Marqdo 回调成员 |

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | map | 附加明确 WebSocket 路由的新应用，尚未监听 |

使用`应用`、`路径`、`模式`="echo"、`房间键`=""、`在线通知`=False、`需要登录`=None、`消息回调`=""。授权 plugin，在监听前保留返回的新应用。构造不会连接浏览器、修改 Document 布局或创建后台线程。

room 模式需要房间键，模板在实际请求中代入路径捕获。广播与房间默认要求登录；本地回显示例显式 False，只用于回环地址的公开演示。隐藏导航不能保护连接，身份策略仍由服务器执行。回调与消息上限沿用原生运输，连接错误不能当作空的成功回复。

绑定完成后返回 *[登记同一个应用的实时运输资源](socket.route(app=`应用`, path=`路径`, mode=`模式`, room_key=`房间键`, presence=`在线通知`, require_auth=`需要登录`, on_message=`消息回调`))*。
