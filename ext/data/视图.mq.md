title: 请求期间查询数据库的视图资源
---

本文件是单文件资源手册。递归页面需要随请求变化的数据库记录时，构造这里的查询资源，再放入组件的资源节点。构造本身是纯计算，不连接数据库，也不生成 HTML；实际查询使用监听应用绑定的数据资源。

view: main 仍在启动时装配结构，不能混用自动 data_source 元数据。普通文档可继续使用元数据绑定；显式 View 用本资源表达动态内容。缺少数据库、条件错误或后端故障都保留请求诊断，不伪造空列表。

## 查询

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 源 | text | 必填 | 监听应用数据库中已有的业务表 |
| 条件 | any | None | 原生条件记录或列表；路径占位来自实际请求参数 |
| 排序 | text | "" | 数据库排序，例如 -created_at |
| 上限 | number | 50 | 1 至 1000 之间的整数 |
| 详情 | bool | False | False 显示卡片，True 显示首条完整文章 |
| 链接前缀 | text | "/post/" | 加到短链前的站内路径前缀 |
| 租户作用域 | bool | False | 要求显式租户策略及实际租户上下文 |

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | map | 尚未查询的 data_query 资源，可放入资源节点 |

使用`源`、`条件`=None、`排序`=""、`上限`=50、`详情`=False、`链接前缀`="/post/"与`租户作用域`=False。服务器先检查资源契约，再在每个请求中查询当前记录。卡片标题与摘要经过转义，完整文章使用已有 Markdown 渲染器；有摘要时，详情仍应显示完整正文，空正文也不会被摘要替换。

返回记录沿用文档的数据约定：title、slug 或 href、summary、body 或 content，以及可选的 created_at/meta 与 tag。父组件继续决定布局，本资源只承担一个动态内容区域。它不恢复旧的页面绑定表，也不接受任意页面配置。需要其他领域投影时，应另立职责清楚的资源。

每次请求先复制条件，再替换实际路径参数，避免污染启动时保留的定义。路径参数优先于同名查询参数。租户作用域要求已有租户策略和已解析租户；请求中的选择值不证明用户属于该租户，数据过滤也不能替代鉴权。

构造不需要副作用权限；服务实际使用插件和监听入口的授权。离线渲染缺少请求上下文时明确报错，不声称已执行查询。阅读源码不会授权数据库访问、写入或启动网络监听。

`资源` =

| _type | source | where | order | limit | detail | link_prefix | tenant_scope |
|---|---|---|---|---|---|---|---|
| data_query | `源` | `条件` | `排序` | `上限` | `详情` | `链接前缀` | `租户作用域` |

请求行为交代清楚后，返回 *资源*，交给组件资源节点安放。
