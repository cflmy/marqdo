# main

A multi-column table with one data row is a map. Read values with footnote keys.

`kinds` =

| apple | cucumber |
|-------|----------|
| fruit | vegetable |

*`k` = `kinds`[^apple] *

> print text=`k`

*`k` = `kinds`[^cucumber] *

> print text=`k`
