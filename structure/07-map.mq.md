# main

A multi-column table with one data row is a map. Read values with `[key](map)`.

`kinds` =

| apple | cucumber |
|-------|----------|
| fruit | vegetable |

**`k` = [apple](kinds)**

> print text=`k`

**`k` = [cucumber](kinds)**

> print text=`k`
