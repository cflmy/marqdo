# 用 ext/linalg 写公式文档

可选扩展（非 stdlib）。安装：`marqdo ext add linalg`（中文 id：`线性代数`）。

*思想：* `.mq.md` 能跑通且断言的规范形一致，则在库规则下该恒等式成立。代数叙述像讲义；`分解` / `最小二乘` / `绘图` 才是显式计算步骤。

这里讨论符号表达式的形状，而不是对矩阵中的每个数值做计算。先声明 A 为两行三列、B 为三行两列，乘积才具有合法的二行二列形状；转置时两个因子的顺序交换，得到 B^T*A^T。输出相符只证明本例在库定义的规范化规则下成立，不意味着任意数值近似或未声明符号也会被接受。

阅读时先看形状表，再看乘法和转置的动作说明。公式库需要对应的原生插件，缺少依赖时应先安装 linalg；不要把插件加载错误当成恒等式不成立。此例不读取或写入业务文件，也不把输出字符串重新执行成代码。需要实际矩阵分解时，沿文件开头的导入路径阅读分解函数的独立契约。
