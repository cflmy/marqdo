view 单元共享状态。

`外联.会话` 从普通表格声明一个 view 会话。表名完全自由；本页用 `分析内核` 和 `分析单元`。

`分析内核` =

| @ | 名称 | 语言 |
|---|------|------|
| 1 | 分析 | python |
| 2 | 复核 | python |

`分析单元` =

| @ | 单元 | 内核 |
|---|------|------|
| 1 | 计算 | 分析 |
| 2 | 复核 | 复核 |

`初始值` =

| 内核 | 名称 | 值 |
|------|------|----|
| 分析 | orders | `订单` |
| 复核 | orders | `订单` |

`会话` = > 外联.会话 内核表=`分析内核` 单元表=`分析单元` 值表=`初始值`

`计算` =
```python
import json
import statistics

by_region = {}
for row in orders:
    by_region.setdefault(row["区域"], []).append(float(row["金额"]))

summary = []
for region, values in sorted(by_region.items()):
    mean = statistics.mean(values)
    sd = statistics.pstdev(values) or 1.0
    summary.append({
        "region": region,
        "orders": len(values),
        "total": round(sum(values), 2),
        "mean": round(mean, 2),
        "z_span": round((max(values) - mean) / sd, 3),
    })

print(json.dumps({
    "regions": summary,
    "total": round(sum(float(row["金额"]) for row in orders), 2),
    "count": len(orders),
}, ensure_ascii=False))
```

`复核` =
```python
import json

print(json.dumps({
    "kernel": "复核",
    "count": len(orders),
    "total": round(sum(float(row["金额"]) for row in orders), 2),
}, ensure_ascii=False))
```

`查看` 消费 `会话` 句柄。Run All 在 `分析` 内核执行 `计算`，在 `复核` 内核执行 `复核`；静态导出走同一批单元，并把真实输出嵌入页面。

语言上的重点：

`初始值` 表把同一个 Marqdo `订单` 值传给两个内核。内核态归 `外联` 管理。view 只渲染句柄和单元。`run` 仍然把同一份文档当程序执行。

没有单独的 notebook CLI，这个示例不依赖 stdin，也没有隐藏的语言切换。
