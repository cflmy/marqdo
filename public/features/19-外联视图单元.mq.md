JSON 调用。Python 把表读成 JSON，按区域聚合，再写出一个 JSON 结果。

`分析` =
```python
import json
import statistics
import sys

rows = json.load(sys.stdin)
by_region = {}
for row in rows:
    by_region.setdefault(row["区域"], []).append(float(row["金额"]))

summary = []
for region, values in sorted(by_region.items()):
    mean = statistics.mean(values)
    sd = statistics.pstdev(values) or 1.0
    summary.append({
        "region": region,
        "orders": len(values),
        "total": round(sum(values), 2),
        "mean": round(mean, 2),
        "z_span": round((max(values) - mean) / sd, 3),
    })

print(json.dumps({
    "regions": summary,
    "total": round(sum(float(row["金额"]) for row in rows), 2),
    "count": len(rows),
}, ensure_ascii=False))
```

**结果 = > 外联.调用 代码=`分析` 输入=`订单`**

> 打印 内容=[count](`结果`)
> 打印 内容=[total](`结果`)
> 打印 内容=[region]([1]([regions](`结果`)))
> 打印 内容=[mean]([1]([regions](`结果`)))

调用是 JSON 进 / JSON 出：表编码到 stdin，stdout 的最后一个值再解析成 Marqdo 值。

view 中的单元。命名内核和单元顺序都是普通绑定表，不是 fence 元数据或 YAML 配置。

```text
`内核表` =

| 名称 | 语言 | 命令 | 说明 |
|------|------|------|------|
| 分析 | python | | 共享分析 |
| 复核 | python | | 独立复核 |

`会话表` =

| 单元 | 内核 | 说明 |
|------|------|------|
| 准备数据 | 分析 | 生成订单 |
| 计算指标 | 分析 | 区域与总额 |
| 独立复核 | 复核 | 读取 JSON 报告 |
```

`marqdo view` 会把这些渲染成带 Run All、Step、切换内核、journal、dirty reload 和状态面板的单元。没有单独的交互命令；`marqdo run` 仍把同一份文件当单个程序执行。
