# main

里程碑（v1.1.0）：AI 原生闭环——让 AI 不仅能写 Marqdo，还能验证 Marqdo。

三件套。核心表面守卫（`doc/design/core-surface.md`）钉住 19 个核心构造，任一侧（清单 / 文档 / 金样）单边改动，CI 必红。渐进式契约是可选的 `参数` / `返回` / `字段` 表，直接嵌在叙述里，四边界校验：调用实参、返回值、表绑定、键访问。MLSP for AI（`marqdo mlsp`）是行分隔 JSON 的语言服务，AI 按需查询语法，而不是背诵整部语法。

静态契约检查：

```bash
marqdo check tests/contracts/ok_contract.mq.md
```

结构化诊断——错误即数据：

```bash
marqdo run tests/structure/hello.mq.md --json
```

按需查询语法（MLSP）：

```bash
printf '%s\n' '{"id":1,"method":"syntax","params":{"query":"返回"}}' | marqdo mlsp
```

MLSP 方法：`locate`（查符号 / 构造卡片）、`syntax`（戒律原文 + 样例 + 文档锚点）、`validate`（结构化诊断）、`repair_targets`（有界靶点）、`repair_apply`（有界行编辑，越界必拒）、`schema`（单元契约）。

> print text=契约是可选的：不写契约表，文件保持全动态。

> print text=诊断自带 code / severity / suggestion / doc_anchor / doc_quote。

> print text=MLSP 语法卡片内嵌戒律原文与样例，AI 无需预学语法。

验证结果见：`doc/roadmap/perf-validation-report-2026-09-23.md`。
