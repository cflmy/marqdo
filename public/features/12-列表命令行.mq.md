# 排序 CSV 并解析参数

零插件：解析 CSV、按键排序、解析 `--input`。

# main

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 空值；按顺序执行本页的演示步骤，观察输出或已说明的副作用。 |

这里先按 name 字段对 CSV 记录排序，所以第一条姓名是 alice；score 在本例中仍是文本，尚未参与数值排序。排序函数返回新集合，重新保存 rows 才能让后续取值使用排序结果。随后构造三个命令参数并交给命令行库，读取 input 的文件名以及 pretty 的开关状态。

参数数组中的元素始终是数据：本例解析 scores.csv 这个名字，不会读取该文件，也不会启动命令解释器。用于真实进程调用时应继续保持逐个参数传递，选项文本要加引号，不要拼成 shell 源码。没有插件、网络和文件授权需求；缺少必须的业务参数时，应由上层根据解析结果决定是否继续，而不是仅看到 pretty 为真就认定所有输入有效。
