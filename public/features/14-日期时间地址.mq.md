# 无需插件的时间与地址

时刻是 map `{unix, zone, iso}`。用 `地址` 拆 HTTPS URL 与查询串。

# main

*epoch = > 日时.自戳 秒=0 区="Asia/Shanghai"*
> print text=`epoch`[^iso]

*u = > 址.解析 内容="https://example.com/path?q=1"*
> print text=`u`[^host]
> print text=`u`[^query]
