# 无需插件的时间与地址

时刻是 map `{unix, zone, iso}`。用 `地址` 拆 HTTPS URL 与查询串。

# main

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 空值；按顺序执行本页的演示步骤，观察输出或已说明的副作用。 |

时间戳零表示同一个时间点；指定 Asia/Shanghai 后，ISO 展示采用该时区的当地时间。改变时区不应改变 unix 字段所代表的瞬间。固定时间戳使本例可以重复验证，不依赖机器当前时钟，也不要求读取时间服务。

地址解析只拆分给定的 HTTPS 文本，host 应为 example.com，query 保留 q=1。它不会访问服务器、验证网站可用性或把查询字符串当作本地文件名。后续需要查询参数时应使用地址库对应的查询解析能力，并保留转义和重复键的边界。时间与 URL 都返回有明确字段的记录；先按契约读取字段，再决定展示格式，避免把整份记录误当成最终用户需要的单段文本。

随后我们**[显示当前步骤的结果](> print text=[iso](access(`epoch`, "iso")))**。

随后我们**[显示当前步骤的结果](> print text=[host](access(`u`, "host")))**。
随后我们**[显示当前步骤的结果](> print text=[query](access(`u`, "query")))**。
