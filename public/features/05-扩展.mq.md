# main

ext/ 存放官方可选扩展，不属于 lib/。解析顺序：MARQDO_EXT、./ext、或可执行文件旁的 ext/。

安装（v0.2+）：

```text
marqdo ext list
marqdo ext add llm
marqdo ext add agent
marqdo ext add web
marqdo ext add quantum
```

带原生插件的包需先编译再 add：

```text
cargo build --release -p marqdo_plugin_agent
cargo build --release -p marqdo_plugin_web
cargo build --release -p marqdo_plugin_quantum
marqdo ext add agent
marqdo ext add web
marqdo ext add quantum
```

- ext/llm（大模型）— OpenAI 兼容聊天。设计：doc/design/ext-llm.md
- ext/agent（智能体）— 智能体框架 + 原生插件。设计：doc/design/ext-agent.md
- ext/web（网页）— HTTP / SQLite 站点助手 + 原生插件。设计：doc/design/ext-web.md
- ext/quantum（量子）— 电路、绘图、噪声、公式 `矩阵=` 自定义门。设计：doc/design/ext-quantum.md
- 安装器：marqdo ext list / add / remove — doc/design/ext-cli.md
- 通用原生插件：lib/plugin + include/marqdo_abi.h — doc/design/ext-abi.md
