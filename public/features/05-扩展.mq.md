# main

ext/ 存放官方可选扩展，不属于 lib/。解析顺序：MARQDO_EXT、./ext、或可执行文件旁的 ext/。

- ext/llm（ext/大模型）— OpenAI 兼容聊天。设计：doc/design/ext-llm.md
- ext/agent（ext/智能体）— 智能体开发框架（当前含布局助手；与大模型组合做编排见路线）。设计：doc/design/ext-agent.md
- ext/quantum（ext/量子）— 态向量电路、`步骤=` 表、`绘图 种类=circuit|probs|bloch`、具名「门」与「匹配矩阵」、教学「噪声」、`屏障`/`测量`/`追加`/`态`。设计：doc/design/ext-quantum.md · Q5：doc/design/ext-quantum-q5.md
- 安装器：marqdo ext list / add / remove — doc/design/ext-cli.md
- 通用原生插件：lib/plugin + include/marqdo_abi.h — doc/design/ext-abi.md
