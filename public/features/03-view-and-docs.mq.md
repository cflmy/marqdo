# main

Milestone: `marqdo view` and `view output` (v1.3.3 document surface).

Local: `marqdo view public`

Static export: `marqdo view output public -o public`

Browse Structure keeps narration, highlights executable markers, and attaches
run results (values, taken branch arms, call/loop frames). The same render path
builds this user docs site; CI publishes to `gh-pages`.

> print text=Docs site: generated by the Marqdo interpreter, not hand-written HTML.
