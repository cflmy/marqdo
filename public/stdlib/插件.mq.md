# main

导入 lib/插件.mq.md。函数：加载(路径)、卸载()、列出()。加载后，插件注册的名称可像普通函数一样调用。C 契约见 include/marqdo_abi.h 与 doc/design/ext-abi.md。路径须落在程序沙箱内。

*`names` = > 插件.列出 *

*`n` = > 长度 值=`names` *

1. `n` >= 0
  > 打印 内容=插件就绪
2. *
  > 打印 内容=插件异常
