# main

版本 2.6.0：标准库通常是单个 lib/名称.mq.md 文件，源码本身就是手册，不要求额外 index。直接阅读标题下的参数、默认值和返回表即可调用；多文件拓展库才通过 index 组织模块。当前 61 份公开标准库包含 650 个函数。

使用 YAML 的 import（或导入）映射导入模块。文件、网络、进程等副作用仍由运行入口授权；marqdo call 默认只运行纯函数，文件调用要明确 --effects 与 --fs-root。文档契约不会自动授予权限。

新增字节、归档、Result、文档操作及集合工作流；数组读写要注意一基路径与旧零基接口的区别。更完整的标准库源码在 lib/，真实工程在 examples/stdlib-handbook，开发规范见 doc/library-development.mq.md。

官方库在仓库 lib/（别名 std/）。在 YAML frontmatter 的 import 或导入映射中填写模块别名与路径，例如 lib/文本.mq.md 或 lib/文件.mq.md。

拉丁文件名导出英文 API；中文文件名导出中文 API。JSON 特例：只有 lib/json.mq.md（中英共用）。

导入只选择模块，不替代实际运行入口的副作用授权。marqdo view 或静态导出里，退出会软失败、长睡眠会被钳制，以免拖垮控制台。

模块：文本（text / 文本）、表（table / 表）、文件（fs / 文件）、时间（time / 时间）、系统（sys / 系统）、json（仅 json）、网络（net / 网络）、数学（math / 数学）、外联（foreign / 外联）、插件（plugin / 插件）、自写回（writeback / 自写回）、子任务（subtask / 子任务）。外联 v2 新增结构化执行记录、JSON 调用、并行扇出、Python/Node 持久内核、显式状态桥与文档原生 view 单元 — 见 stdlib/外联.mq.md 与 features/19-外联视图单元.mq.md。

自 v0.1.2 起，官方 `lib/*.mq.md` 内置于 `marqdo` 二进制（磁盘 `lib/` 或 `MARQDO_LIB` 仍可覆盖）。单独下载 `.exe` 即可导入标准库，无需再解压 stdlib 包。

官方可选扩展在 ext/（不是标准库）：ext/llm、ext/agent — 见 features/05-扩展.mq.md。

各模块说明见本目录其它页。English: 00-overview.mq.md.
