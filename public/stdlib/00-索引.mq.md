# main

官方库在仓库 lib/（别名 std/）。在 YAML frontmatter 用大于号行导入，例如 lib/文本.mq.md 或 lib/文件.mq.md。

拉丁文件名导出英文 API；中文文件名导出中文 API。JSON 特例：只有 lib/json.mq.md（中英共用）。

导入即表示要用对应能力，无需再加允许旗标。marqdo view 或静态导出里，退出会软失败、长睡眠会被钳制，以免拖垮控制台。

模块：文本（text / 文本）、表（table / 表）、文件（fs / 文件）、时间（time / 时间）、系统（sys / 系统）、json（仅 json）、网络（net / 网络）、数学（math / 数学）、外联（foreign / 外联）、插件（plugin / 插件）。

官方可选扩展在 ext/（不是标准库）：ext/llm、ext/agent — 见 features/05-扩展.mq.md。

各模块说明见本目录其它页。English: 00-overview.mq.md.
