# main

Hello — and welcome. I built Marqdo so that *code is documentation and documentation is code*: Markdown markers are the program structure, so what you read is what runs.

AI systems already favor Markdown-shaped output. That raised a simple question: why keep docs and programs as two separate artifacts? Marqdo is the answer. The `.mq.md` suffix exists so a file stays renderable as Markdown while remaining executable. Richer OKF-style YAML catalogs and even slide decks are on the roadmap; for now this site itself is generated by Marqdo — and that often saves tokens when an AI is writing with you.

The language is still early: structural markers, English/Chinese builtin aliases (`print` / `打印` …), an importable standard library (see [`stdlib/`](stdlib/) on this site), local `view`, and static export. Join in at [GitHub](https://github.com/cflmy/marqdo).

中文文档请看同目录的 [`00-欢迎.mq.md`](00-欢迎.mq.md)（叙述与内置均用中文）。

A small function to say hello (calls in entry `# main` actually run; `##` children are methods and do not auto-run):

> greet who=marqdo

Named args can include spaces:

> greet who=marqdo user

Beyond the basics above, Marqdo also ships standard libraries: table, time, text, files, system, math, foreign, and more.

Math and foreign deserve a special mention. With the math library you can bind a formula like this:

`f` =
$$
x^2 - 2
$$

Then plot it:

**`_svg` = > math.plot formula=`f` var="x" min=-3 max=3**

The foreign library lets you call external code, for example:

`hi` =
```python
print("hello-from-python")
```

Under Markdown this stays easy to read — which is the point: Marqdo’s design is code as documentation, documentation as code.

Welcome again — enjoy exploring Marqdo.

## install

Install the interpreter (CLI) in any of these ways:

| Way | Notes |
|------|------|
| Ubuntu PPA | `sudo add-apt-repository ppa:cflmy/marqdo` then `sudo apt install marqdo` |
| GitHub Releases | Prebuilt Windows / Linux packages from [releases](https://github.com/cflmy/marqdo/releases) |
| From source | `cargo build --release` (needs a local Rust toolchain) |

Official extensions update independently of the CLI:

```text
marqdo ext add web
marqdo ext add quantum
```

`ext add` tries CDN https://ext.marqdo.com first, then GitHub, then the proxy mirror. See [`features/05-extensions.mq.md`](features/05-extensions.mq.md).
