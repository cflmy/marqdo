周六的咖啡馆手账——下面既是给人看的说明，也是可以 `marqdo run` 的程序。
**说明**性的加粗只是强调；真正算账的步骤也用粗体写在句子里，算完的值用斜体交回去。

---

## 单价

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 价 | any | 必填 | 同一币种下单件商品的标价 |
| 杯数 | any | 1 | 参与本次计价的杯数，未提供时使用正文默认值 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 逐行累加得到的订单总额 |

一杯标价为`价`的饮品，默认`杯数`=1。先把**总额 = 价 * 杯数**算清，再返回*总额*。

## 会员折

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 原价 | any | 必填 | 应用折扣之前的原始金额 |
| 折扣 | any | 0.85 | 价格乘数；0.85 表示支付原价的百分之八十五 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 下文显式返回的计算值或结构化结果；分支存在时遵循实际命中的分支。 |

会员单要原价`原价`；店里默认八五折，记作`折扣`=0.85。
先算**应付 = 原价 * 折扣**，再返回*应付*。

## 结账摘要

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 品名 | any | 必填 | 收据或摘要中显示的商品名称 |
| 价 | any | 必填 | 同一币种下单件商品的标价 |
| 杯数 | any | 1 | 参与本次计价的杯数，未提供时使用正文默认值 |
| 会员 | any | False | 是否采用本示例的会员折扣分支 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 包含商品、数量和实付金额的显示文案 |

客人点了`品名`，单价`价`，杯数`杯数`=1；是否`会员`=False。

按杯数问单价：**小计 = 单价 价=`价` 杯数=`杯数`**。

1. `会员`
  我们先**实付 = [计算并保存 实付](会员折(原价=`小计`))**，供下一步使用。
  我们先**标签 = "会员价"**，供下一步使用。
2. *
  我们先**实付 = `小计`**，供下一步使用。
  我们先**标签 = "原价"**，供下一步使用。

对账时拼成一句人话：

我们先**文案 = ((((((`品名` + " ×") + `杯数`) + " → ") + `标签`) + " ") + `实付`)**，供下一步使用。
完成上述步骤后，返回*文案*。

## 印章加一

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 印 | any | 必填 | 积分卡当前已有的印章数量 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 下文显式返回的计算值或结构化结果；分支存在时遵循实际命中的分支。 |

积分卡上的`印`，每喝一杯就**印 = 印 + 1**，接着返回*印*。

# main

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 空值；按顺序执行本页的演示步骤，观察输出或已说明的副作用。 |

这份手账把定价规则放在真正的结账函数里，入口只组织今天的几笔订单。菜单横表是品名到单价的记录，外卖行表则是多条带有数量和会员标记的订单；两者的数据形态不同，因此先按名称取价，再逐行传给同一个摘要函数。

会员示例与原价对照使用同一套参数和默认值，避免正文与实现各维护一份优惠规则。金额在本例中使用普通运行时数值，会员折扣可能产生小数；这里没有宣称采用专门的货币舍入模型。需要真实计费精度时应另行规定最小单位与舍入步骤，不能把展示摘要的文本当成准确记账凭证。

打印的是已经计算出的摘要，后续业务若要复用它应直接传递该值，而不是解析输出文字。最后给积分卡加一只改变演示中的印章值，不写入用户文件，也不代表某个真实账户已经更新。

今日黑板价目——表格给人扫一眼，程序当字典用：

`菜单` =

| 美式 | 拿铁 | 燕麦拿铁 |
|------|------|----------|
| 18   | 28   | 32       |

**打印 内容=`对照`**
