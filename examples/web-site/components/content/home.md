# Marqdo

One executable Markdown artifact declares routes, forms, admin pages, and styles — no hand-written business JavaScript, no author .css. Click a card for the full article, then try the three steps below.

- 0 author JS
- 0 author .css
- GFM tables

1. Click any card — /post/{slug} opens the detail page from the same articles table.
2. Open [New](/new) and submit with an empty title (validation from a rule table).
3. Open top-nav **Login** (admin / demo), then **Admin** — gated desk with create form + list.
