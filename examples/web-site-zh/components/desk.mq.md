自定义后台保留自己的品牌与结束链接，不带公共侧栏。实际鉴权仍归服务入口；构造这些节点或隐藏某个链接都不会授权访客进入管理页面。

## nav

| 返回 | 类型 | 说明 |
|---|---|---|
| result | list | 按当前会话解析的后台导航 |

构造无需副作用。首项保持后台上下文，随后提供站点、写文章及退出；与原站一样，只有退出行依赖登录条件。整个页面已由服务入口另行保护，退出目的地仍是原生会话地址。本块返回结构化资源，父层负责位置和外观，不能把可见性判断当成服务器门禁。

后台与公共导航分开，避免管理中的品牌仍跳向首页。修改路径应同步检查真实处理器清单，防止链接看似存在却没有声明对应行为。

`项目` =

| @ | label | href | when |
|---|---|---|---|
| 1 | 后台 | /admin | |
| 2 | 站点 | / | |
| 3 | 写文章 | /new | |
| 4 | 退出 | /admin/logout | auth |

我们 **资源 = [描述后台实际会话导航](组件.导航资源(项=`项目`))**。
最后返回 *[保持相同导航片段身份](组件.请求资源(值=`资源`, 槽="nav"))*。

## foot

| 返回 | 类型 | 说明 |
|---|---|---|
| result | list | 后台终端 Markdown 返回与退出链接 |

授予站点文件根的 fs.read。实际路由门禁在渲染本组件之前已决定访问，站点和后台保留返回目标；退出只有被访问时才结束会话，读叶子不产生退出操作。页脚只有一个链接职责，内部无独立几何，不为凑目录再拆一层。父层放置它，主题提供原来的页脚外观。

我们 **文本 = [读取后台终端结束链接](文件.读文本(路径="components/content/desk-footer.md"))** 和 **叶子 = [保留普通 Markdown 内容](组件.正文(文本=`文本`, 槽="footer-content"))**。
最后返回 *[放入后台语义页脚](组件.包裹(子节点=`叶子`, 种类="footer", 槽="footer", 样式="foot"))*。
