本模块只拥有这一组导航。文字、目标及顺序保留原站约定，会话相关行必须在每次请求中决定，因此使用具型导航资源，不能把启动时的身份快照当成当前用户。

## side

| 返回 | 类型 | 说明 |
|---|---|---|
| result | list | 保留稳定片段槽名的单个导航请求资源 |

构造是纯计算，不登录、退出或注册路由。空 when 始终显示，guest 与 auth 按服务器当前会话筛选；原生导航类名继续服务于已有主题。隐藏后台链接不能阻止直接访问，服务入口另行对实际 /admin 地址绑定角色门禁。

父模块负责网格位置，本块只解释目标。改文字在这里完成，改路径同时核对声明的 Document。资源值保留结构，不拼 HTML，也不返回已被移除的 front/back 页面绑定表。

`项目` =

| @ | label | href | when |
|---|---|---|---|
| 1 | 1. 首页 | / |  |
| 2 | 2. 写文章 | /new |  |
| 3 | 3. 登录 | /login | guest |
| 4 | 3. 后台 | /admin | auth |
| 5 | 关于 | /about |  |

我们 **资源 = [描述当前会话的可见链接](组件.导航资源(项=`项目`, 区域="sidebar"))**。
最后返回 *[保留一个具型导航区域](组件.请求资源(值=`资源`, 槽="sidebar"))*。
