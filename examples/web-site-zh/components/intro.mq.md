引言终止于普通 Markdown：分类、标题、解释、特性列表与阅读步骤。它们已经能直接用文档层次表达，主题选择这些真实语义元素。页面几何仍归父框架，不恢复旧的引言绑定方言。

## nodes

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| name | text | 必填 | 作者选择的 home、about、new、desk 或 post 叶子 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | list | 包裹实际终端 Markdown 的语义引言区域 |

输入`name`，在站点文件根授权 fs.read。路径由作者的 Document 选择，不是请求参数。缺失叶子保留原生文件诊断，不回退到抄写的固定正文。读取内容不会把其中的强调或链接执行成 Marqdo 语句，而是交给既有 Markdown 渲染器解释。

叶子内部没有独立的排列职责，只有引用分类、标题、段落、项目符号和编号步骤。若将来出现需要独立几何的子区域，应继续拆分。样式保留原来的字体、徽章与步骤面板，内容仍直接可读。

我们 **路径 = "components/content/" + name + ".md"**、**文本 = [读取这段引言的实际内容](文件.读文本(路径=`路径`))** 和 **叶子 = [保留简单的 Markdown 层次](组件.正文(文本=`文本`, 槽="intro-content"))**。
完成后返回 *[将引言放入明确语义区域](组件.包裹(子节点=`叶子`, 种类="section", 槽="intro", 样式="main-intro"))*。
