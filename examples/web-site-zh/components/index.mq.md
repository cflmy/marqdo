本父模块只决定站点结构。公共页面保留导航、侧栏和主体、页脚；后台采用自己的导航与页脚，不带公共侧栏。各子模块拥有 Markdown 或具型请求资源，父层不渲染子块后再拼 HTML。

## frame

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| body | list | 必填 | 页面自己提供并保留资源值的主体节点 |
| management | bool | False | 选择已被实际门禁保护的后台框架 |
| homepage | bool | False | 只有首页保留原来的首页 SEO |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | list | 递归站点结构及真正收集到 head 的纯资源 |

使用`body`、`management`=False、`homepage`=False。导航按当前请求会话解析，本函数不认证用户；后台路径由服务入口另行保护，选择后台框架不会授予权限。页脚只有一组普通链接，内部已可用简单 Markdown 表示，因此无需人为继续拆分。

稳定槽名 nav、sidebar、main 与 footer 保留片段身份。原生资源外层继续留在结构树中，主题让其语义子块参与原来的命名网格。is-desk 类属于这个明确框架，代替旧的整页 body 变异；颜色、动画与属性值仍来自原始声明。纯页头资源不会成为用户正文。

1. `management`
  我们 **顶部 = [使用后台自己的导航](后台.nav())**、**旁栏 = [后台不带公共侧栏](表.空表())**、**底部 = [读取后台返回链接](后台.foot())** 和 **样式 = "site-layout no-sidebar is-desk"**。
我们 **主体 = [保留页面自身的正文责任](组件.包裹(子节点=`body`, 种类="section", 槽="main", 样式="main"))**、**子块 = [导航位于公共侧栏之前](表.拼接(a=`顶部`, b=`旁栏`))**、**子块 = [放入实际主体](表.拼接(a=`子块`, b=`主体`))** 和 **子块 = [以选定页脚结束](表.拼接(a=`子块`, b=`底部`))**。
