客户端拥有连接标识和纯文本消息记录，原生控件由 components/live.mq.md 声明，服务端绑定同源 /live 路由。这里只生成官方桥效果，不通过外联脚本操纵页面。连接状态保留旧控件的 connected/closed 文本作为可观察协议。

# main

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | map | 事件绑定、套接字打开与初始状态效果 |

入口使用对象 main 保留后续回调需要的连接标识和消息记录。点击与 Enter 都携带当前输入值，实际收到回显后才追加日志。连接成功启用发送，错误或关闭则禁用。重载重建演示状态，不声称提供持久历史或自动重连。

事件表中的调用名对应下面的直接回调，值选择器显式指向输入。浏览器桥负责真正的运输和 DOM 更新；这份代码的纯效果构造无需插件。普通辅助函数显式接收连接标识，避免假定任意嵌套调用都能捕获入口状态。

官方桥按事件表传入 value，键盘事件另外携带 key，消息回调携带 data，错误回调携带 error，所以这些公共回调保留实际字段名。声明中的 then_open、then_message 等是既有运输协议，不是新的作者语言。相对 /live 路径跟随页面真实主机与端口，避免把本地验收端口写死在客户端。

我们 **连接 = "live"** 和 **消息 = ""**，保留入口状态。

`绑定` =

| @ | 选择器 | 事件 | 调用 | 值选择器 |
|---|---|---|---|---|
| 1 | "#live-send" | click | 发送 | "#live-msg" |
| 2 | "#live-msg" | keydown | 按键 | "#live-msg" |

`打开` =

| op | id | url | then_open | then_message | then_error | then_close |
|---|---|---|---|---|---|---|
| open | `连接` | /live | 已打开 | 收到消息 | 出错 | 已关闭 |

我们 **事件 = [保留原生控件事件](表.设(map=None, key="wire", value=`绑定`))** 和 **运输 = [描述同源实时连接](浏览器.套接字(规格=`打开`))**。
最后返回 *[将事件与运输效果一起交给官方桥](浏览器.合并(甲=`事件`, 乙=`运输`))*。

## _状态

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 文本 | text | 必填 | 显示给用户的纯文本连接反馈 |
| 禁用 | bool | 必填 | 发送按钮真实布尔属性 |

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | map | 状态文字与按钮属性两种效果的组合 |

使用`文本`和`禁用`，让连接反馈与按钮可用性保持一致。False 令桥移除 disabled，字符串 false 则仍为存在的布尔属性，不能混用。状态更新不清空消息、不发送重试，也不创建第二个连接；它只描述两个独立效果种类。

我们 **属性 = [保留真实布尔禁用值](表.设(map=None, key="disabled", value=`禁用`))**、**状态 = [描述纯文本反馈](浏览器.设文本(选择器="#live-status", 文本=`文本`))** 和 **按钮 = [描述实际发送可用性](浏览器.设属性(选择器="#live-send", 属性=`属性`))**。
最后返回 *[保留独立效果种类](浏览器.合并(甲=`状态`, 乙=`按钮`))*。

## 已打开

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| ok | bool | True | 官方桥给出的实际打开结果 |

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | map | 成功时启用发送，否则保留失败状态 |

使用`ok`=True 接收打开回调。成功只证明运输已就绪，消息交付仍由真实回显观察。打开失败不添加假的欢迎消息，也不悄悄重连。状态和按钮通过同一个辅助函数更新，避免用户看到失败却仍能点击发送。

1. `ok`
  返回 *[真实打开后允许发送](_状态(文本="connected", 禁用=False))*。
否则返回 *[保持打开失败可见](_状态(文本="connection failed", 禁用=True))*。

## _发送

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 值 | text | 必填 | 点击或 Enter 交来的输入文本 |
| 通道 | text | 必填 | 入口保留并显式传入的现有连接标识 |

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | any | 非空消息发送效果；去空白后为空则返回 None |

使用`值`和`通道`复用原控件的发送策略。先去掉两端空白，空消息不发送。内容只是文本，不能成为命令或 HTML；发送效果不表示已经交付，日志必须等待真实回显。这一普通辅助调用显式接收通道，不依赖直接回调才有的入口状态。

我们 **内容 = [保留原有去空白策略](text.str_trim(s=`值`))**。
1. `内容` == ""
  返回 *None*，表示没有发送。

`操作` =

| op | id | data |
|---|---|---|
| send | `通道` | `内容` |

准备完成后返回 *[发送一个真实非空消息](浏览器.套接字(规格=`操作`))*。

## 按键

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| key | text | "" | 官方桥提供的真实键名 |
| value | text | "" | 该事件值选择器取得的输入文本 |

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | any | Enter 使用共享发送策略，其他键返回 None |

使用`key`=""与`value`="" 接收键盘回调。只在 Enter 时发送，避免每次编辑键都产生消息。点击和 Enter 共享相同的去空白、空输入忽略行为，既不重复安装处理器，也不创建另一条连接或提前生成本地回显。

1. `key` == "Enter"
  返回 *[使用与按钮相同的发送规则](_发送(值=`value`, 通道=`连接`))*。
普通编辑键返回 *None*。

## 出错

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| error | text | "" | 浏览器运输报告的实际错误描述 |

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | map | 可见错误反馈与禁用发送 |

使用`error`=""，把运输失败放在控件旁边。历史消息仍可阅读，失败不清空记录、不尝试新发送，也不悄悄重连。用户可重载页面建立新会话；这里的效果不等于故障恢复成功，按钮应保持不可用。

我们 **文本 = "error: " + error**，最后返回 *[让错误与可用性一致](_状态(文本=`文本`, 禁用=True))*。

## 已关闭

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | map | 关闭反馈与禁用发送，保留历史消息 |

连接关闭后，既有消息仍可阅读，发送按钮需要禁用。此回调不清空入口状态，也不自动创建另一条连接。后续真实发送应由新页面会话中的实际打开事件启用；不能把关闭当作正常消息交付或显示假的重连成功。

关闭后返回 *[保留真实结束状态](_状态(文本="closed", 禁用=True))*。
