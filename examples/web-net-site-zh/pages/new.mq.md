本 Document 用元数据显式声明 /new 路径。说明留在终端 Markdown，导航、侧栏和页脚归共享布局。本页只放 article 表单引用，字段、校验与真实提交处理器由独立资源定义。

## main

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | list | 共享站点框架中的发布说明与表单请求资源 |

启动阶段只装配结构，授予 fs.read 读取 Markdown 叶子。服务器在每次请求中才为实际会话准备 CSRF 与返回路径，不能在启动时写死令牌。未知表单标识是真实请求错误；页面可见不替代提交地址的访问策略。 路由来自本页声明，首次阅读即可判断入口与内容来源。

我们 **文本 = [读取本页的终端说明](文件.读文本(路径="components/content/new.md"))** 和 **正文 = [保留简单 Markdown 内容](组件.正文(文本=`文本`, 槽="intro"))**。
我们 **引用 = [引用实际挂载的文章表单](表单.引用(标识="article"))**、**操作 = [安放请求期间解析的表单](组件.请求资源(值=`引用`, 槽="article-form"))** 和 **正文 = [让说明先于填写操作](表.拼接(a=`正文`, b=`操作`))**。
最后返回 *[放进共享递归布局](布局.框架(正文=`正文`))*。
