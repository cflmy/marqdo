本页对明确的本地夹具执行标准网络解析器，不访问外部 HTTP。Cookie 头是纯文本，multipart 正文是 content 目录中的终端协议数据。预格式文本控件展示实际记录，既不拼 HTML，也不把手抄的预期值当作执行结果。

## _面板

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 标题 | text | 必填 | 作者控制的观察项标题 |
| 值 | any | 必填 | 解析器实际返回的原生值 |

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | list | Markdown 标题与转义的预格式文本节点 |

输入`标题`与`值`，用这个纯构造把含义与观察结果放在一起。标题来自作者，协议输入只作为文本展示，不能变成页面结构或执行表达式。原生值转为显示文本后由 pre 保留字符；即使包含尖括号或引号也不会作为 HTML 解析。本函数不读取文件，也不运行解析器。

我们 **标题文本 = "## " + 标题**、**说明 = [用 Markdown 解释观察项目](组件.正文(文本=`标题文本`))** 和 **文本 = [保留原生结构的实际显示值](str(值))**、**数据 = [按纯文本展示观察结果](组件.控件(种类="pre", 值=`文本`))**。
最后返回 *[将说明与实际数据放在一起](表.拼接(a=`说明`, b=`数据`))*。

## _Cookie

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | list | 真实请求 Cookie 与响应 Set-Cookie 两种解析结果 |

请求模式解析 session 与 theme 键值；响应模式把 Path、HttpOnly 与 SameSite 视为同一个 id Cookie 的属性。两次调用都使用维护中的标准库，结果形态的差异来自真实模式，不是作者拼接的展示。

这是确定性的文本夹具，不代表当前浏览器登录，也不会写 Cookie 或把夹具当作有效凭据。面板保留所有返回字段，读者能直接观察名称、值和标志。解析为纯计算，不需要插件或网络授权。

我们 **请求 = [解析明确的请求头夹具](网络.解析Cookie(内容="session=abc123; theme=dark"))** 和 **响应 = [按响应头模式解析属性](网络.解析Cookie(内容="id=42; Path=/; HttpOnly; SameSite=Lax", 是响应头=True))**。
接着 **请求面板 = [展示真实请求键值](_面板(标题="Cookie 请求头", 值=`请求`))** 和 **响应面板 = [展示真实响应属性](_面板(标题="Set-Cookie 响应头", 值=`响应`))**。
观察完成后返回 *[相邻保留两种解析模式](表.拼接(a=`请求面板`, b=`响应面板`))*。

## _多部分

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | list | 实际 multipart 文本字段与文件部分的观察面板 |

授予 fs.read，从站点根读取 CRLF 协议夹具，边界保持文件声明的 net-boundary。title 部分是“你好”，cover 部分标记 pic.png 与 image/png。文件值仅为字面 <字节>，不声称包含真正的二进制图片或执行上传。

解析器返回原生列表，使用从零开始的取项选择两个部分。夹具缺失或格式错误保留真实文件/解析诊断，不能改为固定预期答案。展示协议内容不会提取文件、访问网络或解释其中的 Markdown。

我们 **正文 = [原生读取精确的本地协议文本](文件.读文本(路径="components/content/multipart.txt"))** 和 **部分 = [解析边界与内容处置字段](网络.解析多部分(正文=`正文`, 边界="net-boundary"))**。
接着 **字段 = [读取第一条真实部分记录](表.首(list=`部分`))**、**文件部分 = [读取从零开始的第二条记录](表.取(xs=`部分`, i=1))**、**字段面板 = [展示真实表单字段](_面板(标题="多部分字段", 值=`字段`))** 和 **文件面板 = [展示真实文件元数据](_面板(标题="多部分文件", 值=`文件部分`))**。
最后返回 *[保留两种实际观察](表.拼接(a=`字段面板`, b=`文件面板`))*。

## main

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | list | 共享布局内的四项真实标准库解析观察 |

装配需要 fs.read 读取 multipart 夹具与共享布局叶子，解析本身是纯计算。四个面板保留请求 Cookie、响应 Cookie、multipart 字段和文件元数据。修改夹具会改变展示结果，因为页面运行真实标准库，而不是显示事先编好的答案。

用户仍可从共享导航去发布、后台或实时区域。面板内只展示纯文本，协议中的 <字节> 不会成为标签。这个工具页不代表真实网络流量、登录身份或用户上传。

我们 **介绍 = [解释本地解析演示](组件.正文(文本="# 网络工具\n\n由标准网络库提供真实 Cookie 与 multipart 解析结果。"))**、**Cookie = [观察请求与响应两种模式](_Cookie())** 和 **多部分 = [观察实际字段及文件部分](_多部分())**。
接着 **正文 = [说明位于观察结果之前](表.拼接(a=`介绍`, b=`Cookie`))** 和 **正文 = [保留后续 multipart 结果](表.拼接(a=`正文`, b=`多部分`))**。
全部观察就绪后返回 *[放进共享站点框架](布局.框架(正文=`正文`))*。
