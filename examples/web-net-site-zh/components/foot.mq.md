页脚保留原示例的项目链接与工具文档入口。本块只有一组简单链接，没有双栏布局；将来出现独立品牌栏与链接栏时再继续拆成两个子组件。

## 页脚

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | list | 包含终端 Markdown 的单个语义区域 |

本组件只拥有本块内容与语义容器。以站点为 --fs-root 授予 fs.read，正文读取相邻内容目录的 Markdown 叶子，不查询记录或启动服务器。父布局决定本块位置；修改文字与链接只编辑叶子。保留稳定槽名与样式类，使片段和主题继续找到本区域，内容不会先被渲染成不透明字符串。

我们 **文本 = [读取本区域的终端 Markdown](文件.读文本(路径="components/content/foot.md"))** 和 **叶子 = [保持简单 Markdown 内容](组件.正文(文本=`文本`, 槽="foot-content"))**。
准备好内容后返回 *[保留这一块的语义与样式](组件.包裹(子节点=`叶子`, 种类="footer", 槽="foot", 样式="foot"))*。
