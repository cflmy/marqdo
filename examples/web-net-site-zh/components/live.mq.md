本区域拆到简单 Markdown 与原生控件即停止，不写 HTML 或业务 JavaScript。浏览器客户端负责事件与状态，服务入口负责 /live 运输。控件标识是双方契约，修改文案时保留这些标识。

## _状态

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | list | 独立的连接状态文本目标 |

连接与消息是两个不同的反馈区域。状态使用稳定 live-status 标识及礼貌的辅助通知，初始文字不表示已连接。真实连接的开、错、关由浏览器客户端更新。本构造是纯计算，不加载运行时或尝试网络；状态文字按文本转义，不能变成页面结构。

`属性` =

| id | aria-live |
|---|---|
| live-status | polite |

我们返回 *[创建独立的连接反馈目标](组件.控件(种类="text", 值="正在连接…", 属性=`属性`, 槽="live-status"))*。

## _操作

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | list | 输入与发送按钮组成的响应式行 |

输入提供消息值，按钮启动时使用真实布尔 disabled，只有连接成功后才移除该属性。字符串 false 仍会让 HTML 布尔属性存在，因此不能用它替代 False。控件 id 和客户端事件绑定一致，标题可改，标识应同步修改。

这两个叶子已经无法再拆成 Markdown，因为需要原生输入与点击目标。横向排列仍交给统一 View 行容器，窄屏按运行时规则折叠；这里不固定像素宽度、不安装事件处理器，也不在构造期间发送任何消息。按钮显式 type=button，因此嵌入其他内容时不会意外触发表单提交；placeholder 只提示输入，不作为实际消息值。

`输入属性` =

| id | placeholder | type |
|---|---|---|
| live-msg | 输入一条消息… | text |

`按钮属性` =

| id | type | disabled |
|---|---|---|
| live-send | button | True |

我们 **输入 = [声明原生消息输入框](组件.控件(种类="input", 属性=`输入属性`, 槽="live-input"))** 和 **按钮 = [连接前保持发送禁用](组件.控件(种类="button", 值="发送", 属性=`按钮属性`, 槽="live-send"))**。
随后 **操作 = [保持输入与发送相邻](表.拼接(a=`输入`, b=`按钮`))**，最后返回 *[声明可折叠的操作行](组件.包裹(子节点=`操作`, 种类="row", 槽="live-controls"))*。

## _输出

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | list | 保留纯文本回显的预格式区域 |

消息由客户端收到真实帧后追加，页面构造不伪造初始回显。pre 保留换行，稳定 live-out 标识供文本效果更新；辅助通知采用 polite，避免将输入误当作实时状态。尖括号、引号与协议内容都应显示字面字符，不能通过设 HTML 展示。

`属性` =

| id | aria-live |
|---|---|
| live-out | polite |

结构明确后返回 *[创建转义文本消息目标](组件.控件(种类="pre", 属性=`属性`, 槽="live-output"))*。

## 节点

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | list | 实时区域的标题、状态、操作、输出与官方桥资源 |

本层只确定四个子块的顺序，终端控件由上面三个职责提供。标题用普通 Markdown，区域 id 保留侧栏 /#live 目的地。构造无需插件，不连接服务器；监听和网络策略仍归服务入口。

官方桥从明确静态地址加载当前 WASM 与 public/client.mq.md。调用前应构建匹配版本并放入 public/generated，构造节点本身不检查存在性。启动时的空日志仅代表尚未收到消息；错误与关闭不能被解释为成功传输。客户端源是 Marqdo，页面不嵌入手写业务 JavaScript。运行时资源与页面内容并列保留，不能先调用旧字符串挂载再塞进正文。页面只有一个客户端源和一条连接，不因为组件拆分而重复启动同一个小部件。

我们 **标题 = [说明实时区域](组件.正文(文本="## 实时 WebSocket", 槽="live-heading"))**、**状态 = [独立装配连接反馈](_状态())**、**操作 = [独立装配原生输入与发送](_操作())** 和 **输出 = [独立装配文本消息目标](_输出())**。
接着 **正文 = [先呈现标题与状态](表.拼接(a=`标题`, b=`状态`))**、**正文 = [再放置输入操作](表.拼接(a=`正文`, b=`操作`))** 和 **正文 = [最后展示真实回显](表.拼接(a=`正文`, b=`输出`))**。
我们 **属性 = [保留既有页内目的地](表.设(map=None, key="id", value="live"))** 和 **区域 = [组合一个语义区域](组件.包裹(子节点=`正文`, 种类="section", 属性=`属性`, 槽="live"))**。
随后 **运行时 = [引用官方桥与 Marqdo 客户端](客户端.挂载节点(源="/static/client.mq.md", wasm="/static/generated/marqdo_wasm.wasm", 桥="/static/generated/marqdo-bridge.js"))**。
完成后返回 *[保留区域与运行时结构](表.拼接(a=`区域`, b=`运行时`))*。
