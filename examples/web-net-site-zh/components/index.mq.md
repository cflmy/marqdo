本入口只管理各块的位置关系。先拆导航、侧栏与主体行、页脚，再由子模块读终端 Markdown。请求期间的查询和表单保留在主体内，不把渲染结果拼回 HTML 字符串。调整文案沿子模块找到内容叶子，调整几何只修改本层。

## 框架

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 正文 | list | 必填 | 页面自身已经构造的主体节点 |

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | list | 有序导航、侧栏/主体双栏、页脚与主题资源 |

输入`正文`，本层不查询数据库、不验证身份，也不负责启动监听。侧栏和主体是行容器的两个子块，窄屏折叠由已有 View 运行时负责。节点始终保留结构值，主题只引用 serve 已编译并写入的文件；纯构造不会读取或下载样式。共享 Markdown 的读取需要 fs.read。

我们 **顶部 = [读取导航内容](导航.导航())** 和 **旁栏 = [读取侧栏内容](侧栏.侧栏())**，**主体 = [给页面正文稳定区域名](组件.包裹(子节点=`正文`, 种类="column", 槽="main"))**。
接着 **双栏 = [保留侧栏与主体的兄弟关系](表.拼接(a=`旁栏`, b=`主体`))**、**中部 = [声明响应式横向几何](组件.包裹(子节点=`双栏`, 种类="row", 槽="page-body"))** 和 **底部 = [读取结束链接](页脚.页脚())**。
我们 **页面 = [导航位于内容之前](表.拼接(a=`顶部`, b=`中部`))**、**页面 = [页脚位于内容之后](表.拼接(a=`页面`, b=`底部`))** 和 **样式 = [引用明确生成的声明式主题](组件.资源(地址="/static/generated/theme.css", 种类="stylesheet"))**。
完成布局后返回 *[让结构与样式资源一起保留](表.拼接(a=`页面`, b=`样式`))*。
