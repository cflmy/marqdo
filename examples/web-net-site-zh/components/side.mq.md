侧栏提供文章、实时连接、鉴权、表单与网络解析的任务跳转。WebSocket 的页内锚点保持 /#live，改变文字无需修改连接实现。

## 侧栏

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | list | 包含终端 Markdown 的单个语义区域 |

本组件只拥有本块内容与语义容器。以站点为 --fs-root 授予 fs.read，正文读取相邻内容目录的 Markdown 叶子，不查询记录或启动服务器。父布局决定本块位置；修改文字与链接只编辑叶子。保留稳定槽名与样式类，使片段和主题继续找到本区域，内容不会先被渲染成不透明字符串。

我们 **文本 = [读取本区域的终端 Markdown](文件.读文本(路径="components/content/side.md"))** 和 **叶子 = [保持简单 Markdown 内容](组件.正文(文本=`文本`, 槽="side-content"))**。
准备好内容后返回 *[保留这一块的语义与样式](组件.包裹(子节点=`叶子`, 种类="aside", 槽="side", 样式="side"))*。
