主题保留原站的四组属性值，控件与容器只引用类名。它没有大段作者 CSS 或页面字符串。服务入口调用编译，将结果通过原生文件写到明确的生成路径，再让布局引用该资源。

## 顶栏

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | any | 导航背景与底部分隔线 |

导航内容采用白色背景，并以浅色细线与下方内容分开。返回值保留原有颜色和边框，不负责导航链接或几何布局。它是纯属性数据，调用不加载插件、不写文件；编译阶段才把它映射到原生导航类。

`属性` =

| 属性 | 值 |
|---|---|
| background | #ffffff |
| border-bottom | 1px solid #e7e5e4 |

属性明确后返回 *属性*，供主题编译继续使用。

## 侧栏面板

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | any | 侧栏背景属性 |

侧栏用浅色背景区分任务跳转与主体内容。这里只保留原有背景值，不重复设置父行宽度或移动端折叠行为。纯属性表可以独立阅读和比较，调用不查询数据，也不生成样式文件；父布局继续拥有侧栏位置。

`属性` =

| 属性 | 值 |
|---|---|
| background | #f5f5f4 |

属性明确后返回 *属性*，供主题编译继续使用。

## 卡片标题

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | any | 文章标题字号与间距属性 |

请求查询资源生成的文章卡片使用这些标题声明，保留原始字号和下边距。标题内容仍由真实记录提供且经过转义，样式不会注入文章文字或链接。属性构造为纯计算，不运行查询；选择器在编译阶段与原生卡片结构对齐。

`属性` =

| 属性 | 值 |
|---|---|
| font-size | 1.15rem |
| margin | 0 0 0.35rem |

属性明确后返回 *属性*，供主题编译继续使用。

## 卡片正文

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | any | 文章正文颜色与间距属性 |

文章正文保留原站的次级文字颜色和零外边距。此表不截断或替换正文，也不改变 Markdown 与数据字段之间的约定。它只提供纯属性数据，布局、渲染和数据库生命周期都在各自模块，编译后再引用共同的主题文件。

`属性` =

| 属性 | 值 |
|---|---|
| color | #57534e |
| margin | 0 |

属性明确后返回 *属性*，供主题编译继续使用。

## 编译

| 返回 | 类型 | 说明 |
|---|---|---|
| 结果 | text | 四个原始属性表编译成的有序 CSS |

调用需要 plugin，按导航、侧栏、卡片标题和正文的顺序编译。选择器直接对应原生组件与查询卡片，避免重复声明一份旧页面绑定布局。所有属性值保留原站定义；通用响应式几何仍由 View 运行时负责。

本函数不写文件或挂载资源，调用者收到文本后通过原生文件能力写入明确目标。编译失败应阻止监听，不能退回旧样式假装本轮成功。修改单块属性只改上面的对应函数，验证编译结果与真实窄屏页面，避免颜色保留却丢失结构作用。生成文件可以重建，原始声明仍以本文件为准。

我们 **导航 = [读取原有导航属性](顶栏())**、**侧栏 = [读取原有侧栏属性](侧栏面板())**、**标题 = [读取原有标题属性](卡片标题())** 和 **正文 = [读取原有正文属性](卡片正文())**。
随后 **导航样式 = [编译导航类](网页.编译样式(名称="topnav", 属性=`导航`))**、**侧栏样式 = [编译侧栏类](网页.编译样式(名称="side", 属性=`侧栏`))**、**标题样式 = [编译实际卡片标题选择器](网页.编译样式(名称="content.cards h2", 属性=`标题`))** 和 **正文样式 = [编译实际卡片正文选择器](网页.编译样式(名称="content.cards p", 属性=`正文`))**。

`片段` =

| 样式 |
|---|
| `导航样式` |
| `侧栏样式` |
| `标题样式` |
| `正文样式` |

编译完成后返回 *[保留声明顺序](text.str_join(xs=`片段`, sep="\n"))*。
