—— 5. 遮蔽：把实现藏进括号 ——

描述给人读，`()` 里才是机器执行的部分。

写法用 `` `名` = [描述](实现) ``（裸赋值），而不是 `**名 = [描述](实现)**`：
粗体会把描述也包成"代码味"，读者一眼看到的是强调而不是人话。

`留存` = [客户留存率，模拟数据](0.42)

> print text=遮蔽的值：`留存`

未接通的功能用空载荷申报（会得到一条 warning，提醒写清返回值）：

`待接` = [搜索接入，接口未接，待开发]()

> print text=空载荷桩的值：`待接`
