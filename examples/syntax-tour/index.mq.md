## main

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | 本次演示实际得到的名字长度、求和结果、嵌套调用值及空载荷值 |

从本节开始按顺序执行一份完整程序；命令行可以直接 call 本文件的 main 得到计算记录；View 或 run 另行展示打印步骤。call 需要 output.write 授权，因为本例确实执行打印，但它的业务结果以返回记录为准。下方辅助函数也可以按自己的标题独立调用，不需要先理解一套另外维护的工具签名。执行位置中的变量会保存本轮实际结果，说明文字则交代这些结果为什么出现在这里。

变量、参数和字段名有不同职责。变量保存已经得到的值，参数把外部输入交给函数，字段名标识记录中的数据；看见同样的文字不能把三者混为一谈。读取已有值时使用反引号，文本字面值加引号，命令选项也遵守这个规则。表格先说明形态，再绑定为值；字段与返回契约则紧接对应标题，帮助读者在看实现前决定如何调用。

本例没有文件写入、网络请求或外联解释器。空载荷是刻意保留的教学桩：它返回空值并给出 warning，用来展示待补充逻辑如何被看见，而不是模拟搜索已经完成。默认分支也只是此例选择的业务规则，不代表库能够自行推断所有未知输入。循环会改变示例中的计数变量，返回会立即结束函数，所以所有后续演示都安排在最终返回之前。

一列表是列表，一行多列是记录；行记录集合使用首列标记区分。表头标识业务字段，标记列不成为业务值。需要按列保存多行数据时，应明确选择对应形态，不能只凭视觉排列猜运行时结构。

程序最后返回真实中间值，便于调用方逐项验证。打印文字是给人观察的另一条通道，不应再被解析成下一步的输入。要改变演示数据，先检查对应契约和索引约定，再重复实际调用；不能仅凭标签读起来正确就认定其中实现符合描述。

## 计税

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 档位 | any | required | 税率档位；1 取 3%，3 取 20%，其他值沿用本例 10% |
| 金额 | any | required | 待计税金额；需要支持与选定税率相乘 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 金额乘以本例选定税率；不包含额外舍入 |

输入`档位`与`金额`，先按明确的分支选择税率，再计算同一份输入的税额。这是教学规则，不读取外部税表，也不把未知档位推断成新的税率。返回值由乘法得到，调用方根据自己的金额单位继续处理。

本函数不做货币舍入、不写日志或文件。普通数值可以直接传入；不支持乘法的值保留原生诊断，而不是悄悄当作零。观察选中哪个分支，比只看最后的打印标记更容易核对规则。

先**率 = 0.1**作为本例的默认税率。
1. `档位` == 1
  此档位使用**率 = 0.03**。
2. `档位` == 3
  此档位使用**率 = 0.2**。
3. *
  其余输入沿用**率 = 0.1**。
选定税率后，我们返回*[按本例规则计算税额](金额 * 率)*。

## 加

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| a | any | required | 左操作数；与 b 使用兼容的加法语义 |
| b | any | required | 右操作数；与 a 使用兼容的加法语义 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 两个操作数按原生加法语义得到的新值 |

输入`a`和`b`，直接组合两个已提供的值。本例用整数调用以展示位置实参、逗号分隔和嵌套调用；函数不会修改调用者变量，也不读取打印输出。需要类型转换时在调用前显式完成，不让这个简单函数猜测字符串是否代表数字。

得到两个输入后，我们返回*[按相同规则相加两个操作数](a + b)*。

## 加一 号

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| n | any | required | 参与加一的输入值；本例以数字演示 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 输入加一的新值，函数名中的空格仍保留 |

输入`n`之后，按原生加法与一相加。这个函数刻意保留带空格的名称，以展示可读名称与命令行参数引用之间的关系。调用者仍通过完整标题定位它；空格不代表参数，也不需要额外的隐藏入口。

完成这次计算后，我们返回*[把输入推进一位](n + 1)*。
