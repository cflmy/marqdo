# 采购智能体：验收与真实接口接入说明

## 工程放置方式

建议把 `index.mq.md` 放入 Marqdo 仓库的 `examples/procurement/`，或可以解析 `lib/table.mq.md` 和 `lib/time.mq.md` 的现有项目中。`import` 中沿用仓库根目录提供的公开标准库。下面命令假设从 `index.mq.md` 所在目录执行。

此文件目前是**采购业务 SKILL + 本地模拟工具集合**，不是可执行的真实采购交易系统。它仍需要负责决策的 Agent 调度各工具，并保存独立调用日志。

## 真实系统接入路线

1. **供应商主数据**：替换 `查询采购商` 中的示例名录，保持相同字段，并加入供应商状态更新时间与可靠的准入校验。
2. **报价**：替换 `查询采购商价格` 的静态样例源，增加供应商确认的报价编号、有效期、税运费与币种信息；只有真实服务确认后才允许真实下单。
3. **预算账本**：把 `已花费` 的调用方输入升级为权威持久账本读数，并在工单提交前做原子预算预占、幂等和失败释放，防止并发超预算。
4. **真实工单**：真实发送必须以服务端校验的报价、准入、预算预占凭证为依据；保存工单号、状态迁移、外部调用结果和完整审计轨迹。
5. **真实回执与议价**：把 `模拟回复` 替换为工单服务查询结果；议价后重新获取报价，不能擅自修改原单价格；切换后重新比价。
6. **Agent 层**：由调用者保存每一步的入参、原始结果、选择理由及关联编号。当前函数调用为无持久状态的模拟，尚不能担保跨进程审计或执行重放。

## 重要限制

- 本次改写参考了公开仓库源码与规范，但运行环境未提供 `marqdo` 可执行文件，因此没有实际完成 `marqdo check` 或函数调用测试。
- 表格金额使用示例整数元；生产环境应使用整数分或经过审计的十进制金额库，避免浮点误差。
- 当前“发工单”返回 `ok=True` 只表示本地演练的门禁通过，不表示真实订单提交成功。
- 模拟工单号含秒级时间戳，不保证跨调用唯一，也不能充当生产幂等键。
