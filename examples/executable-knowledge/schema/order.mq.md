# 订单

| 字段 | 类型 | 说明 |
|---|---|---|
| 行 | list | 待计价的订单行；每一项遵守下方独立对象的字段契约 |

订单只收拢本次计算需要的行记录，不替调用方补缺失金额或品类。
每一行使用同一金额单位，税率知识由能力模块选择；此处只描述数据形态。

# 订单行

| 字段 | 类型 | 说明 |
|---|---|---|
| 金额 | number | 未税金额 |
| 品类 | text | 用于选择税率 |

订单行是独立的顶层对象类型，因此订单中的列表元素可以引用它。
字段表紧接对象标题，避免将类型声明误写成具有参数和返回值的普通函数。

行字段的运行时契约约束列表本身；元素形态按订单行的字段说明提供，
不把尚未支持的泛型类型拼写当成已经执行的逐元素校验。
