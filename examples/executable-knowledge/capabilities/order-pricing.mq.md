# 订单定价

按订单行取未税金额与品类，套用税率后汇总含税总额。

## 含税价

`行`

**金额 = [订单行金额](access(行, "金额"))**
**品类 = [订单行品类](access(行, "品类"))**
**税率 = > tax.标准税率.查询 品类=`品类`**
**结果 = [本行含税价](金额 * (1 + 税率))**
*结果*

## 含税总额

`订单`

**行列表 = [订单行列表](access(订单, "行"))**
`总额` = 0
- [逐个订单行](遍历 行列表 为 行)
  **行含税价 = > 订单定价.含税价 行=`行`**
  **总额 = [累加](总额 + 行含税价)**
*总额*
