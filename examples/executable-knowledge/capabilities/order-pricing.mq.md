# 订单定价

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 供下述方法复用的对象或类型命名空间；直接调用所需的子函数。 |

按订单行取未税金额与品类，套用税率后汇总含税总额。

## 含税价

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 行 | any | 必填 | 订单行记录；按相邻数据表提供金额、品类等字段 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 本次计算得到的结果 |

输入`行`，按下方步骤使用这个值。

我们先**金额 = [订单行金额](access(`行`, "金额"))**，供下一步使用。
我们先**品类 = [订单行品类](access(`行`, "品类"))**，供下一步使用。
我们先**税率 = [计算并保存 税率](tax.标准税率.查询(品类=`品类`))**，供下一步使用。
我们先**结果 = [本行含税价]((`金额` * (1 + `税率`)))**，供下一步使用。
完成上述步骤后，返回*结果*。

## 含税总额

| 参数 | 类型 | 默认 | 说明 |
|---|---|---|---|
| 订单 | any | 必填 | 包含行记录集合的订单数据；税率与金额字段由本示例约定 |

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 逐行累加得到的订单总额 |

输入`订单`，按下方步骤使用这个值。

我们先**行列表 = [订单行列表](access(`订单`, "行"))**，供下一步使用。
我们先**总额 = 0**，供下一步使用。
- [逐个订单行](遍历 行列表 为 行)
  我们先**行含税价 = [计算并保存 行含税价](订单定价.含税价(行=`行`))**，供下一步使用。
  我们先**总额 = [累加]((`总额` + `行含税价`))**，供下一步使用。
完成上述步骤后，返回*总额*。
