# main

启动（spawn）四选一（其余参数默认 None）。

路径=：marqdo run 子进程；等待返回退出码。

函数= 加可选 参数=：入口模块中的函数（线程）；等待返回返回值。

代码=：外联代码块子进程；等待返回 stdout 文本。

语言= 加 源码=：外联源码子进程；等待返回 stdout 文本。

文件子任务默认静默；静默=假 时继承父终端。另有：探测、终止、等待全部。父进程结束会终止文件/外联子进程。

> 打印 内容=子任务总览就绪
