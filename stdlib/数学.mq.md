# main

导入 lib/数学.mq.md。运行时类型：num（浮点）与 formula（符号树）。用空 RHS 赋值后跟 `$$…$$` 围栏绑定公式（与表格赋值同构）。view 的 Structure 会用 KaTeX 渲染该公式。

`f` =
$$
x^2 - 2
$$

数值：圆周率、自然底数、数、加/减/乘/除/幂、正弦/余弦/正切、平方根/绝对值/对数/指数、向下取整/向上取整、最小/最大。随机：设种子、随机、随机整数。

符号：公式、化简、展开、求导、代入、求值、求解。

作图（库已提供）：绘图 / 绘点列 / 绘圆锥，返回 SVG 文本。坐标轴带箭头与刻度；**默认显示网格**（`grid=假` 可关闭）。可选 path= 写盘。无 path 时 CLI 自动写 stem-plot-n.svg 并打印 plot: …；view 在 Execution 内嵌 SVG。

求导 / 化简 / 展开 / 未完全数值化的代入仍返回 formula，可继续链式调用（例如求二阶导后再绘图或求值）。

*`ty` = > type `f`*

> print text=`ty`

*`df` = > 数学.求导 formula=`f` var="x"*

> print text=`df`

*`roots` = > 数学.求解 formula=`f` var="x"*

> print text=`roots`

*`_svg` = > 数学.绘图 formula=`f` var="x" min=-3 max=3*

> print text=plot-ok
