# 标准库

标准库组件负责低层通用能力，验收后共同组成基础发行的标准库 Bundle。 进入各组件目录查看独立仓库和开发任务。

- [marqdo-std-core](core/README.md) · Result 与基础数值
- [marqdo-std-collections](collections/README.md) · List、Map 和 Table 值操作
- [marqdo-std-text](text/README.md) · Unicode 文本、字节值与 UTF-8
- [marqdo-std-encoding](encoding/README.md) · Base64、Base32 和 Hex
- [marqdo-std-data](data/README.md) · JSON、CSV、TOML 与 GFM 数据转换
- [marqdo-std-io](io/README.md) · Console、Stream、格式化和官方 print 别名
- [marqdo-std-fs](fs/README.md) · 文件、目录与路径
- [marqdo-std-system](system/README.md) · 时钟、UTC、环境、进程与随机
- [marqdo-std-net](net/README.md) · TCP、UDP、TLS 和网络字节流
