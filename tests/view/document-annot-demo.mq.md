# main

本页演示 **view 文档面**：叙述文字保留，可执行标记高亮，跑完后把变量值、分支命中与循环次数引出到段落下方。

先准备一份小测验的原始分数表`分数表`：

`分数表` =

| 分 |
|----|
| 92 |
| 67 |
| 45 |
| 88 |

我们用累加器`总分`和计数器`人数`从零开始，遍历每一行分数：

**总分 = 0**
**人数 = 0**

- [分](分数表)
  **总分 = 总分 + 分**
  **人数 = 人数 + 1**
  > print text=录入分数 `分`

遍历结束后计算平均分`均分`（人数不为零时）：

**均分 = 总分 / 人数**

接着按均分给出等级文案`等级`——这是一条三路分支：

1. `均分` >= 85
  **等级 = "优秀"**
2. `均分` >= 60
  **等级 = "及格"**
3. *
  **等级 = "需补习"**

最后打印摘要，并两次调用下方的「等级说明」（便于 view 下拉切换调用帧）：

> print text=人数 `人数` · 均分 `均分` · 等级 `等级`
**说明 = > 等级说明 等级=等级**
> print text=`说明`
**对照 = > 等级说明 等级="优秀"**
> print text=对照：`对照`

## 等级说明

对于输入变量`等级`，我们按字面再分支一次，返回一句说明文字。

1. `等级` == "优秀"
  *"均分很高，保持节奏即可。"*
2. `等级` == "及格"
  *"已过线，仍可把薄弱项补一补。"*
3. *
  *"建议安排复习周，再测一次。"*
