# main

**打印 内容=(礼貌 [问候] "Marqdo")**
**打印 内容=([问候] "Ada")**
**打印 内容=([问候] ([格式化] "Bo"))**

`菜单` =

| 美式 | 拿铁 |
|------|------|
| 18   | 28   |

**价 = [拿铁](菜单)**
**打印 内容=`价`**
