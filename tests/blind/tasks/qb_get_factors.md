# Task: qb_get_factors (hard) — Prime Factorization

Implement **prime factorization** as a function named `get_factors` in a Marqdo `.mq.md` program. The function takes an integer `n ≥ 2` and returns its prime factors in ascending order.

## Requirements

1. Function name `get_factors`.
2. In `# main`, hardcode the demo inputs below and print each result on its own line — factors joined by `*` with no spaces, exactly three lines, no labels.

## Demo inputs (hardcode)

- `12`
- `13`
- `60`

## Expected output (self-check)

Three lines:

```
2*2*3
13
2*2*3*5
```

## Deliverable

Write the program as a Marqdo `.mq.md` file. Return the complete source in a single ```markdown fence — no prose outside the fence.
