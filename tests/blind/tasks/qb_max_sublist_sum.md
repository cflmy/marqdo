# Task: qb_max_sublist_sum (hard) — Maximum Sublist Sum

Implement the **maximum contiguous sublist sum** as a function named `max_sublist_sum` in a Marqdo `.mq.md` program. The function takes a list of integers and returns the maximum sum of any contiguous sublist (at least one element).

## Requirements

1. Function name `max_sublist_sum`.
2. In `# main`, hardcode the demo inputs below and print each result on its own line — exactly three lines, no labels.

## Demo inputs (hardcode)

- `[-2, 1, -3, 4, -1, 2, 1, -5, 4]`
- `[1, 2, 3]`
- `[-3, -1, -2]`

## Expected output (self-check)

Three lines:

```
6
6
-1
```

## Deliverable

Write the program as a Marqdo `.mq.md` file. Return the complete source in a single ```markdown fence — no prose outside the fence.
