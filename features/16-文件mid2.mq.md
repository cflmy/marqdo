使用固有文件库完成整个演示。调用 main 时授予 fs.write，并指定独立的 --fs-root。函数返回实际元数据与相对路径列表，正常结束后清理自己的临时目录。

## main

| 返回 | 类型 | 说明 |
|---|---|---|
| result | map | 真实文件字节数、目录条目数与相对路径列表 |

本轮先创建唯一临时目录，再在其中建立子目录和文本文件，避免固定的演示名称与已有目录冲突。创建和写入都受 --fs-root 约束，目录参数并不授予访问其他位置的权限。所有路径由当前流程明确构造，没有外部脚本代为读取或修改正文。

内容“好”占三个 UTF-8 字节，size 描述存储大小而不是字符数。遍历结果包含文件和子目录的相对路径，条目数与字符串长度也是不同的量。本例只观察枚举内容，不依赖操作系统给出的顺序；需要稳定排序时应继续组合表库。

实际观察值保存后删除本轮独有的临时树。返回的路径列表描述已经观察过的内容，不是仍然存在的文件句柄。中途失败保留原生诊断与可能留下的本轮目录，调用方可以检查后清理，不应递归删除与演示无关的用户目录。

先**work = [创建本轮独有的授权临时目录](文件.临时目录(前缀="文件树演示"))**和**child = work + "/子"**及**note = work + "/说明.txt"**。
接着**[递归创建本轮子目录](文件.建目录树(路径=`child`))**，并**[写入一个明确的 UTF-8 字符](文件.写文本(路径=`note`, 内容="好"))**。
观察时保存**metadata = [读取真实文件元数据](文件.状态(路径=`note`))**和**paths = [枚举本轮目录里的实际条目](文件.遍历(路径=`work`))**及**size = [保留存储字节数](access(metadata, "size"))**和**entries = [保留遍历条目数](长度(`paths`))**。
最后**[只清理本轮独有的目录树](文件.删目录树(路径=`work`))**，再组织实际观察值。

`observed` =

| size | entries | paths |
|---|---|---|
| `size` | `entries` | `paths` |

完成观察与清理后，我们返回*observed*。
