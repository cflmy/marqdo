# 无需插件的配置与安全字面

# main

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 空值；按顺序执行本页的演示步骤，观察输出或已说明的副作用。 |

三个步骤处理三种文本边界：TOML 解析得到 app 字段的记录，HTML 转义把尖括号变成普通可展示文本，Base32 把 UTF-8 输入编码为另一种文本表示。它们彼此独立，不能把配置解析、页面布局和编码混成一个隐藏的字符串处理流程。

TOML 文本直接来自本页，读取真实配置文件时应先使用原生文件库；本例不会隐式寻找系统配置。HTML 转义适用于普通文本展示，不能代替 URL、脚本或样式上下文各自需要的处理，更不应因此拼接大量业务 HTML。Base32 只改变表示方法，不加密数据。所有结果都可继续传递给其他 Marqdo 函数，当前步骤不创建文件、不发送网络请求，也不需要外联解释器。

我们先**cfg = [解析显式提供的 TOML 配置](配置.解析(内容="app = \"演示\"\n"))**，供下一步使用。
随后我们**[显示当前步骤的结果](> print text=[app](access(`cfg`, "app")))**。

我们先**safe = [将尖括号转义为普通展示文本](超.转义(内容="<tag>"))**，供下一步使用。
随后我们**[显示当前步骤的结果](> print text=`safe`)**。

我们先**b = [把输入文本编码为 Base32](编.基32编码(内容="ok"))**，供下一步使用。
随后我们**[显示当前步骤的结果](> print text=`b`)**。
