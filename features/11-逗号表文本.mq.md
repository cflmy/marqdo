# 用文本助手清洗 CSV

解析小表、规范化字段、打印 — 无需插件。

# main

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 空值；按顺序执行本页的演示步骤，观察输出或已说明的副作用。 |

CSV 解析先保留每个单元格的文本语义；下面选择第一条记录，再把城市字段规范为大写，得到 LONDON。姓名字段仍是 Ada，另一条记录仍保留在原集合中。调用文本变换不会自动替换原记录，因此这里只展示规范化值，不宣称整个表已经被清洗。

这里的 at 使用从零开始的位置，access 则按字段名读取记录；不要把二者的索引规则混用。输入正文直接写在本页，没有文件或进程访问。接入真实文件时先用原生文件库读取文本，再交给同一个解析函数；需要金额等数值运算时必须另外做明确的类型转换，不能根据 CSV 中的数字外观推断类型。两行计数只验证这份固定样本的解析结果。
