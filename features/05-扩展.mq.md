ext/ 存放官方可选扩展，不属于 lib/。解析顺序：`~/.marqdo/ext`、MARQDO_EXT、./ext、或可执行文件旁的 ext/。

安装（v0.2+）：

```text
marqdo ext list
marqdo ext add llm
marqdo ext add agent
marqdo ext add web
marqdo ext add quantum
marqdo ext add linalg
```

`ext add` 会下载 L1 与预编译 native（若有）。下载顺序：CDN https://ext.marqdo.com → GitHub Releases → proxy 镜像。扩展包版本见 `ext/VERSION`，可与 CLI 分开发版。

带原生插件的包若需本地重编：

```text
cargo build --release -p marqdo_plugin_agent
cargo build --release -p marqdo_plugin_quantum
cargo build --release -p marqdo_plugin_linalg
bash ./scripts/build-web-plugin.sh
marqdo ext add agent
marqdo ext add web
marqdo ext add quantum
```

扩展包（勿用 Markdown `-` 列表：在 Marqdo 里 `-` 是循环）：

ext/llm（大模型）— OpenAI 兼容聊天。设计：doc/design/ext-llm.md

ext/agent（智能体）— 智能体框架 + 原生插件。设计：doc/design/ext-agent.md

ext/web（网页）提供 Document/Endpoint、递归 View、页头和请求资源。布局拆到 Markdown 或原生控件叶子，数据、鉴权与运输分别归 ext/data、ext/security、ext/net。完整实践见 examples/web-site-zh/index.mq.md 与 examples/web-net-site-zh/index.mq.md；浏览器交互通过 Marqdo 客户端及官方 WASM 桥完成。开发、构建和真实验收入口为 skills/marqdo-dev/index.mq.md，操作使用 marqdo call；当前作者契约见 ext/web/网页/索引.mq.md。

ext/quantum（量子）— 电路、绘图、噪声、公式矩阵自定义门、Q7 密度/高级图、Q8 主题 SVG（`主题=dark|light|bw`）。设计：doc/design/ext-quantum.md · doc/design/ext-quantum-viz-style.md

安装器：marqdo ext list / add / remove — doc/design/ext-cli.md

通用原生插件：lib/plugin + include/marqdo_abi.h — doc/design/ext-abi.md
