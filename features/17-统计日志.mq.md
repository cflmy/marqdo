# main

| 返回 | 类型 | 说明 |
|---|---|---|
| result | any | 空值；按顺序执行本页的演示步骤，观察输出或已说明的副作用。 |

数值列表包含十、二十和三十，平均值应为二十。这里把数据写成一列表格，让读者能直接核对输入，而不是在外部解释器中再构造同一份列表。统计函数不修改原集合；需要中位数、标准差或空集合策略时，应继续阅读统计库对应函数的独立契约。

结构化日志同时携带消息与步骤、状态字段，用于后续过滤或诊断。日志输出不是函数的业务返回值，也不能作为已经完成某项发布或文件写入的证据。本例没有文件和网络操作；实际日志目的地与权限沿用日志库的运行环境规则。若后续任务依赖统计结果，就应直接传递 m 的数值，而不是重新解析打印文本或把最后一条日志当作成功标志。
